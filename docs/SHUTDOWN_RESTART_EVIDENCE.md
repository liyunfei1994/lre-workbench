# 关机与再启动：文献证据、模型边界及验证要求

核读日期：2026-10-22。下列页码均为本地 PDF 的文件页码，从 1 开始；Binder 的正文印刷页码比 PDF 页码小 2。本文检查全文提取文本，并对主要证据所在的原始页面进行了渲染核对。论文正文、批注和高亮是资料，不是平台实现指令。

本文记录研究依据与实施取舍，不是实机验证报告。平台当前实际功能和验收结果应分别参见模型说明、代码和验证记录。公式是本平台按统一符号约定建立的守恒合同，不宣称逐式复制某篇文献。

## 1. 结论与本阶段定位

关机不是将推力或流量直接置零。入口关阀之后，管路与容腔中的质量、内能、转子动能和壁面储热仍然存在；压力改变可能使原流路发生反流。再次开阀时的初态应来自前一阶段的实际终态，而不是重置为首次启动的温度、库存和转速。

本地文献中，**Binder 1995 对 RL10 的关机试验比较，是本阶段最直接的证据**。Di Matteo 2011 提供关机阀门功能、低速泵图与预启动初始化方法；Zhou 2021 和 Liu 2025 提供热容、冷却、容腔及部件耦合方法，但不能据此声称已验证甲烷发动机的完整关机和再次点火。Majumdar 与 Flachbart 2003 支持关阀瞬态必须保留动量和压缩性，并提示集中参数模型对水击峰值的适用边界。

这一阶段宜先建立可审计的**关阀、排放、惰转、余热停留及再次开启响应**。如果算例未包含燃烧及涡轮驱动耦合，界面应明确其为供给支路再启动研究，不能把再次恢复流量称为发动机重新点火成功。给定再次点火事件也不等于自主预测点火成功。

## 3. 建议采用的守恒与事件合同

### 3.1 时间线与状态连续性

至少区分：运行初态、关阀命令、实际阀位变化、驱动转矩撤除、排放开启、停留余热、排放关闭、再次供给及再次驱动事件。保存事件时间和实际到达情况。本轮库存模式要求仿真时长覆盖再次开启命令斜坡，否则拒绝该输入；如果适用域停止使后续事件没有到达，应显示“未执行”，不能伪称已完成一个关机/再启动循环。

各阶段应继续积分同一套有效状态。改变外部边界或阀门命令本身不应重置 `m`、`U`、各物种库存、`Tw`、管路流量和 `ω`。若因模型切换必须转换状态，应检查质量、元素、能量及动量的一致性，并记录转换残差。没有完整相态、工质和物性基准的数据快照不能自动导入。

### 3.2 库存、排放与反流

对刚性控制体，取端口流入为正：

```text
dm/dt = Σ mdot_port
dU/dt = Σ (mdot_port × h_upwind) + Qwall + Qexternal + Wshaft_into_fluid
dm_k/dt = Σ (mdot_port × Y_k,upwind) + chemical_source_k
```

当某端口反流时，其焓和组分采用实际上游状态；不能保持正向入口的工质组成。`p dV/dt` 对固定容积为零，压力流动功已含在端口焓中。摩擦和轴功怎样进入流体热量，需要与所选模型能量定义一致，不能重复计算。

“残余总库存”“仍可排出库存”“累计排出质量”“累计反流质量”和“未反应推进剂库存”是不同量。只积分一条流量曲线不能代表管路已排空；总质量非零也不必然说明含有液态推进剂。容腔与外界压力平衡后仍可有残余气体。单相液体或未跟踪物种的模型应使用相应限定名称。

准稳态孔口的流向按压差决定；具有动量状态的惯性支路可能在压差改变后继续原方向运动。不得用每一步压差的符号强制覆盖惯性支路流量。关闭阀的过渡中，应说明泄漏面积或理想完全关闭处理；不能靠无说明地剪裁状态掩盖刚性或守恒问题。

### 3.3 转子惰转和再次驱动

```text
J × dω/dt = τdrive − τhydraulic − τloss
Erotor = 0.5 × J × ω²
dErotor/dt = (τdrive − τhydraulic − τloss) × ω
```

关机时撤除驱动命令不意味着 `ω=0`。阻力矩必须与转向一致；零速不能使用 `τ=P/ω`。若禁止倒转，须有明确的止逆机构/事件模型；若允许倒转，泵图及轴损失必须覆盖负转速。固定或指数衰减的给定驱动转矩只代表输入边界，不能宣称计算了涡轮残气的实际输出。

应独立审计转子动能变化与积分净轴功。只有液体库存与机械模型能量基准一致时，才能把它们纳入一个总能量账本；将不同子模型各自的“通过”并列展示，不等于整机总能量已经闭合。

### 3.4 余热与停留

```text
Qwall_to_fluid = UA × (Tw − Tf)
Cwall × dTw/dt = Qambient − Qwall_to_fluid
```

正负号应允许反向换热。关阀后已存储的壁能继续释放，可能加热残余气体/液体、造成相变或压力回升；这些现象能否预测取决于实际采用的物性和相态模型。固定 `UA`、恒定热容量的单节点壁模型是等效研究模型，不解析局部热点、导热路径变化或真实沸腾换热转变。

停留期间不能自动将壁温重置到环境温度。再启动的初始壁温应来自停留积分结果，或由有出处的测量明确覆盖；两者应在记录中可区分。

## 4. 应展示的结果与不能混淆的判据

| 显示内容 | 可直接定义的研究量 | 不能自动推断的结论 |
|---|---|---|
| 命令与实际阀位 | 关闭/开启时刻、响应滞后、泄漏面积 | 真实硬件已完成关阀 |
| 各控制体压力、温度、库存 | 压力衰减、残余质量、压力回升 | 熄火成功、排空合格 |
| 有符号流量与累计反流 | 反流开始/结束、反流质量和路径 | 已预测所有回火或交叉污染风险 |
| 转速、转矩、转子动能 | 惰转曲线、动能释放、再次驱动响应 | 实际涡轮启动装置能力充分 |
| 壁温及热流 | 停留后的热状态、输入热假设下的余热 | 热疲劳寿命或材料安全性 |
| 再次供给后的压力/流量 | 恢复到用户参考阈值的时间 | 自主点火成功、再启动可靠性 |
| 点火/化学模块（若已耦合） | 外加能量、反应放热、未燃组分变化 | 未经相应试验建立的通用点火、延迟、熄火判据 |

参考压力、残余质量比例或转速阈值应标记为用户的研究阈值，不作为普适“安全再启动许可”。计算完成、数值守恒通过、某参考阈值达到、真实发动机验证是四个不同层次。

## 5. 分层验证计划

1. **事件与连续性**：关闭、停留、再次开启前后状态不被重置；落在输出采样点之间的事件仍准确执行；无再启动事件时应完整保留关机结果。
2. **惰转独立解**：关闭所有液压负载，采用线性黏性损失时，与 `ω(t)=ω0 exp(−b t/J)` 对比；核查零速行为及动能账本。此检验验证数值和方程实现，不标定真机摩擦。
3. **密闭壁流换热**：隔离端口与外热时，流体和壁面总能量保持，最终趋向共同热平衡；比较独立平衡解。
4. **排放与反流极限**：等压零流；双向口交换两侧状态后流量符号反转；单向阀反压关闭；出流焓与实际上游一致；库存不得因输出裁剪而变为负数。
5. **开放系统守恒**：质量、元素（有物种时）、流体/壁面能量、转子机械能分别检查；用独立后处理积分检查主要通量，避免状态与账本共享错误而共同“通过”。
6. **全过程记忆**：两次完全相同的开阀命令，若停留时间或前序热状态不同，应得到由方程决定的不同响应；不能复制首次曲线。
7. **数值与适用域**：缩小容差/步长，比较关键峰值和事件时刻；低库存、相态越界、泵图超域、反流及零速应有明确行为；超域停止保留最后有效状态。
8. **实验层验证**：后续引入对应装置的阀位、压力、流量、转速、壁温、排放质量和点火观测，并报告传感器时延、采样率、边界及参数不确定度。用于拟合阀序或摩擦的测量不能再次算作独立验证量。

## 6. 参数来源与后续耦合条件

所有缺少实测数据的容积、泵图、转动惯量、摩擦、阀时间常数、泄漏、热容量、热导和事件时间应标记为研究示例或工程假设。不能冠以用户所选参考发动机的真实关机参数。

完整液体发动机关机与再启动还需要：与具体循环一致的多支路拓扑、供给端有限库存、泵/涡轮在低速和两相工况下的适用模型、气液相选择性排放、非凝气吹除、真实阀泄漏与止逆机构、壁面空间热状态、气液喷注和燃烧耦合，以及有数据支持的再次点火与熄火判据。逐步加入这些能力时，应保留当前独立子模型的来源记录和验证边界。
