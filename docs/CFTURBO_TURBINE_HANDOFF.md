# 涡轮初步设计与 CFturbo 建模交接

核查日期：2026-11-07。适用于液氧甲烷全流量补燃循环中的富氧涡轮与富燃涡轮。本文区分循环记录、交互式均径初选和 CFturbo 详细设计；软件许可、菜单和气体库仍须按实际安装版本核对。

## 设计点如何确定

两侧分别使用各自预燃室出口燃气的质量流量和状态，以及各自轴系的转速与功率需求。涡轮燃气流量不等于同轴纯推进剂主泵流量，泵的级数也不决定涡轮级数。涡轮排气还要满足后续管路、喷注器与主燃烧室的压力需求，压比不能脱离循环独立任意选择。

CFturbo 的 Gas turbine 全局设计点输入为质量流量、转速、总总压比或总静压比；同时给定入口总压、总温及气体模型。[Global setup](https://manual.cfturbo.com/en/global_setup.html)

| 交接量 | 定义与要求 | 平台来源 |
|---|---|---|
| 质量流量 `ṁ` | 涡轮燃气流量，kg/s | 同记录涡轮部件输出 |
| 转速 `n` | rpm，与对应主泵轴系匹配 | 同记录轴系设计点 |
| `pt,in`、`Tt,in` | 明确入口截面的总压与总温，使用绝压 | 仅在记录明确总总接口约定后提供 |
| `πtt` | `pt,in / pt,out` | 已确认总态边界的压力比 |
| `πts` | `pt,in / p,out`，出口为静压 | 当前未解析出口速度与静压，保留缺项 |
| 功率 | 区分等熵参考、实际燃气做功、轴端输出及负载 | 循环功率对账与独立损失预算 |
| 气体 | 完整组成、组成基准、EOS、温区物性 | 保存的燃气与物性快照 |

Global setup 的项目入口可能位于首静叶之前；动叶入口则位于静叶之后。静叶造成的速度变化和损失必须由相邻部件接口传递，不能把全局入口条件无条件复制为每一叶排入口。[主尺寸与相邻部件](https://manual.cfturbo.com/en/md_dimensions_axturbine.html)

历史记录中的节点 `p/T` 若未定义总静态，不会被自动改名为 `pt/Tt`。若新方案采用零维总总储腔接口近似，应显式选择该约定并运行新记录；登记接口假设不等于执行了总静转换。已有历史记录的节点温压仍保留原义。

## 富氧、富燃气体分别交接

使用各自完整保存组成，不使用空气、液氧或液态甲烷替代预燃后的燃气。CFturbo 可在气体管理器中按组成定义混合气，气体模型、混合规则及热力数据应与循环模型核对。[气体混合物](https://manual.cfturbo.com/en/gas-mixtures.html)、[物性模型](https://manual.cfturbo.com/en/preffluids.html)

平台当前保存冻结组成、温度相关比热的 Cantera 理想气体混合物。11 点物性表在固定入口压力下采样，并非沿程流动轨迹；高压非理想性尚未由这一模型验证。交接时重点核对质量/摩尔分数、分子量单位、`cp(T)`、气体常数、焓熵基准、密度和黏度。若 CFturbo 使用其他 EOS 或常比热近似，应重新比较进出口状态、等熵焓降和实际功率，而非仅比较入口 `cp`。

## 三类功率与效率

`PQ = ṁ Δhs` 为等熵参考功率；`Pgas = ṁ Δha` 为实际气体做功。若另外建立机械效率预算，则 `Pshaft = ηm Pgas`，并与同轴负载核对。当前 FFSC 循环直接将气体实际功率匹配同轴主泵，未单列轴承/密封机械损失。

系统整台等熵效率、叶排/转子效率、机械效率、CFturbo 附加非典型流动损失效率分别有独立含义。不得将系统效率复制到每一级、机械效率或附加效率；同一损失也不能同时计入多个预算。[涡轮参数与效率](https://manual.cfturbo.com/en/md_parameter_axturbine.html)

## 交互式方案初选

“方案初选”借用所选记录的质量流量、转速和实际比功，允许独立比较级数、中径、轴向流量系数、反动度约束、级功分配、首静叶入口旋流、静/动叶轴向弦长与 Zweifel 目标。用户在页面明确这些假设后计算；该过程不改变原计算记录、当前整机草稿或循环匹配结果。

方案结果与源记录绑定，下载文件保留源记录、输入假设、方法及缺项。未计算或修改参数后的旧结果不能视为当前方案结果。方案不会作为新的整机计算记录永久保存，需要留存时下载方案文件。

### 均径运动学

各级采用同一中径 `Dm` 与同一轴向速度 `ca`。正切向与转动同向，流角自正轴向量起。给定转速 `n`、流量系数 `φ`、每级实际比功 `L` 和约束 `R*`：

```text
U = π Dm n / 60
ca = φ U
cu1 = U(1 − R*) + L/(2U)
cu2 = U(1 − R*) − L/(2U)
wu1 = cu1 − U
wu2 = cu2 − U
α = atan2(cu, ca)
β = atan2(wu, ca)
L = U(cu1 − cu2)
```

这里 `R* = 动叶静焓降 / 级欧拉比功`。只有重复级 `c0² = c2²` 时，它才等于以整级静焓降为分母的反动度。对任意首级旋流，分别计算：

```text
Δhrotor,static = L − (c1² − c2²)/2
Δhstage,static = L + (c2² − c0²)/2
Rstage,static = Δhrotor,static / Δhstage,static
```

首静叶入口 `cu0` 是显式方案输入；后续静叶入口承接前一动叶出口。无功静叶下的静焓变化可由速度平方差给出，但这不确定静叶损失、压力或温度分布。分母无效、反向静焓变化等情况应保留诊断，不通过截断数据伪造合理反动度。

各级实际比功之和应等于源记录实际比功，阶段气体功率为 `ṁ L`，对应气动力矩为 `ṁ L/ω`。这些是约束下的代数闭合，不是损失模型预测出的效率或经试验确认的轴端输出。官方 CFturbo 主尺寸也使用欧拉方程、连续方程和速度三角形，但其完整设计步骤比本局部初选更广。[轴流主尺寸计算](https://manual.cfturbo.com/en/md_dimensions_axturbine.html)

### Zweifel 叶片数候选

采用二维不可压叶栅的 Zweifel 负荷关系。对从轴向定义的带符号入口/出口流角 `θin`、`θout`，取切向载荷的大小：

```text
σx = 2 cos²(θout) |tan(θin) − tan(θout)| / Zw
z* = π Dm σx / cx
s = π Dm / z
σx,integer = cx / s
Zw,integer = 2 cos²(θout) |tan(θin) − tan(θout)| / σx,integer
```

`cx` 为轴向弦长，`s` 为节距，`σx` 为轴向稠度。动叶使用相对流角 `β`，静叶使用该静叶自身的绝对入口/出口流角 `α`。连续叶片数 `z*` 取整数后必须回算实际对应的 Zweifel 值；整数候选仍需动静干涉、气动及结构校核。零转弯或退化输入不能生成任意叶片数。

关系依据为 NASA-CR-191164 *Blading Models for TURBAN and CSPAN Turbomachine Design Codes* 的式 (1)，这里写成与本平台带符号角度一致的等价形式。它只给出二维载荷初估，不提供本工况高马赫数、厚度、端壁、间隙及二次流修正。[NASA 原始报告](https://ntrs.nasa.gov/api/citations/19940006731/downloads/19940006731.pdf)

CFturbo 手册同样将 Zweifel 方法作为轴流涡轮叶片数提示。手册中的常见叶片数及经验系数范围不是本两台涡轮的定型值；系数与轴向弦长仍是要说明依据的设计选择。[CFturbo 叶片数](https://manual.cfturbo.com/en/bladeprop.html)

### 流角与 CFturbo 角度约定

平台以轴向为角度零点并保存符号。CFturbo 手册的 `αF/βF` 相对周向定义，而且相对速度切向分量的符号约定与本平台表达不同。交接时应使用速度分量、转动方向和参照方向复核角度，不能按同名字段直接复制。流角也不等于叶片金属角；入射角、落后角及叶片排挤尚需单独处理。[CFturbo 角度及速度定义](https://manual.cfturbo.com/en/bladeprop.html)

## 为什么暂不生成定量叶高与叶片实体

通流面积应满足 `ṁ = ρstatic ca A`；圆环在中径定义一致时有 `A = π Dm b`。这里必须使用截面的静态密度。总态密度、任意节点密度及冻结组成温区采样密度都不能直接替代局部静态密度。

同理，马赫数使用局部静温下的声速；总静转换需要气体 EOS、焓关系和速度，压力分配还需要损失模型。仅有 Euler 三角形不能确定这些量，更不能证明喉部不壅塞。当前交互初选不计算逐级静压/静温、马赫数、叶高、壅塞、损失、金属角或三维叶片实体。这些缺项仍可在交接清单中逐项检查。[CFturbo 流动状态与壅塞检查](https://manual.cfturbo.com/en/md_dimensions_axturbine.html)

现有概念环道属于独立历史快照。图形示意、速度三角形和分级流程不能冒充具有可靠静态通流面积的整机装配。

## 在 CFturbo 中继续设计

1. 分别固定富氧、富燃的来源记录和设计任务，确认入口/出口截面与总静态定义，检查全局功率匹配。
2. 录入全局设计点，并建立对应混合气；用保存温区物性和焓降核对气体模型。
3. 选择实际的轴流方案和级数，分配逐级功率，明确静叶与动叶接口。CFturbo 的多级功率分配必须与全局目标一致。[多级设计](https://manual.cfturbo.com/en/md_multistage.html)
4. 使用均径候选作为对照，完成进出口环道、轮毂比及静态通流校核。轴流涡轮可选择 `Rocket engine` 转子类型，实际使用依安装版本和许可；该选项不代表详细设计已验证。[轴流设置](https://manual.cfturbo.com/en/md_setup_axturbine.html)
5. 完成展向速度分布与径向平衡、前后缘、静/动叶叶片数、中弧线、厚度及间隙；复核流角与金属角的区别。[展向速度设计](https://manual.cfturbo.com/en/cucm-specification-ml.html)、[叶片厚度](https://manual.cfturbo.com/en/prof.html)
6. 结合 CFD、结构/振动及热分析核对性能与裕度，再回传部件特性、几何版本和适用工况。局部方案 JSON/CSV 和循环任务书属于设计交接资料，不是 CFturbo 原生工程或详细模型验收证明。

## 简化工程筛查

原记录的材料筛查采用离心应力量级 `σ ≈ ρmaterial U²`，并以保存温度假设下的材料屈服强度计算强度比。交互方案改变中径后，程序不复制原强度比，而以新圆周速度对这一简化模型重新缩放：

```text
σscenario = σsaved (Uscenario / Usaved)²
SFscenario = σyield,saved / σscenario
```

这一缩放沿用原记录的材料密度、屈服强度和温度假设，仅用来观察轮速变化对离心应力量级的影响。原模型将入口气温用于材料性能取值，不等于已求得真实金属温度；没有新轮盘、轮缘、叶根、叶片截面、应力集中、热应力、蠕变、振动或疲劳计算。修改级数和中径后，真实结构几何也可能改变，不能以这一比例关系代替结构分析。

结果统一为“需复核”，不会因为 `SFscenario ≥ 1` 就显示结构通过；低于 1 时提示重新审查初选。缺少保存的材料、应力或轮速依据时保留缺项，不重新查询当前材料库来补造历史材料结果。

## 与平台既有功能的关系

旧的可选均径模式在运行整机时按保存输入生成记录附属初选；新的交互方案在已保存记录之上比较局部候选。两者均不通过叶排损失模型自动改写循环效率。原记录工程指标与新方案缩放结果分别显示，后者也只是一项基于既有假设的筛查。
