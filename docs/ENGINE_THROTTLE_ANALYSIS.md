# 发动机节流分析：设计匹配、局部估算与完整固定硬件求解

本页定义“工况与运行”中的发动机节流分析。当前可运行模型为**基准标定局部节流估算**：从一个已保存且通过源结果检查的 FFSC 设计点标定集总部件关系，在扫描过程中保持这些关系和喷管几何不变，求解新的稳态平衡。它不调用概念设计的温度反求入口，也不在每个工况重新设计泵、涡轮或喷管。

完整的 `fixed_hardware_steady` 任务仍保留独立的数据完整性和模型接入门槛。局部估算数值收敛不会解除这些门槛，不能据此宣称发动机已经具有经过验证的节流包线。

## 三种计算的边界

| 计算 | 用途 | 可以变化的量 | 结果含义 |
|---|---|---|---|
| 概念设计 / 旧设计匹配扫描 | 寻找满足设计要求的方案 | 由设计求解选择的分流、温度目标及部件估算量 | 不同要求下重新匹配的设计结果 |
| 基准标定局部节流估算 | 同一个基准模型附近的运行趋势研究 | 两侧供给等效通流系数比，以及由稳态方程求出的状态、转速和流量 | 有明确假设的降阶模型预测 |
| 完整固定硬件稳态 | 已定义发动机的非设计点运行分析 | 实际执行机构控制量和运行边界；状态量由闭合方程确定 | 还需固定几何部件模型、特性和约束证据 |

旧扫描保留其原始计算记录和算法身份。不能将历史“设计匹配”结果改名后作为新算法的性能曲线，也不能用旧扫描填补新计算失败的工况。早期文档中“固定选定几何与四支路阻力的重匹配”描述的是旧算法的有限冻结范围，不代表完整发动机固定硬件。

桌面客户端的入口统一标为“设计匹配扫描（旧）”，点击后只说明旧计算已停用并引导至 Web 的“工况与运行 → 发动机节流分析”；不再调度旧扫描任务，也不清空历史表或曲线。新算法结果不写入桌面旧扫描数据结构。

## 节流百分比及基准

节流指令定义为：

```text
command_percent = 100 × F_target / F_reference
achieved_percent = 100 × F_solved / F_reference
```

`F_reference` 采用所选计算记录的实际已求解推力，不采用输入框中的设计推力目标，不读取当前尚未计算的方案修改。环境压力和推力口径随基准一起固定；不能将海平面推力百分比和真空推力百分比混用。100% 点用于检查新模型能否重现其标定来源。

请求推力与实际达到的推力分别保存。推力误差、总氧燃比误差、方程残差和计算域状态共同决定一个工况能否作为有效估算点。没有满足控制目标的数值点不应画成成功性能点。

NASA 将液体火箭发动机节流表述为相对于 100% 额定功率级的推力变化，并讨论了通过阀门调节来控制推力与混合比的实例；这支持上述指令口径，不表示本项目采用了某台实机的控制规律。[NASA：A Historical Systems Study of Liquid Rocket Engine Throttling Capabilities，正文第 2、8 页](https://ntrs.nasa.gov/api/citations/20100033271/downloads/20100033271.pdf)

## 求解模型与未知量

复用 `src/lre_workbench/operations/transient.py` 中 `HotStateModel` 的质量、热内能及轴动能方程，求取其稳态平衡，而不是将瞬态积分末尾的任意时刻当作稳态。FFSC 有三个燃气容腔：主室、富氧预燃室、富燃预燃室；有两根轴：氧侧与燃料侧。

八个物理状态为三个容腔的质量和热内能，以及两根轴的动能。内部平衡模型使用相对基准的归一化库存状态：

```text
x_state = [m_main/m_main0, U_main/U_main0,
           m_OPB/m_OPB0,   U_OPB/U_OPB0,
           m_FPB/m_FPB0,   U_FPB/U_FPB0,
           K_ox/K_ox0,     K_fuel/K_fuel0]

T_i = U_i / (m_i cv_i)
p_i = m_i R_i T_i / V_i
N_j / N_j0 = sqrt(K_j / K_j0)
```

非线性求解器实际使用三个容腔的压力比、温度比，两根轴的转速比，以及氧侧和燃料侧两个供给等效通流系数比的自然对数，共十个未知量。取指数后按 `m/m0=(p/p0)/(T/T0)`、`U/U0=p/p0`、`K/K0=(N/N0)^2` 转换到库存状态；这样保证试探压力、温度和转速为正。十个闭合条件为：

```text
三个容腔：dm_i/dt = sum(mdot_in) - sum(mdot_out) = 0
三个容腔：dU_i/dt = sum(mdot_in h_in) - sum(mdot_out h_out)
                    + Q_effective - P_extracted = 0
两根轴：  dK_j/dt = eta_local,j P_turbine,j - P_pump,j = 0
控制目标：F_solved - F_target = 0
控制目标：mdot_ox / mdot_fuel - MR_reference = 0
```

预燃室温度是上述方程的输出。模型不会把富氧或富燃预燃室的设计温度作为每个节流点必须维持的等式条件。若今后加入真实温度闭环控制，必须同时给出相应执行机构、控制权限及限位，不能用温度反求分流替代硬件通流关系。

瞬态模型另有两个守恒积分账本状态。这两项不是独立稳态状态，不加入八个状态未知量，也不将瞬态的累计库存变化误差当作稳态闭合指标。

质量残差按基准流量归一化，能量残差按基准热功率归一化，轴残差按基准轴功率归一化；推力和混合比按各自基准归一化。这样稳态验收不依赖任意容腔容积或转动惯量选值。物理量残差仍须保留，以便核查其数量级。

## 单点标定关系

### 泵与液体支路

泵压升采用在基准点经过标定的下降型二次关系：

```text
dp_pump = dp0 [(1 + s) (N/N0)^2 - s (mdot/mdot0)^2]
P_pump = P0 (mdot/mdot0) (dp_pump/dp0)
mdot_branch = C_branch × a_side × sqrt(max(p_pump_out - p_destination, 0))
```

`s` 是明确保存的曲线斜率假设，`C_branch` 从基准流量和供给压差标定。该系数集中了液路、冷却和喷注器的有效损失；同一种推进剂通往两座预燃室的支路同时乘以 `a_side`。

因此，`a_side` 只能解释为**供给等效通流系数比**。它不是阀门开度百分比，不是实际阀门的面积比，也不是已测得的行程限位。基准值 1 表示标定点的通流能力。调整这个系数是当前降阶控制模型的假设，不能据此声称全部液体供给硬件已经冻结并完成建模。

主泵入口压力采用来源记录中的值作为固定边界。前置增压泵、贮箱至主泵的管路及其运行变化没有在该局部估算中重新求解。

### 涡轮与燃气

涡轮使用包含临界与非临界分支的理想气体等熵流通关系。有效流通面积和有效做功系数在来源点一次标定，扫描时保持不变；出口背压用来源的涡轮出口与主室压力比例连接到当前主室状态。该比例是集总假设，不能替代真实主室热气喷注器的非设计点特性。

泵效率、涡轮做功系数、轴传动系数均为局部等效系数。单点标定不能识别完整效率曲面、流量极限或机械损失分解。源结果中极小的轴功数值残差可按原模型容差处理，不允许用大幅系数修正掩盖不闭合的来源。

燃气 `cp`、`R`、`gamma` 和液体热焓近似冻结在基准附近；预燃室有效热释放按其受限反应物流量变化，主室有效热释放按来流变化。这是局部热释放斜率模型，没有重新求解化学平衡或真实低温流体热力状态。基准回归精确不代表变工况组成或温度已经得到独立验证。

### 喷管与推力

主喷管喉部面积、出口面积和标定流量系数保持不变。当前局部模型的推力采用冻结真空推力系数：

```text
F = Cf_vac,0 × pc × At - pa × Ae
Isp = F / [(mdot_ox + mdot_fuel) × g0]
```

比冲只对通过稳态质量闭合的工况报告。喷管壅塞检查是该表达式的必要条件；它不证明喷管内流始终附壁，不覆盖过膨胀分离、侧载或冷却效应。

## 冻结、约束与计算域

每次扫描绑定来源记录、其实际输出、标定参数和喷管几何。每个工况共用同一份标定模型；不能在每个新工况重新标定一次，否则又会退化为设计重匹配。扫描设置及来源指纹应随结果保存。

当前局部模型对三个容腔的 `p/p0`、`T/T0`、两侧 `N/N0` 及两个等效通流系数比使用 0.65–1.35 的计算保护范围，并要求喷管维持壅塞。这些界限基于研究降阶模型的保护策略，是防止远离标定点的计算保护，**不是经过试验确认的有效域或发动机安全运行范围**。求解器试探边界略宽于报告范围，以识别“可数值闭合但越界”的候选解；试探允许不等于接受该性能点。

因此，用户提出 40% 推力并不意味着算法能够有效计算到 40%。无法在保护范围内满足平衡及控制目标的点必须保留失败或域外原因，不能靠增大保护范围、插值补点或回退旧设计求解获得“成功”曲线。

温度、转速等真实运行限值若在来源中有明确依据，可以对求得结果另行检查；缺少限值证据时保持待评估。数值收敛、处于计算保护范围、满足设计约束和硬件运行可行是不同结论，不应合并为一个“通过”。

## 应展示的结果

有效工况可以展示目标及实际推力百分比、推力、比冲、主室压力、总氧燃比、两侧流量与轴转速、两座预燃室压力与温度、泵出口压力与功率、涡轮功率，以及两侧等效通流系数比。曲线必须来自这些已求得数据，保留失败点的断点，不连成假想的完整包线。

同时保存质量/能量/轴功残差、控制目标误差、数值状态、模型保护域状态与模型假设。未收敛、域外的点可展示原因及数值诊断，但不能作为有效性能点参与曲线统计。范围内的数值解若超过保存的温度上限，仍可用于观察模型预测趋势，但必须显示超限原因，不能视为满足运行约束的可用工况；暂定上限与有依据上限分别显示。

本模型不应输出“已通过”的壁温、冷却裕度、汽蚀裕度、失速裕度、转子强度、喷管分离侧载、实际阀位或实机最小稳定推力。这些量需要相应部件与验证模型；不能复制基准值后伪装成节流点预测。稳态求解也不覆盖起动、关机、节流过渡或动态稳定性。

## 到完整固定硬件分析的路径

`webapp/fixed_steady.py` 和 `webapp/steady_model_contract.py` 继续要求实际部件身份及连接、泵和涡轮特性、阀门流量规律与限位、主室热气喷注器流通数据、固定冷却通道热水力模型、物性/焓参考约定、轴系损失及运行限制。登记了文档或单点标定值也不等于相应物理模型已经接入。

后续可以使用已验证的特性图，也可以使用基于冻结几何且经过验证的部件非设计点模型；不必强制只有试验特性图一条路径。NASA 的 PUMPA/NPSS 工作给出了将泵平均流线非设计点模型与整机循环迭代耦合的实例。[NASA/TM-2000-210574：Mean Line Pump Flow Model in Rocket Engine System Simulation，正文第 1–2 页](https://ntrs.nasa.gov/api/citations/20000120590/downloads/20000120590.pdf)

完成上述接入后，再由实际执行机构调节求解推力/混合比目标，并按每个部件的有效域和运行约束判断可达工况。当前局部估算为这个过程提供可追溯的趋势研究入口，不替代其证据要求。
