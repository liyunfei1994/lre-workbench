# 主泵初步几何：依据、定义与使用范围

核查日期：2026-10-28。对象为液氧主泵与甲烷主泵的系统级初步几何。

## 平台应交付什么

系统设计点能够给出流量、压升、入口状态、轴转速和级数，但这些条件不能唯一确定叶轮。适合当前平台的下一步是：从保存的设计点生成可追溯的**代表级径向叶轮主尺寸与子午流道**，提供二维尺寸图、三维旋转流道和坐标文件，供后续部件设计修改。

叶轮的轮毂比、速度系数、轴向尺度等仍是设计选择，必须显示其定义和来源。起始示例值不能称为优化结果、NASA推荐值或某发动机真实尺寸。旋转流道不包含经过设计的叶片、轮毂实体、轮盖厚度、诱导轮、扩压器、蜗壳、级间回流道、轴承和密封。多级泵的等扬程代表级也不能当作已经完成的多级装配。

NASA SP-8109讨论了转速、吸入性能、级数、叶轮和机壳之间的设计权衡；前言明确这类专著是设计指南，除非项目规格另行采用，并非NASA强制要求。SP-8110的主题是**涡轮**，不应作为泵眼径或出口宽度公式的直接依据。[NASA SP-8109](https://ntrs.nasa.gov/citations/19740020848)、[NASA SP-8110](https://ntrs.nasa.gov/citations/19740026132)

## 系数必须带定义

以下是本平台初算的明确约定，并非复刻CFturbo内部全部算法：

| 量 | 初算定义与边界 |
| --- | --- |
| 入口体积流量 | `Q1 = mdot / rho_in`；密度来自相同保存工况 |
| 水力参考扬程 | `H = delta_p / (rho_in g)`；这是入口密度不变近似，不等于真实流体等熵焓升除以g |
| 代表级扬程 | `H_stage = H / Z`；等扬程分配为本期假设 |
| 本平台压头系数 | `psi = g H_stage / u2²` |
| 出口叶尖速度与直径 | `u2 = sqrt(g H_stage / psi)`，`D2 = 2 u2 / omega` |
| 入口速度系数 | 若使用 `k1 = cm1 / u2`，必须写明分母是**出口**叶尖速度，不能标成NASA的入口流量系数 `phi1 = cm1 / u1` |
| 出口流量系数 | `phi2 = cm2 / u2`；不能与 `Q / (omega D2³)` 等其他流量系数混用 |
| 眼径与入口轮毂比 | `nu = D1h / D1s`，`Q1 = cm1 pi (D1s²-D1h²)/4` |
| 径向出口宽度 | `Q2 = cm2 pi D2 b2`；若初算取 `Q2 = Q1`，应标注恒密度、无泄漏、未计叶片排挤的通流面积假设 |
| 比转速 | `nq = n[rpm] sqrt(Q[m³/s]) / H_stage[m]^0.75`；不能与美制或无量纲比转速数值直接比较 |

CFturbo官方参数页使用 `Psi = Y / (u2²/2)`，还允许选择考虑效率的 `Y_eff`。当两边采用相同的 `Y = g H_stage` 时，**CFturbo的Psi等于本平台psi的两倍**。例如本平台0.50对应1.00；不能把0.50不经转换填入对方同名字段。该转换只统一定义，不证明其他设计假设一致。[CFturbo主尺寸参数](https://manual.cfturbo.com/en/md_parameters_pumpvent.html)、[官方公式图片](https://manual.cfturbo.com/en/embim27.png)

CFturbo把系统设计点、主尺寸、子午流道和叶片设计分为不同步骤；轮毂直径需要结合轴毂连接确定。其设计点输入采用Q/质量流量、扬程/总压差及转速，多级能量增量应与整泵一致。导出时须交代本平台压力节点未解析端口速度，因此 `delta_p/(rho_in g)` 是水力参考，不能擅称已得到完整总压扬程。[设计点定义](https://manual.cfturbo.com/en/global_setup.html)、[主尺寸](https://manual.cfturbo.com/en/md_dimensions_pumpvent.html)、[子午流道](https://manual.cfturbo.com/en/mercon.html)

## 必须保留的工程边界

- 眼径初算满足面积连续性，不代表汽蚀合格。NASA SP-8109第2.3.1节将入口流量系数与吸入性能联系；泵的可用NPSH不能替代所需NPSH。诱导轮与主叶轮入口也不是同一个截面。
- 轮毂比与轴向长度可以作为少量可编辑假设；绘图需要的平滑曲线仅是几何构造，不是求解出的三维流线。
- 单一比转速区间不能证明某方案最优。直径、转速、叶片角、叶片数、泄漏和效率仍需后续联合设计。
- 图示与导出应采用同一份坐标，并保留源计算记录和假设；切换历史记录不能把当前草稿参数注入旧几何。
- 大直径或高速度不能静默裁剪成“合理值”。应保持 `u2 = omega D2/2`，对不成立的假设明确拒绝，对待校核的工程范围明确提示。

本次检查旧代码时发现 `src/geometry/pumps.py` 曾将D2裁到0.03—0.80 m，同时保留未裁剪u2，破坏速度—直径一致性；还存在密度、级数和系数的静默下限。新增几何链应使用有限、正值及整级数校验，不能依赖这些兜底生成外观正常的图。

## CAD交接的最小可用范围

建议输出尺寸/设计条件表、带单位的子午坐标CSV，以及轮毂与轮盖各一份纯数字TXT。CFturbo官方明确支持 `*.txt` / `*.cftcv` 的二维点导入：每行 `z,r`，轮毂和轮盖分别导入；这一接口只覆盖子午轮廓，叶片还需后续设计。导出文件的单位、轴向、原点和轮廓名称应随说明保存，实际导入后复核尺寸。[CFturbo二维点导入](https://manual.cfturbo.com/en/import_2dpointdata.html)

通用DXF多段线可用于CAD曲线重建；STL只表示三角网格，不具有可编辑的参数化实体特征。只有实际生成并验证了曲面/实体，才应提供STEP、IGES等导出。不以改扩展名方式生成 `.cft`、`.prt` 等专有项目。CFturbo有公开的几何交换和中性格式功能，但不意味着本平台已经完成与特定安装版本的导入验证。[CFturbo基础导出](https://manual.cfturbo.com/en/export_basic.html)、[官方几何导入格式](https://manual.cfturbo.com/en/import_external_geometry.html)

## 本期使用方法与实现

1. 在参数栏“泵转速与几何初选”中分别设定两侧转速、级数、压头系数、入口/出口速度系数、轮毂比和轴向长度比。速度系数0.10/0.08、轮毂比0.35和轴向比例0.30为可编辑的起始假设。
2. 运行设计点后，左侧“泵初步几何”显示该计算记录的结果。切换液氧主泵或甲烷主泵，查看二维子午面或可旋转、缩放、剖开的三维边界。
3. 尺寸表包括D2、D1s、D1h、b2、Lz、进出口面积与速度。系统点和几何假设可展开；记录固定其参数、曲线及校验值。修改草稿或刷新页面不会改写历史几何。
4. 可下载CSV、轮毂与轮盖各一份TXT、二维DXF、三维OBJ，以及包含尺寸/设计点/假设的JSON。坐标单位m，页面尺寸单位mm。DXF将轴向z映射到X、半径r映射到Y；OBJ采用Z轴旋转。OBJ是完整周向开口边界曲面，页面剖开不改变导出。

旧记录缺少这四项轮廓假设时，只显示其保存的泵设计点和已有外径，不补造曲线；明确新假设后需运行新记录。无效几何会保留不可用原因，不阻止已完成的整机结果展示，也不以截断尺寸伪造有效流道。当前只有液氧和甲烷主泵生成轮廓。压头系数现在由同一输入传到FFSC、GG主泵部件及几何模块；它影响尺寸诊断，不改变真实流体泵功方程。
