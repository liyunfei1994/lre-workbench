# 推进剂模型与适用范围

当前数字化平台固定采用 `lox_methane`：液氧／甲烷，全流量补燃循环（FFSC）。循环身份、推进剂身份及采用的热力学数据集随计算记录保存。

液相泵送与再生冷却采用实际工质物性；燃烧气体的组分、焓及膨胀过程沿用当前 FFSC 模型。物性数据集温区、高压理想气体近似与未验证范围在计算结果中分别说明，不因数值收敛而认定物性或实机性能已验证。

新建、导入、设计与研究计算均检查循环和推进剂身份。不支持的旧架构保留原始数据查看与导出，不重标为甲烷 FFSC，也不生成新的图纸或部件结果。

已有 FFSC 文件中不参与本循环的冗余参数在输入归一化时清理；其余物理设计参数、初值和约束保持原值。旧计算记录不自动重写，缺失状态不以当前默认值补造。

参考示例与参数证据见[FFSC 循环与参考机型](ENGINE_REFERENCES.md)，热力学适用范围见[热力学适用性](THERMODYNAMIC_APPLICABILITY.md)。
