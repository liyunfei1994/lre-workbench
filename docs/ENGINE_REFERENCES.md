# 循环术语、轴系与参考机型

Raptor 3 推力资料核对日期：2026-10-23；其他条目的核对日期为 2026-10-21。这里分别记录公开事实和本平台模型假设；参考机型名称不表示厂商完整模型或实测复现。

## 循环名称

界面使用“全流量分级燃烧循环（FFSC，闭式）”和“燃气发生器循环（GG，开式）”。“全流量”应保留完整名称；“开式”是分类属性，单独使用它不能唯一确定本平台的 GG 模型。

开式/闭式的区别在于涡轮工质最终是否进入主燃烧室：开式排气可通过独立喷管排出，也可在主喷管喉部下游引入；后者仍属于开式。FFSC 的富燃与富氧支路在驱动涡轮后进入主燃烧室，属于闭式分级燃烧。见 [NASA / Rocketdyne / Boeing，Propulsion System Choices and Their Implications，2010，V.D.1 节](https://ntrs.nasa.gov/api/citations/20110003599/downloads/20110003599.pdf)，以及 [ESA 对循环形式的说明](https://www.esa.int/Enabling_Support/Space_Transportation/First_hot_firing_of_European_staged-combustion_demonstration_engine)。引用旧文献仅用于循环定义，不沿用其中当年的服役、复用或技术成熟度判断。

## 轴系布局

循环类型与轴系布局是不同的设计维度。同一 GG 循环可以采用不同的泵/涡轮连接方式。本平台支持：

| 选择 | 当前求解器的含义 |
| --- | --- |
| 单轴：一台涡轮同轴驱动双泵 | 氧泵、燃料泵、涡轮共轴同转速；按合计泵功率匹配涡轮输出。当前轴速由氧泵侧参数决定。 |
| 双轴：两台涡轮分别驱泵（燃气并联） | 一个 GG 的燃气并联分配到两台涡轮，分别驱动氧泵和燃料泵；两轴分别匹配功率、分别确定转速。当前模型共用 GG 入口状态和涡轮背压。 |

这两项是本模型支持的拓扑，并非所有开式循环轴系的完整分类；双轴也不天然等于燃气并联。

SpaceX 明确公布 Merlin 1D 的氧泵、燃料泵和涡轮使用同一根轴，见 [Falcon User's Guide，2025-05-09，2.3 节，PDF 第 19 页](https://www.spacex.com/assets/media/falcon-users-guide-2025-05-09.pdf#page=19)。这是直接针对机型的厂商证据，故 Merlin 1D 的单轴属性可写入公开事实。Vulcain 家族可用于理解独立涡轮泵：[ESA 的 Vulcain-2 技术表](https://www.esa.int/esapub/bulletin/bullet102/Coulon102.pdf)列出氧、氢涡轮泵不同转速；[NASA 发动机循环课程，4.25 页](https://ntrs.nasa.gov/api/citations/20140002716/downloads/20140002716.pdf)明确示出 Vulcain Mk-1 的两台并联涡轮。[DLR 2024 年研究，3.3.1 节](https://elib.dlr.de/206596/1/s12567-024-00564-w.pdf)也采用类似 Vulcain 的并联双涡轮泵 GG 拓扑。

界面删除了“Merlin 布局”“Vulcain 2 布局”括注，直接显示模型连接关系。特别是 Vulcain-2 将涡轮排气引入喷管的设计，不等于本平台独立排气喷管的简化；不能仅因轴数相同就声称复现该发动机。

### Raptor 3 参考数据的版本与参数身份

本次推力依据为 [SpaceX，Introducing Starship V3，2026-05-12，Raptor 3 Change Highlights](https://new.spacex.com/updates)。该条公开说明分别列出海平面版本 250 tf 与真空版本 275 tf；本平台的海平面示例只采用前者。来源是带日期的厂商公开标称，不是由本模型计算或拟合所得的性能。

按标准重力加速度 9.80665 m/s² 换算，1 tf = 9806.65 N，250 tf = 2451662.5 N = 2451.6625 kN。保留换算小数是为避免重复取整，不代表厂商推力测量具有对应精度。此前通用输入默认值 2450 kN 与 250 tf 相差约 0.068%。本次只修改 `raptor3_ffsc` 参考示例的推力覆盖值；通用 `EngineInputs` 兼容默认值、已保存方案与历史计算记录不自动迁移。用户显式加载或恢复参考示例时，才采用新值。

| 示例字段 | 当前示例值 | 参数身份与证据边界 |
| --- | --- | --- |
| 海平面目标推力 `thrust` | 2451.6625 kN | 厂商 2026-05-12 公布的 250 tf，经标准单位换算；是本次唯一依据该公开资料更新的性能输入。 |
| 主室压力 `pc` | 33 MPa | 工程设计假设；未核实为与上述 250 tf 同口径、同构型配套的实机室压。 |
| 总氧燃比 `of_ratio` | 3.6 | 工程设计假设；氧与燃料的总质量流量比。 |
| 主喷管面积比 `expansion_ratio` | 34.34 | 工程设计假设；出口面积/喉部面积，不能与氧燃比 3.6 混淆。 |
| 比冲初始化 `target_isp` | 327 s | 数值初值，用于估算质量流量，不是公开实机性能目标，也不是验收指标。 |
| 入口温度、效率、预燃室温度、分流与压力损失、泵转速等 | 沿用当前示例 | 属于边界、设计假设、约束或初值；不能仅因采用了公开推力就升级为实机数据。具体作用须结合启用模式判断。 |

`ENGINE_REFERENCES["raptor3_ffsc"]["parameter_evidence"]` 保存上述主要参数的身份、来源日期与核对日期，与用户可编辑的方案输入分离。没有核实来源的字段明确标为工程假设或数值初值，不伪造来源。250 tf 与其他日期资料中的 280 tf 不应拼接为同一设计点；本次没有用二手解释断言两者分别对应试验峰值、额定降额或其他具体原因，也没有把另一版本的比冲、室压自动移入本示例。

因此，载入后计算得到的结果应称为“采用公开推力参考的 FFSC 工程示例结果”。数值收敛、守恒闭合与厂商数据验证是不同层级；本次参考数据更新不构成 Raptor 3 模型验证。

天鹊依据为 [蓝箭产品页](https://www.landspace.com/product.html?mao=1)和[蓝箭提交上交所的招股说明书申报稿，2025-12-31，1-1-210 页](https://static.sse.com.cn/stock/disclosure/announcement/c/202512/002174_20251231_1QK0.pdf)。后者的自有机型表明确标注 TQ-12A 的燃气发生器循环；本次未核实其精确轴系布局，不将当前单轴初值写成厂商已公开事实。Merlin 1D 的推进剂、循环及同轴关系依据上述 SpaceX 用户指南，而非第三方推测。

公开资料、工程假设和用户方案分开保存。煤油示例采用独立的 Cantera 正十二烷气相平衡与 CoolProp 正十二烷泵送/冷却物性；不以甲烷物性改名代替。它仍是单组分替代物，不等同于真实 RP-1 的多组分性质、结焦行为或实机性能。支持范围和热力学外推说明见[推进剂模型](PROPELLANT_MODELS.md)。
