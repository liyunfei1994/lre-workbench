# FFSC 循环与参考机型

当前数字化平台专用于液氧甲烷全流量补燃循环发动机。参考机型名称不表示厂商完整模型或实测复现；公开资料、工程假设和用户方案分开保存。

## 循环与轴系

富氧预燃室燃气驱动液氧泵涡轮，富燃预燃室燃气驱动甲烷泵涡轮；两路涡轮排气进入主燃烧室。燃料经过再生冷却后分配至两个预燃室。原理图中的机械连接表示功率传递，不表示实际安装位置。

Raptor 的循环依据为 [SpaceX 推进工程负责人向美国国会提交的证词，2015，印刷页 118](https://www.govinfo.gov/content/pkg/CHRG-114hhrg95320/pdf/CHRG-114hhrg95320.pdf)；当前 [SpaceX Starship 产品页](https://www.spacex.com/vehicles/starship/design)仍说明其甲烷/氧推进剂与分级燃烧属性。上述资料不用于推定 Raptor 3 的未公开支路参数。

### Raptor 3 参考数据的版本与参数身份

本次推力依据为 [SpaceX，Introducing Starship V3，2026-05-12，Raptor 3 Change Highlights](https://new.spacex.com/updates)。该条公开说明分别列出海平面版本 250 tf 与真空版本 275 tf；本平台的海平面示例只采用前者。来源是带日期的厂商公开标称，不是由本模型计算或拟合所得的性能。

按标准重力加速度 9.80665 m/s² 换算，1 tf = 9806.65 N，250 tf = 2451662.5 N = 2451.6625 kN。保留换算小数是为避免重复取整，不代表厂商推力测量具有对应精度。此前通用输入默认值 2450 kN 与 250 tf 相差约 0.068%。本次只修改 `raptor3_ffsc` 参考示例的推力覆盖值；通用 `EngineInputs` 兼容默认值、已保存方案与历史计算记录不自动迁移。用户显式加载或恢复参考示例时，才采用新值。

| 示例字段 | 当前示例值 | 参数身份与证据边界 |
| --- | --- | --- |
| 海平面目标推力 `thrust` | 2451.6625 kN | 厂商 2026-05-12 公布的 250 tf，经标准单位换算；是本次唯一依据该公开资料更新的性能输入。 |
| 主室压力 `pc` | 33 MPa | 工程设计假设；未核实为与上述 250 tf 同口径、同构型配套的实机室压。 |
| 总氧燃比 `of_ratio` | 3.6 | 工程设计假设；氧与燃料的总质量流量比。 |
| 主喷管面积比 `expansion_ratio` | 34.34 | 工程设计假设；出口面积/喉部面积，不能与氧燃比 3.6 混淆。 |
| 比冲初始化 `target_isp` | 327 s | 数值初值，用于估算质量流量，不是公开实机性能目标，也不是验收指标。 |
| 入口温度、效率、预燃室温度、分流与压力损失、泵转速等 | 沿用当前示例 | 属于边界、设计假设、约束或初值；不能仅因采用了公开推力就升级为实机数据。具体作用须结合启用模式判断。 |

`ENGINE_REFERENCES["raptor3_ffsc"]["parameter_evidence"]` 保存上述主要参数的身份、来源日期与核对日期，与用户可编辑的方案输入分离。没有核实来源的字段明确标为工程假设或数值初值，不伪造来源。250 tf 与其他日期资料中的 280 tf 不应拼接为同一设计点；本次没有用二手解释断言两者分别对应试验峰值、额定降额或其他具体原因，也没有把另一版本的比冲、室压自动移入本示例。

因此，载入后计算得到的结果应称为“采用公开推力参考的 FFSC 工程示例结果”。数值收敛、守恒闭合与厂商数据验证是不同层级；本次参考数据更新不构成 Raptor 3 模型验证。
