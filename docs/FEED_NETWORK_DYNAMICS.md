# 供给网络动态：模型合同、文献依据与验证要求

日期：2026-10-22。本文规定新增供给网络研究台的物理范围和可审计约定。文献页码均为本地 PDF 文件页码，从 1 开始。本文的公式是按一致 SI 单位与端口方向重新整理的模型合同，不是对任何论文的逐式复刻；论文中的工况、惯量和经验修正量不作为平台的实机标定数据。

本文不以文档存在证明功能已经实现或试验验证已经通过。具体能力以代码、运行记录、边界说明及验证结果为准；后续功能在第 9 节单独列出。

## 1. 本轮分析对象

本轮建立氧化剂和燃料两条独立供给回路，各自包含如下连接：

```text
固定压储箱 → 有惯性泵支路 → 有限容积液腔 → 有惯性阀门支路 → 固定背压边界
```

两条回路可以同步积分和对比，但尚未通过预燃室、主燃烧室或涡轮连接为完整发动机。泵转速来自用户规定的时间线，泵图返回压升和转矩负载；模型不由涡轮功率或启动装置自行算出轴速。因此，“从零转速开始的规定转速响应”属于供给部件试算，不是发动机自主启动预测。

设计记录提供工质、参考流量、参考泵压升及转速等尺度。密度和等温体积模量由 CoolProp HEOS 在来源入口温度、用户设置的液腔初压处计算，再在任务内冻结；用户改变初压后，由服务端重算并保存物性快照，不能直接在请求中任意改写物性。`liquid` 和 `supercritical_liquid` 均可表示本页支持的单相液体，后者在此表示压力高于临界压力、温度仍低于临界温度的压缩液体；气相、真正的超临界流体和两相状态不属于当前接口。

管长、管径、液腔容积、阀门动态、泄漏及泵图仍须明确来源，不能由一个稳态点唯一反演。默认解析泵图是用于方程与交互研究的演示特性，并非 Raptor、Merlin、天鹊或其他实机的四象限试验图。

参考体积流量 `Q0=来源质量流量/来源泵入口密度` 保持不变；本研究台的质量流量统一由液腔参考密度 `ρ0 Q` 换算。因此，本研究台参考质量流量 `ρ0 Q0` 可以与来源发动机质量流量不同，记录中应同时保留来源质量流量、来源入口密度及本研究台冻结物性。该近似不能复现真实泵前后密度和温度的变化，也不能据此解释成原发动机已经发生质量不守恒。

这里与已有“热态瞬态响应分析”保持独立。该研究台采用自定义固定背压建立子系统初态，不能据此消除来源 FFSC 设计中的交叉供给欠压，也不应将子系统的通过状态回写成整机约束通过。

## 2. 状态、方向和单位

每条回路的动态状态至少包括：泵支路体积流量 `Qp`、液腔绝对压力 `pc`、阀门支路体积流量 `Qv` 和实际阀门开度 `a`。积分累计流量、边界功或耗散是守恒审计的附加状态，不代替上述物理状态。

| 量 | 单位 | 正方向或定义 |
|---|---|---|
| `Qp` | m³/s | 储箱至液腔；允许为负 |
| `Qv` | m³/s | 液腔至固定背压边界；允许为负 |
| `p` | Pa | 所有输入和相态检查均使用绝对压力 |
| `ω` | rad/s | 指定轴正转方向；`ω = rpm × 2π/60` |
| `Δpp` | Pa | 泵沿储箱至液腔方向施加的压升，可为负 |
| `τp` | N·m | 外部驱动轴需要施加给泵的负载转矩，可为负 |
| `ρ0` | kg/m³ | 来源入口温度、所设液腔初压处的参考液体密度，全回路冻结 |
| `LQ` | kg/m⁴ | 流体惯性；不是电感，也不是质量流量形式的惯性系数 |
| `C` | m³/Pa | 液腔液压容性 `V/K` |

正流量、正转速并不自动表示正压升；同样，负流量并不一定意味着能量回收。工况性质必须结合 `Δpp × Qp` 与 `τp × ω` 的符号判定。

## 3. 管路惯性、带符号阻力与库存

### 3.1 支路动量

对定截面、冻结密度的液体支路：

```text
LQ = ρ0 × length / area
ΔpR = R × Q × |Q|,  R ≥ 0

Lp × dQp/dt = ptank − pc + Δpp(Qp,ω) − Rp × Qp × |Qp|
Lv × dQv/dt = pc − pback − Rv × Qv × |Qv| − Δpvalve(Qv,a)
```

上述阻力在反流时自然换向，耗散 `ΔpR × Q = R × |Q|³ ≥ 0`。不能使用无符号 `R Q²` 后再将负流量裁剪为零。若选择积分质量流量，必须同时转换惯性系数，不能将 `ṁ` 直接代入上述体积流量公式。

本轮是集总低频网络，没有管路空间网格，也没有沿管传播的局部波动解析。阀门快速关闭所得集总压力变化不应标成已经验证的水击峰压。

### 3.2 有限液腔

固定几何体积 `V`、等温小压缩、体积模量 `K > 0` 下：

```text
C = V/K
C × dpc/dt = Qp − Qv
m(pc) = ρ0 × [V + C × (pc − pc,initial)]
dm/dt = ρ0 × (Qp − Qv)
```

质量库存中的压力项代表固定容积内的线性密度变化，不是液位变化或几何体积膨胀。供给及排出质量流量按相同的 `ρ0 Q` 口径计算，才能使线性化库存与通量一致。

必须限制 `|(pc−pc,initial)/K|`，并保证正库存与压力有效域；不能把大幅排空仍描述成充满液体的线性容腔。若达到两相、空腔或物性边界，应保留已完成结果并报告停止原因，而不是把压力钳制到一个可继续绘图的值。

### 3.3 默认参考点闭合

令参考泵压升为 `Δp0`、参考流量为 `Q0`。研究台可以使用以下明确标记的演示阻抗分配：

```text
pback = ptank + 0.25 Δp0
pc,initial = ptank + 0.95 Δp0
泵支路参考损失 = 0.05 Δp0
出口管路参考损失 = 0.07 Δp0
阀门参考损失 = 0.63 Δp0
```

在参考转速、参考开度及 `Qp = Qv = Q0` 时：泵侧 `Δp0−0.05Δp0 = 0.95Δp0`；出口侧可用压差 `(0.95−0.25)Δp0 = (0.07+0.63)Δp0`。因此默认子回路初态能够同时满足两条动量方程和液腔库存方程。

这组比例是建立可复核研究初态的工程假设，不是实机管损分配，也不是从原发动机的欠压支路反算得到的修复方案。用户修改背压、泵图或阀门后，应重新检查初始动量残差；非平衡初态需要如实显示。

## 4. 低速与反流泵图的合同

以正参考尺度 `Q0`、`ω0`、`Δp0`、`τ0` 定义：

```text
q = Qp/Q0
n = ω/ω0
r² = n² + q²
Δpp = Δp0 × r² × WH(θ)
τp = τ0 × r² × WT(θ)
```

当前代码约定 `θ = atan2(q,n) mod 360°`，即从正转速轴向正流量轴计角，`τ0 = Δp0 Q0/(η0 ω0)`。在 `n=q=1` 的参考点，`θ=45°`，`WH=WT=0.5`。导入界面、模板和结果应记录这套原点、转向及归一化。文献常写成 `π + atan(q/n)`；只有一个反正切分式不能唯一确定四象限，不能直接照抄为程序。导入图必须覆盖完整周期并保持周期接缝连续；其他角约定的图应先转换再使用。

`q = n = 0` 时直接定义零压升和零转矩，避免 `0/0`。低速转矩应从转矩图获得，不能由 `P/ω` 计算。四象限名称容易因作者而异，平台以数值符号为准：

| 转速与流量 | 研究情况 | 不能省略的检查 |
|---|---|---|
| `n > 0, q > 0` | 正转正流 | 压升、转矩、效率与泵图覆盖 |
| `n > 0, q < 0` | 正转反流 | 阻力方向、回流库存、泵功符号 |
| `n < 0, q < 0` | 反转反流 | 反转图数据与可能的液力驱动 |
| `n < 0, q > 0` | 反转正流 | 制动负载与回收功判断 |

能量检查采用：

```text
Pshaft = τp × ω
Phydraulic = Δpp × Qp
Ppump,diss = Pshaft − Phydraulic
```

本轮泵采用无内部储能的准稳态图，故不能持续出现超出数值容差的 `Ppump,diss < 0`。若图来自真实动态测量，其瞬时能量差还可能含内部储能，不能未经处理便塞入准稳态接口。周期性、平滑性和额定点吻合本身都不足以保证图在全象限物理可用。

当前默认解析演示特性为：

```text
Δpp = Δp0 [(1+s)n|n| − s q|q|]
τp = Δp0 Q0/ω0 [(1+s)|n|q + (1/η0−1−s)n|n|]
0 < s ≤ 1/η0 − 1

Ppump,diss = Δp0 Q0 [(1/η0−1−s)|n|³ + s|q|³] ≥ 0
```

这保证演示图在所有符号组合下有限、连续且耗散非负；不是对真实泵反转性能的预测依据。当前导入图采用周期闭合的线性插值，校验数据节点及插值区间的耗散，并核对参考点。角定义、周期端点、列单位、参考尺度、额定点、覆盖范围及能量一致性都需要检查；实际积分过程中也再次检查走过的工况。通过这些检查表示数据满足本模型合同，不表示四象限图已经完成试验验证。

来源稳态泵的效率数值来自其真实流体等熵焓升模型；本研究台借用该数值作为 `Δp0 Q0/Pshaft,0` 的参考效率尺度，是额外的等温液压近似。参考转矩及轴功由本页公式重建，不保证与原稳态记录中的真实流体泵功完全相同，不能标成实测转矩。后续可通过来源轴功或部件试验图建立独立的等效液压效率标定。

规定转速使外部驱动功率成为边界输入。若后续积分 `J dω/dt`，必须加入转子储能及涡轮/启动器/摩擦的机械端口，不能把当前泵负载转矩直接当成发动机加速方程。

## 5. 阀门执行机构与泄漏

阀门指令 `u(t)`、实际开度 `a(t)` 和有效流通面积 `CdA(a)` 是三个不同量。首版的一阶限速执行机构可写为：

```text
da/dt = limit[(u−a)/τact, −rate, +rate]
0 ≤ a ≤ 1
CdA(a)/CdA_full = leak + (1−leak)a
Δpvalve = ρ0 × Qv × |Qv| / [2 × CdA(a)²]
```

当前采用相同的开、闭速率上限；命令始终位于 `[0,1]` 时，该一阶方程保持实际开度区间不变，端点允许反向动作。积分精度检查还应确认数值结果没有超出行程。开闭速率、时间常数和指令插值方式均属于可追踪模型参数。

隐式积分器在初始化和内部迭代中可能试探行程外的数值，当前只对计算有效面积使用的开度做 `[0,1]` 连续延拓，避免试探态导致面积非正。真实开度状态和输出不裁剪，流量不裁剪；若接受的行程超过数值容差则通过事件终止。Radau 的初始步猜测不超过最小阀时间常数的十分之一，后续仍自适应选择内部步长。

关闭阀门若仍使用有限阻力，应显式给出泄漏有效面积或泄漏面积比，并保存到记录中；不能暗藏极小分母，然后将其称为理想严密关断。如果允许真正零面积，须采用相应约束或离散事件模型，不能在阻力公式中直接除零。阀门损失在反流时同样阻碍流动。

当前 `CdA(a)` 的演示关系不等同某一真实阀门的行程特性。没有执行机构或流量试验数据时，应标注为用户假设，不能借用论文阀门时间表宣称实现了同型机阀序。

## 6. 守恒审计与有效域

### 6.1 质量余额

各液腔及总研究边界分别核对：

```text
rm(t) = m(t) − m(0) − ∫ρ0(Qp−Qv)dt
```

反流保留其代数符号。累计正向供给、累计反向回流与净库存变化宜分开显示，避免净值抵消掩盖双向输运。

### 6.2 液压机械能余额

对于一条回路，选定统一参考压力 `pref`：

```text
E = 0.5 Lp Qp² + 0.5 Lv Qv² + 0.5 C(pc−pref)²
dE/dt = (ptank−pref)Qp − (pback−pref)Qv
         + Δpp Qp − Rp|Qp|³ − Rv|Qv|³ − Δpvalve Qv
```

当前代码统一采用 `pref=0 Pa`，即储能与边界功均使用绝对压力。选择非零参考压力时边界压力功必须同步减去该参考压力。不能在储能项中用表压、在边界功中用绝对压，否则会产生与库存变化成比例的假残差。

若采用轴功输入，还需减去 `Ppump,diss`，与上式等价。等温模型不积分泵/管/阀耗散造成的升温，耗散量作为离开液压机械能账本的热项记录。因此这里的通过状态应称为“集总液压机械能余额通过”，不能宣称整机热力学总能量守恒已由该研究台验证。

### 6.3 单相及部件图边界

- 绝对压力必须处于冻结物性与小压缩近似可解释的范围，液腔质量保持正值。
- 体相压力高于相应温度的饱和压力，只是单相的必要条件；没有 `NPSHr(Q,N)` 或空化模型时，不能据此标记“泵空化裕度通过”。
- 液体反流意味着实际吸入端可能变化。相区检查不能只顾原本正向入口而忽略另一端。
- 该模型不解析泵叶轮内部局部最低压力、气穴、两相充填、冷凝或气体夹带。接近或跨越相态边界应停止解释。
- 有效域事件、用户取消和正常结束必须区分；停止前数据可保留，但图表不能越过终止事件继续画成有效结果。
- 输出采样点数不等于积分步长。需要自适应积分、事件定位，并用容差收紧对比判断求解是否稳定。

## 8. 分层验证矩阵

以下是验收要求；通过情况应引用相应测试或实际任务记录，不应因写在表中而默认为已通过。

| 层级 | 验证用例 | 检查内容 |
|---|---|---|
| 代数与单位 | 默认参考点 | 两条动量方程、液腔净流入及执行机构导数同时为零 |
| 代数与单位 | 零速零流 | 压升和转矩有限且为零，没有除零或虚构效率 |
| 泵图 | 四象限、周期接缝、反流 | 方向连续，尺度明确，默认耗散非负；导入不合格图被拒绝或明确停止 |
| 泵图 | 指定轴速反向 | 压升、轴功和液压功按符号变化；没有将规定轴速误标为动态预测 |
| 阀门 | 指令阶跃、斜坡、饱和及反向动作 | 实际开度满足时间常数、开闭速率、行程；指令与实际值分别显示 |
| 阀门 | 关闭与显式泄漏 | 泄漏参与流阻；零面积策略明确；关闭后不会通过隐藏流量截断破坏余额 |
| 库存 | 不等进出流量 | `Δm` 与累计净质量通量一致，反向流量不丢失 |
| 液压机械能 | 两回路独立及合计 | 储能变化等于边界功与泵输入扣除耗散；参考压力一致 |
| 积分 | 无扰动保持 | 初态平衡保持，无额外数值激振 |
| 积分 | 容差收紧与采样改变 | 同一时刻解收敛；改变输出采样不改变物理模型 |
| 有效域 | 低压、过压、压缩率、图谱边界 | 事件准确定位，状态标明停止，保留有效样本而不继续外推 |
| 工作流 | 取消、历史记录、下载及隔离 | 保留已有结果；参数/来源快照不可变；项目权限和任务归属正确 |
| 实验验证 | 独立部件/子系统试验 | 保留实际边界、阀序、初态、传感器误差；区分标定数据和留出验证数据 |

数值正确性、模型有效域和试验验证是三个不同状态。即使余额接近机器精度，也不能据此给出实机压力、转速或启动时间的精度保证。

本次独立核查已实际运行 `web_tests.test_feed_network_physics` 的 16 项测试及 `web_tests.test_feed_network_adapter` 的 5 项测试，均通过。前者覆盖参考点、四象限耗散、真实反流、质量与液压能导数、惯性/容性尺度、执行机构解析解及行程、回路独立性、导入图、域事件、积分容差和取消；后者检查来源与物性适配等工作流合同。这是当前数值与模型合同的验证记录，不替代上表的实际 UI、完整任务链或独立试验验收。

## 9. 下一阶段与整机热态模型的耦合

1. 用预燃室或主燃烧室的动态压力替换固定背压，将各流路和气腔通过共同的质量、焓、组分端口连接；反流时按实际上游状态输运。
2. 用轴方程 `J dω/dt=τturbine+τstarter−τpump−τloss` 替换规定转速。GG 单轴只保留一个共享轴状态；双轴和 FFSC 分别建立轴状态及真实机械连接。
3. 真实流体物性随状态更新，液腔转为质量/内能库存闭合；加入泵与管路耗散的热去向、壁面热容和预冷过程。
4. 在有数据和相区模型后，加入空化、气液充填、残液和非凝气。需要水击时再建立空间网格，并与单管解析或特征线基准比较。
5. 最后加入点火器、点火许可与延迟、熄火判据、启动能量和发动机专用阀序。给定点火事件后的响应不等同预测能否点火。

上述耦合必须同时比较同一硬件、同一边界下的最终动态平衡与稳态方程，并保留独立试验验证状态。本轮的供给网络研究台是这一过程的可审计基础模块，而非冷启动或关机全过程的完成声明。
