# FFSC 稳态供给网络与能量闭合

本轮将四条预燃室供给支路纳入循环压力和泵功计算，并建立储箱至喷管出口的统一焓账。方程闭合对应当前集总模型；流路、压力损失和效率仍包含工程假设，不能解释为 Raptor 3 实机结构或性能已验证。原有历史记录保留，新结果带 `steady_closure.schema_version=1`。

## 流路与取流点

两种推进剂分别经过储箱、外部驱动增压泵、入口短管和主泵。全部甲烷经过再生冷却后分流；液氧在主泵出口分流。主泵出口没有未建模的补压设备。绝热管路、阀门和喷注压降在忽略内部宏观动能变化的集总近似下保持比焓。

| 支路 | 取流点 | 目的地 | 质量流量来源 | 压力损失来源 |
|---|---|---|---|---|
| 甲烷至富氧预燃室 | 再生冷却出口 | 富氧预燃室 | 总流量、总 O/F 与两预燃室 O/F 约束 | 喷注预算、基础管损、附加调节阀压降 |
| 甲烷至富燃预燃室 | 再生冷却出口 | 富燃预燃室 | 同上 | 同上 |
| 液氧至富氧预燃室 | 液氧主泵出口 | 富氧预燃室 | 同上 | 同上 |
| 液氧至富燃预燃室 | 液氧主泵出口 | 富燃预燃室 | 同上 | 同上 |

供给表中的新温度是经过等焓供给损失后的预燃室入口温度；取流点温度另外保留在流动状态中。同一工质去往不同压力的预燃室，入口温度可以不同，比焓保持相同。基础管损与附加调节阀压降分列，避免重复扣除上游冷却压降。

## 供给方程与设计自由度

给定总燃料、总氧流量 F、O，富氧和富燃预燃室的目标质量混合比分别为 Rₒ、R𝒻。四条分流满足：

```text
m_f,OPB + m_f,FPB = F
m_o,OPB + m_o,FPB = O
m_o,OPB = R_o m_f,OPB
m_o,FPB = R_f m_f,FPB
```

目标模式要求 `0 < R_f < O/F < R_o`。不满足时拒绝，不能裁剪分流后继续声称混合比闭合。自由分流模式由功率方程确定分流，不额外施加目标混合比。

每条支路满足：

```text
p_tap - p_PB - dp_line - dp_injector - dp_extra_valve = 0
dp_extra_valve >= 0
min(dp_extra_valve of each propellant) = 0
```

最后一个条件定义最低供给压头的设计匹配：每个取流点至少有一路无需附加节流。设计点的喷注损失为给定压降比乘该预燃室压力，基础管损为给定预算。四个流量、两个取流压力、四个附加阀压降，共十个未知量；对应质量二式、混合比二式、压力四式、最低压头二式。

`steady_network.solve_design` 对这些代数方程作精确消元。主泵功随两条目的支路中的最高压力需求变化，再反馈到循环非线性残差；这与仅在计算后检查交叉欠压有实质区别。阀门只耗散压头，不能补充压头。最低压头匹配没有证明工程储备裕度，也没有给出真实阀开度或调节范围。

局部网络审计重新计算质量、混合比、压力、阻力律、共用取流点和阀压降条件，不读取已有通过标志。压力验收为 `max(1 Pa, 1e-9 × 压力尺度)`；质量验收为 `max(1e-8 kg/s, 1e-9 × 最大推进剂总流量)`。这些是数值闭合门槛，不是工程安全系数。

交叉供给压力检查仅在新记录通过独立网络审计时采用同一显式压力容差，原始负残差仍保留。例如 −0.093 Pa 可属于 1 Pa 内的数值误差；原先约 −4.37 MPa 的欠压仍会失败。旧记录和网络审计失败的记录不能借用该容差。

## 焓基准与能量边界

液氧和甲烷采用相同的化学焓基准：Cantera 纯气体在 298.15 K、101325 Pa 的焓，加上 CoolProp 相对该参考态的真实流体焓差。燃气使用 GRI30 对应化学焓。统一标识为 `cantera_gri30_coolprop_298p15K_101325Pa_v1`；不同参考标识、缺失焓或缺失边界项不能通过校核。

```text
泵：        m (h_out - h_in) = P_shaft
冷却剂：    m (h_out - h_in) = Q_regen
绝热供给损失：h_out = h_in
预燃室：    sum(m h)_out = sum(m h)_in
涡轮：      sum(m h)_in - sum(m h)_out = P_turbine
主室：      H_out + Q_regen + Q_efficiency = H_turbine_exhausts
喷管：      H_chamber = m_exit (h_exit + V_exit²/2)
整机边界：  H_exit_static + P_exit_kinetic + Q_efficiency
            - H_tanks - P_external_boosters = 0
```

化学放热已经包含在反应物和产物生成焓的差异中，不再额外加入燃料低位热值。主泵功和涡轮功是内部传递，分别核验轴平衡后在总边界中抵消。再生冷却热量同样是内部传递，在冷却剂侧增加、燃气侧等额扣除。增压泵是外部轴功输入，不能因不在主轴残差中就漏出总账。

燃烧效率仍采用原模型的温升折减定义。本轮把其对应能量差单列为 `combustion_loss_W` 的等效热汇，没有把它解释成已求解的有限速率不完全燃烧。热汇不能取负值变成隐含热源。

再生热载荷包括主室、收缩段、喉部和喷管。本轮采用**总焓等效集中扣热**，再进行绝热冻结喷管膨胀。因此总账可以闭合，但局部主室温度、喷管性能与沿程热流仍受集中近似影响。下一层模型应将各区域热流与非绝热喷管连续、动量、能量方程联立；现有沿程冷却后处理不等于完成该双向耦合。

反应燃气仍采用 GRI30 的理想气体平衡模型。高压真实气体效应、物种热容拟合适用范围及高温外推并未通过本轮守恒校核自动获得验证；本轮约 3743 K 的主室状态仍需独立热化学数据与适用域检查。状态重建和元素守恒验证的是程序一致性，不是该物性近似的实验准确度。

`steady_closure.audit_energy` 从保存的 19 个状态和部件输出重算 23 项能量检查。每项阈值为 `10 W + 1e-5 × 最大绝对能量项`，界面保留有符号残差、实际容差与来源。负的化学参考焓不表示能量流向反转。通过表示内部一致性，独立试验或独立热化学数据库验证是另一证据层级。

## 数值求解与对照

保留现有分块默认方法：三变量循环根求解、热反馈外环、预燃室目标温度外环、自适应延续和完整热启动。四支路方程在循环评价内解析消元；使用当前密度的冻结阻力以及自动冷却压降时，额外水力内环也必须收敛。

FFSC 内层默认相对阈值由 `1e-4` 收紧为 `1e-6`，以满足新增独立轴功能量校核。原输入第一次重算的燃料轴误差约 1.71 kW，虽然满足旧阈值，却未满足约 330 W 的能量检查；收紧后降至瓦级。没有放宽能量门槛来让结果通过。

`ffsc_coupled.solve_coupled` 是实验性 18 变量对照：总流量、两涡轮压比、两预燃室 O/F、主室 T/γ/M、四支路流量、两取流压力、四阀压降同时参与方程。对应推力一式、轴功二式、预燃室温度二式、热反馈三式、质量二式、混合比二式、压力四式和最低压头二式。TRF/Newton 停止原因与全部物理残差验收分开记录。

联立对照从已经通过独立审计的分块解附近扰动初值；分块额定运行包含冷启动延续及外环，因此两者调用次数不能直接换算成加速倍数。当前证据用于检查同一方程是否得到一致根，不支持宣布一种算法全工况最优。

## 节流硬件范围

来源额定记录必须具有完整数值收敛、供给网络和能量证据；旧记录缺少证据时要求重新计算，不补造通过状态。冻结主喷管喉部、膨胀比、冷却通道高度及四条支路的基础管路与喷注阻力系数。

支路采用集总密度修正阻力律 `dp = K m² / rho_upstream`；设计反推 `K = dp_ref rho_ref / m_ref²`。节流使用当前取流点密度。附加调节阀压降仍作为非负控制量求解，没有阀流量特性时不换算为物理开度。

泵/涡轮效率仍为输入值，泵转速与部分部件尺寸仍作工况估算；主室热气喷注损失仍沿用预算，固定模式的冷却总压降仍沿用输入值。因此当前结果称为**固定选定几何与四支路阻力的稳态重匹配扫描**。完整固定发动机包线还需要泵扬程与效率图、涡轮流通能力图、阀门特性及行程边界、实际冷却几何与非绝热喷管模型。

扫描在额定完整解和最近成功点中按推力距离选择热启动来源，并在室压修正间复用当前点的完整解。每个请求点限制为 240 次循环评价；超预算、数值或守恒失败都保留原因，不插值填造成功点。预算次数与壁钟时间属于诊断，不表示发动机物理响应。

## 尚未闭合的冷却几何与压降输入

原始示例使用给定冷却压降 5 MPa；该固定压降额定结果自己的通道几何估算约为 31.370 MPa。本轮另以保存的额定求解状态开启自动水力模式，做一次有界前向探针：水力内环 6 轮达到约 0.011 Pa 的闭合残差，得到 Darcy 集总压降约 30.893 MPa，且没有截断压降。自动模式中的泵出口及冷却状态随压降改变，所以它与固定模式的几何估算不同。它沿用原流量和涡轮压比，**没有重新平衡轴功，因此不是新的额定解**。

这一差异说明给定压降和当前通道几何/损失假设仍不一致。不能通过把固定压降直接改成 30.893 MPa，或放宽守恒门槛，就宣布模型已验证。应先核实通道尺寸、流长、粗糙度、局部损失和流体物性，再启用几何水力耦合重新匹配。界面按每条记录自己的冷却结果显示采用值与水力估算来源；独立探针保存在验证报告中。

## 界面信息与诊断分层

主界面显示四支路流量、取流点、供给损失后温度、供给与目的压力、闭合状态，以及能量边界、主要收支和全局残差。压力预算、逐项控制体残差、判据、物性基准和数据来源放在可展开区；现有收敛曲线继续显示数值状态。

雅可比矩阵、差分探针、未接受试探、物性缓存、18 变量联立参数与工作量比较留在诊断文件。它们不能包装成发动机性能指标。模型假设、压力储备尚未证明、固定硬件范围和历史缺失证据属于解释结果所必需的信息，保留在界面。

## 证据和复算

本轮数据与脚本在 `diagnostics/physical_closure_20261023/`。`verify_rated.py` 复算同一原始输入的 Newton/TRF 额定点，`verify_throttle.py` 使用同一来源硬件，`compare_coupled.py` 保存联立对照。文件不写入工作台历史数据库。

方程依据包括本地 He 等 2024 年论文第 3–4 页、式 9 的共用泵供给压力关系，以及 Naderi 与 Liang 2019 年论文的部件和系统稳态匹配框架。论文支持建模方法，不能提供本项目缺少的实际 Raptor 泵图、阀特性或试验标定数据。原文提取与页图保留在 `diagnostics/steady_audit_20261023/`。
