# 主燃烧室总体设计与分析

## 范围与页面

“设计与配置 → 主燃烧室设计与分析”以所选 FFSC 计算记录为来源，汇集两股入口燃气、主室 HP 平衡状态、守恒、有效特征速度、容积与内型面、主室冷却及材料适用性。它是总体设计的数据审查和建模交接工作区。

页面及导出不读取未保存草稿，不重跑热化学，不更改历史计算结果。修改设计输入后需运行新的设计点。独立热化学复核沿用“热力学校核 → 燃气交接与筛查”：实际富氧与富燃涡轮排气的元素、完整组成和共同参考焓作为输入，纯推进剂基准不替代这个接口。

射流混合、空间热释放、三维火焰、燃烧不稳定增长率和局部热斑属于后续性能数字样机。当前的均匀参考态不能绘制成真实火焰云图。

## NASA 方法与本平台模型

- [NASA CEA / RP-1311 方法](https://ntrs.nasa.gov/citations/19950013764)及 [CEARUN 说明](https://cearun.grc.nasa.gov/intro.html)：给定元素库存、比焓和压力的 HP 平衡提供热化学参考。独立比较需对齐入口化学焓、元素、压力、相态和允许物种，并保留数据版本与差异。热化学软件间一致不等于试验验证。
- [NASA SP-8087，1972](https://ntrs.nasa.gov/citations/19730022965)：总体分析同时核对燃气热负荷、冷却压降、壁面结构及运行条件。文献提供设计检查框架；历史材料、工况和经验数值不能直接认定适用于高压甲烷 FFSC。
- [NASA SP-8113，1974](https://ntrs.nasa.gov/citations/19750020175)：燃烧不稳定涉及非定常放热与流体动力学耦合。当前名义声学频率仅作后续声学模型输入，不能判定稳定、给出自动通过或指定必须避开的工作点。
- [Cantera 热力学说明](https://www.cantera.org/stable/userguide/faq.html)：化学平衡求解与有限速率反应不同；Cantera 的 cp/cv 为定组成性质。页面保留这些定义以及化学焓参考，不将负参考焓解释成负热量。
- [Zhukov 与 Kong，2018，DLR 高压甲烷机理](https://elib.dlr.de/125451/)：机理之间的校核与实验验证分开。当前高温热力学数据温区检查不能证明动力学在本项目压力、入口产物和稀释条件下有效。

## 有限速率理想反应器的取舍

本版不把理想反应器加入总体设计的必要求解链。它适合未来研究化学时间尺度和敏感性，但不能解决喷注混合，也没有足够证据使当前高压机理成为燃烧完成度验收依据。[Cantera 完全搅拌燃烧室示例](https://www.cantera.org/stable/examples/python/reactors/combustor.html)仅说明反应器模型和停留时间研究方法，其模型、参数与结论均不直接移植到火箭主室。

未来启用须单独登记机理身份及有效范围、入口混合假设、反应器类型、初始/边界条件、求解终止与守恒检查，并将结果标为独立研究，不能回写总体设计温度或替代 CFD/试验。当前只保留名义容积更新时间 rho*Vc/mdot；它不是点火延迟、反应时间或燃尽率。

## 几何和性能定义

- 主室范围：喷注面至喉部，含圆筒和完整收缩段。Vc = L* At，L* 不是实际轴向长度。
- 母线来自同记录完整热气内轮廓，截取至喉部；尺寸/坐标一致性有冲突时禁用坐标导出。离散母线积分与构造曲线积分须允许合理采样差异，不能把绘图拟合重新作为设计源。
- CSV 坐标只描述内壁母线，可用于 CAD 旋转建模；不包含喷注孔、冷却槽、承压实体、边界面分组或网格。导入拟合后需复核喉径、轴向长度和容积。
- 系统有效 c* = Pc At / mdot。理论绝热基线、当前带热损模型和试验值分别解释；不生成未验证的 c* 效率。
- 历史 combustion_efficiency 是可选温升折减系数，不能称燃料转化率或 c* 效率；仅在对应模式下生效。

## 热量与材料身份

沿程冷却模式在准一维热侧扣除再生冷却吸热，零维主室 heat_loss_W 为零不代表硬件没有冷却。主室热量按真实 channel 单元的轴向位置求和，区分主室与整条再生回路，排除零长度汇流元件。峰值来自原单元并保留其位置。

新计算的默认内衬材料必须与默认热物性数据集的 material_id 一致；明确的轴向材料分区另列，不能用分区掩盖基础配置错误。旧记录保留原始配置和实际逐单元物性证据，在页面显示不一致，不改标签、不替换物性、不重写历史数据。

温区、制造状态、壁温限值和结构资格分别检查。导热曲线末端延用不能扩大文献有效温区；牌号相同不代表制造状态相同。内衬/通道几何与外套承压估算分开，简化壁厚不是制造定型或疲劳寿命结论。

## 验证约束

验证覆盖同记录数据不变性、缺失值不补零、全组分质量和、同身份物种摩尔质量换算、热侧区域与峰值、材料冲突和显式分区、异常几何禁导出、前端转义与 CSV 精度，以及导航/API 接入。内部守恒通过仅证明该模型的账目一致。
