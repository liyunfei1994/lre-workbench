# 总体阶段再生冷却热负荷估算

总体阶段采用概略型面、冷却覆盖范围和当前燃气状态估算沿程热流，再按受热面积积分得到吸热功率。新建方案默认采用此模型。通道宽深、数量、壁厚和材料仍归部件设计；总体阶段不要求先完成通道设计。

## 三种模型

| 模型 | 主要输入 | 输出与用途 |
| --- | --- | --- |
| 概略热负荷（mode 2） | 设计工况、概略型面、冷却范围、参考热面壁温、燃气有效辐射系数、压降估计与依据 | 沿程估算热流、受热面积、峰值及位置、积分吸热功率、冷却剂出口端口状态；用于总体循环匹配 |
| 详细通道耦合（mode 1） | 同一型面、通道几何、材料及换热/水力模型 | 沿程壁温、冷却剂状态、热流和压降；用于部件热工与水力校核 |
| 外部指定（mode 0） | 外部提供的吸热功率和压降 | 端口能量平衡；用于外部结果交接、对照及敏感性研究，不产生沿程曲线 |

概略模式不读取外部指定的吸热功率。旧方案保留原来的 mode；缺少 mode 的历史域输入仍按原详细模型解释。选择新模型不会清除部件草案或覆盖旧计算记录，需重新计算形成新的结果。

## 计算与参数归属

“总体方案与循环设计 → 总体模型与假设”中设置冷却模型和“概略型面与冷却范围”。后者是共享几何的唯一编辑入口，推力室与冷却部件页面引用同一份定义。喷管面积比仍在“喷管总体膨胀条件”设置。

1. 当前流量、主室状态和喷管求解给出喉部尺度；特征长度、收缩比和轮廓参数确定概略受热面，冷却终点面积比决定覆盖范围。
2. 使用现有 Bartz 型对流关联和简化辐射模型，在各单元的参考热面壁温下求局部热流，按实际热面面积求和。默认参考壁温为 800 K，是可修改的估算假设，不是材料温限或计算结果。
3. 冷却剂出口按积分吸热功率、流量及估计出口压力求单相 HEOS 焓平衡。概略模式没有冷却剂沿程状态，不推定实际壁温或通道尺寸。
4. 将热量反馈至循环和热气模型。热气沿程扣热与冷却剂吸热使用同一份热量，避免重复扣除；压力、热态、几何、总热量、局部燃气状态、局部热量六项残差共同验收。
5. 保存模型身份、几何、每个估算单元、峰值、参考壁温、压降估计及依据。结果页面只读取该记录，不使用当前草稿补绘历史曲线。

概略冷却压降独立保存，默认 5 MPa 只是初始工程假设。它参与泵压需求和冷却出口状态，不是通道水力解、允许上限或数值迭代初值。详细模型使用自身水力计算；旧的外部压降字段在详细模式中仅用于初始化。

## 适用范围与后续工作

当前概略模型限于液氧/甲烷 FFSC 总体设计。关联式、燃气物性、辐射近似和参考壁温均需按具体工况复核；未实现液膜热流修正。概略模式拒绝不支持的反向传热，不自动把负热流裁为零。

同一总吸热功率可以有不同的局部峰值。数值收敛和能量平衡只说明该模型闭合，不能说明壁温、压降、材料或冷却能力合格。进入部件阶段后，应完善通道、壁厚、材料与相关模型，切换详细耦合模式并复算。概略结果不能用作固定硬件冷却基准。

## 依据与验证

- [NASA SP-8087, Liquid Rocket Engine Fluid-Cooled Combustion Chambers](https://ntrs.nasa.gov/citations/19730022965)，§3.1.1.5 等关于热环境、壁温和冷却设计的要求。用于组织设计过程，不代表本程序经 NASA 验证。
- [RPA 4 User Manual](https://app.rocket-propulsion.com/downloads/4/docs/RPA_4_User_Manual.pdf)，热流估算与完整冷却分析的分层思路；本程序不复现 RPA 的完整实现。

自动回归覆盖热流面积积分、端口焓守恒、参考壁温/工况/面积敏感性、网格加密、与未启用通道参数的独立性、非法输入、旧任务无损读取、真实循环六项耦合收敛、结果显示和固定硬件入口限制。回归算例验证程序行为，不等于独立实验验证。
