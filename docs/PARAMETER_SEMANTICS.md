# 参数定义、模式与参考资料修正

日期：2026-10-23。范围：网页系统仿真参数编辑器、共享标签、默认值说明与 Raptor 3 参考示例。本轮不改变循环方程或冷却、热化学模型。

## 设计方式

总体设计默认使用“指定预燃室出口温度”，反求混合比及分流。温度目标是设计选择；运行上限是另行验收的约束，均不等同于材料寿命证明。复现已知配比或文献算例时使用“指定预燃室混合比”，以温度为输出。

网页选择器是兼容适配，不是新增的求解参数：

| 网页方式 | 温度开关 | 混合比开关 | 含义 |
|---|---:|---:|---|
| 指定出口温度 | 1 | 1 | O/F 为外环初值和求解结果 |
| 指定混合比 | 0 | 1 | O/F 为输入，温度为输出 |
| 历史自由分流（只保留） | 0 | 0 | 打开时不转换，显式选择现代模式后才转换 |

旧开关仍按求解器原有 `>=0.5` 阈值解释，温度模式优先。因此旧 `(1,0)` 也按温度模式显示。网页不保存虚拟的 `preburner_design_mode`，避免三种字段相互矛盾。没有迁移既有方案、版本或计算结果。

## 参数角色和生效范围

参数声明位于 `src/parameter_contract.py`，网页 schema 和前端据此显示性质、默认来源及说明。

| 参数 | 角色 / 生效条件 |
|---|---|
| 推力、室压、O/F、面积比 | 设计输入；命中指定推力不是独立推力验证 |
| 推进剂温度、压力 | 边界条件；FFSC 温度从贮箱侧给定，主泵入口状态另算；GG 仍采用温度沿用的简化入口链 |
| 部件效率、压降预算 | 模型假设；会改变物理解，不是初值 |
| 主室温升折减系数 | 经验温升模型，不等于 c* 效率或燃尽率；FFSC 单独记录对应焓亏损 |
| Isp 初值 | 构造总流量初猜 |
| 主室 T / γ / 摩尔质量 | Bartz 或自动水力热反馈初值，不是化学焓基准 |
| PB O/F | 指定温度时为折叠的初值；指定混合比时为设计输入 |
| PB pPB/pc | 目标模式中为初猜输入，不等于涡轮进出口压比；历史自由分流中为受最小涡轮压比下界影响的输入 |
| PB 分流初值 | 仅历史自由分流模式显示 |
| 固定 Q | 仅指定吸热量模式显示 |
| 固定冷却 Δp | 仅给定压降模式显示 |
| 常比热 cp | 正常 Cantera + CoolProp 焓路径不用于固定温升；隐藏，保留兼容校验和序列化 |
| 泵指定转速 | 大于零则锁定；不是特性图匹配结果 |
| 泵 nq 目标 | 仅转速为零时显示；注明 rpm、m³/s、m 的单位约定 |
| 泵 ψ | 仅独立概念几何使用，组件诊断口径仍待统一；完整参数保留，主编辑器隐藏 |

初值默认折叠。当前无效字段不参与页面搜索结果，但仍完整导入、导出和保存。隐藏字段若不满足旧输入有效性校验，错误信息引导完整 JSON，避免无法定位。GG 单轴下燃料泵指定转速、其 nq 目标和氧侧涡轮效率不生效，亦隐藏。

## Raptor 3 参考来源

[SpaceX《Introducing Starship V3》](https://new.spacex.com/updates)，发布于 2026-05-12，本次核对日期 2026-10-23：海平面版本 250 tf，另一个真空版本 275 tf。

载入 `raptor3_ffsc` 时海平面设计推力为 `250 × 1000 × 9.80665 = 2451662.5 N`。多位小数是单位换算结果，不代表原始数据具有对应精度。真空版本推力仅列于资料卡，不混入海平面示例。

通用 `EngineInputs()` 的历史工程默认值仍是 2450000 N。33 MPa、O/F=3.6、面积比 34.34、入口状态、效率和内部损失继续明确列作未核实的工程假设；327 s 为数值初值。不能据厂商公开一个推力值推定整套模型已获验证。每项证据的分类、来源与日期见机型资料中的证据表。

## 校核结果与范围

- 240 项网页后端测试通过，覆盖序列化、方案、API、静态模块依赖及本轮参数契约。
- 342 项 JavaScript 测试通过，含新模式选择、条件显隐、初值折叠、来源显示、保存、撤销与重连。
- 18 项 FFSC 收敛回归测试通过；本轮核心数值表达式保持不变。
- 隔离数据库中的真实浏览器检查通过：页面启动、两种模式、保存后的两个开关、隐藏值保留、Q / cp 显隐、转速切换、推力换算及页面无脚本错误。
- 更新预设的指定温度模式完整收敛；取其实际 O/F 作为指定混合比模式输入后冷启动复算，也完整收敛。两次推力差约 0.00176 N，预燃室温度最大差约 0.0109 K，在既有容差内。第二种方式的预燃室温度外环正确停用。

原始结果和脚本保存在 `diagnostics/parameter_contract_20261023/`。两模式比较是同一物理模型的参数角色一致性检查，不是多初值稳健性试验，也不是 Raptor 实机验证。

下一步仍需独立处理热化学数据温区、冷却热侧与水力侧统一、燃烧损失定义以及固定硬件部件特性。当前初值/来源修正没有消除这些物理模型限制。
