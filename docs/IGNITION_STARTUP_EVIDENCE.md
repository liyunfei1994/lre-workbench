# 点火与启动建压：文献证据及模型取舍

核读日期：2026-10-22。页码均指本地 PDF 文件页码，从 1 开始；不等同于期刊页码或印刷页码。本文重新检查了四篇相关文献的全文提取文本，并渲染核对关键原始页面。PDF 中的高亮、批注和论文结论作为资料处理，不作为平台实现指令。

本文是模型选择依据，不是实机验证报告。实际功能、适用域与验收结果分别以模型说明、代码和验证记录为准。

## 1. 本阶段的研究定位

文献支持先建立**给定事件和边界条件下的系统响应**，再以特定工质、点火器、喷注器与试验数据建立点火成功、点火延迟和熄火判据。系统模型中人为指定一个点火时刻，与能够预测真实点火，是两种不同能力。

本平台首版选用一个更明确、可校核的子问题：**预先汽化的 CH4/O2 入口、N2 初始气体、刚性均匀容腔、有限速率气相化学反应、外加热脉冲、压力驱动入口及出口、壁面热容**。外加热脉冲是规定的能量输入，不是已标定的火炬、电火花、激光或自燃点火器；它既不强制指定燃烧温度，也不保证出现持续放热。该选择是本轮的工程建模取舍，并非以下四篇文章共同采用的完全相同模型。

此子问题可以研究：入口时序和压差、腔内库存、外加能量、壁面热损失与化学反应共同造成的压力和温度演化。它不能代表完整 GG、FFSC 或膨胀循环发动机从冷态到额定点的启动。原有供给网络、预冷与充填模型必须在相态、端口焓基准和库存定义一致后，才能逐步接入。

## 3. 化学、库存与外加热输入如何保持一致

对于均匀、刚性、气相控制体，推荐保存总质量/组分库存和总内能的物理含义，即使求解器实际采用温度和质量分数作为积分状态。令 `M_k` 为组分质量，`U` 为含化学参考能的总内能：

```text
dM_k/dt = Σ_in(mdot_in Y_k,in) - mdot_out Y_k + V W_k omega_k
dm/dt   = Σ_in mdot_in - mdot_out
dU/dt   = Σ_in(mdot_in h_in) - mdot_out h + Q_external - Q_to_wall
rho     = m / V
U       = m Σ_k(Y_k u_k(T))
```

化学反应的组分源必须满足总质量和各元素守恒。采用一致的 Cantera 物种热力学后，反应引起的温升通过组分和内能共同确定，不能再次在上式加入燃料低热值。反应放热率可以作为诊断输出，与外加热功率分别显示；诊断项不等于额外能源。Cantera 的理想气体控制体文档给出了相应质量、组分与温度形式的守恒方程。[Cantera 3.2 官方方程](https://www.cantera.org/3.2/reference/reactors/ideal-gas-reactor.html)

外加热输入的起点、持续时间、形状及积分能量必须显式记录；化学反应是否显著由该模型状态和反应速率决定。若在给定时刻人为把低温混合物直接重置为平衡燃气，却没有保存同一库存和内能，这种温压跃迁会引入未登记能量。首版热脉冲方案避免通过重置状态强制“点燃”。

GRI-Mech 3.0 是天然气燃烧和 NOx 形成的详细气相机理；它作为 Cantera 输入文件被提供，不构成高压纯氧甲烷火箭点火器的验证。热力学多项式可计算的温度范围也不等于反应速率的实验验证范围。运行记录应保存实际机理文件、版本/指纹、温度适用检查及未标定说明。[Cantera 官方输入文件说明](https://www.cantera.org/stable/examples/input/index.html)

## 4. 低压建压与排气模型的最低要求

冷态初始室压可能接近外界压力，此时不能沿用全程壅塞的 `mdot = Pc At / c*`。对约定的等效气相排气口，至少应满足以下数值和物理极限：

1. 内外压力相等时，净排出流量趋于零。
2. 未壅塞流量随背压改变，达到临界后受到最大质量通量限制。
3. 临界切换处流量连续；若采用定比热理想气体近似，应通过标准壅塞公式的独立对照。
4. 出口能量携带采用控制体的上游总焓约定，不能把喷口静焓当成腔体全部能量流出。
5. 若排气连接不允许环境反向流入，应声明为单向排气假设；该假设不能隐含解释成开放喷管真实回流。

NASA 的喷管质量流量推导表明，在给定总态和截面下声速状态对应最大质量流量。这为临界流量极限提供独立参考；它没有验证特定火箭在启动时的激波、分离或真实气体流动。[NASA Mass Flow Choking](https://www.grc.nasa.gov/www/k-12/BGP/mflchk.html)

“等效收敛排气口的建压响应”和“完整拉瓦尔喷管的启动推力”应在界面、图例与导出记录中区分。未求解后者时，不根据主室压力曲线补出未经支持的全喷管推力或比冲。

## 5. 与前两阶段的接口边界

预冷模块的液体或两相末态不能直接成为理想气相化学反应器的相同状态。接口至少需要：

- 同一个物理容积与端口编号；质量、组分、总内能、壁温和阀实际开度的一致定义。
- 液体显热、汽化潜热、剩余液滴库存及其焓基准；已有 HEOS/REFPROP 焓零点不能不加处理地与化学机理生成焓相接。
- 非凝气库存和置换过程；若先采用 N2 气相初值，只代表用户设定的均匀初始混合物，不代表已求解真实氮气吹除过程。
- 供给惯性、压差、反流和泵/涡轮能量的双向耦合；入口质量流量不能在压力不允许时仍由时间曲线无条件注入。

首版采取独立气相研究台时，应保留上述接口需求并阻止自动液态快照导入；不得通过自动升温或强制气化悄悄补齐缺失物理。

## 6. 后续判据需要什么证据

| 希望判断的量 | 本阶段可以输出 | 建立实机判据还需要 |

| 是否出现显著反应 | 温度、组分、CH4 消耗、诊断化学放热率，以及用户阈值的越界时刻 | 对应工质、喷注结构、点火源和压力范围的试验；探测量与火焰状态的对应关系 |

准则元数据至少记录来源、工质、初温初压、稀释、点火器类型、能量/持续时间、喷注构型、测试范围、阈值、观察持续时间、不确定度和版本。超出覆盖范围时应显示“未评价”，而不是默认通过。

## 7. 验证建议与证据等级

按以下顺序验证，避免只把同一套代码算得守恒当成物理真实性证明：

1. **方程级验证。** 无反应、密闭、绝热时质量和总能量保持；有已知外热输入时 `ΔU = ∫Qdt`；同壁面交换时流体与壁体总能量闭合。逐元素检查化学源及库存。
2. **独立求解器对照。** 相同机理、相同初态下，用原生 Cantera 封闭定容反应器对照自建集总方程；这能检查实现，但两者共享机理和物性，不是化学机理实验验证。
3. **流动极限。** 独立验证等压零流、理想气体未壅塞/壅塞流量、临界连续性以及入口压差不足时的行为。
4. **事件与时间积分。** 在不与输出采样点重合的热脉冲起止时刻验证能量积分；加密容差和最大时间步检查峰值压力、事件时刻与物种轨迹；比较无热脉冲对照，不要求无脉冲必然不反应。
5. **异常与守恒。** 无燃料、无氧化剂、弱热输入、强壁冷却、阀延迟、反向压差和达到适用域边界。达到边界应保留有效历史并说明终止原因，不能截断温压后继续声称正常积分。
6. **试验级验证。** 后续导入有时间轴、单位、仪器误差和边界/初值的原始曲线。区分用于标定的量和保留验证量；先做独立气相台架，再逐级扩展为真实推进剂喷注与全系统。

本地文献中的 RL10 或其他结构验证误差只属于其研究对象。它们不能成为本平台 CH4/O2/N2 气相研究台的既有误差指标，也不能用于宣称真实发动机点火可靠性。
