# 点火与启动建压研究：方程、接口及适用范围

日期：2026-10-22。实现入口为 `src/ignition.py` 的 `IgnitionModel`，平台适配层为 `webapp/ignition.py`。本说明与[文献证据](IGNITION_STARTUP_EVIDENCE.md)配套；具体测试结果单独记录。文献方法、数值实现验证与实机验证是不同证据等级。

## 1. 当前实际计算对象

本阶段建立**给定外部点火热脉冲下的气相容腔建压研究台**：

```text
固定 O2 气体总态 → 氧执行阀 ─┐
                             ├→ 刚性均匀反应容腔 ↔ 集总金属壁
固定 CH4 气体总态 → 燃料执行阀┘           ↓
                              单向等效气相排气口 → 固定背压
```

容腔采用 Cantera GRI-Mech 3.0 的理想气体热力学与有限速率化学反应。入口是已经汽化的氧气、甲烷，初始气体可设为氮气或给定 O/F 质量比的氧气/甲烷均匀混合物。壁面有有限热容量，可以与容腔及固定环境换热。

用户给定的“点火事件”在数学上是**向整个容腔施加规定功率和持续时间的外部热源**。它不是一个把组分重置为燃烧产物的开关，也不把温度或室压强制拉到额定值。热脉冲可能只造成升温，也可能促成显著化学反应；没有热脉冲的足够热混合物也可能自行反应。

本模块不宣称预测真实点火器的点火成功率、火焰形成时刻或吹熄边界。主室、预燃室、涡轮泵和供给网络尚未在此模型中形成完整 GG/FFSC/膨胀循环启动闭环。参考发动机只提供所属方案的追溯背景，不会把本研究台自动变成该发动机的启动模型。

## 2. 初始状态与参数来源

| 参数类别 | 当前来源/含义 | 使用要求 |
|---|---|---|
| 容腔体积、壁热容量、热导 | 用户可修改的研究假设 | 应替换为具体结构或台架数据，并做敏感性分析 |
| 初始压力、温度、组分、壁温 | 用户给定的均匀气相初值 | 不从高温稳态结果反推冷态库存；不自动接受液体/两相预冷末态 |
| 气体供给总压、总温 | 固定无限大气源边界 | 不是动态贮箱、泵出口或液氧状态；入口焓在同一化学机理基准下计算 |
| 阀有效通流面积、指令时间、斜坡、响应时间和速率 | 研究台执行机构假设 | 与实测 `CdA(opening)`、机械行程、死区和迟滞不同 |
| 脉冲起点、持续时间、总热量 | 用户规定的外部热输入 | 不是实测电功率、火炬功率或沉积效率；没有默认的实机来源 |
| 排气有效面积、背压 | 单向等效排气口 | 无拉瓦尔扩张段、内激波、分离、侧向力或推力预测 |
| 参考压力线 | 用户的响应观测目标 | 不进入动态方程，不代表点火成功、额定压力或控制器设定值 |
| 温度和压力上/下限 | 本次数值研究的适用边界 | 是终止条件，不是材料许用值、点火判据或机理试验验证范围 |

代码中提供的默认值是可复现的小型气相研究算例，均不冒充 RL10、Merlin、天鹊或 Raptor 的结构和时序。实际运行请求会保存这些数值；仅修改界面上的参考压力线不会改变计算出来的室压。

本轮气相状态限制在 300-3000 K 的声明范围内。该范围用于避免直接进入低温液体状态及明显超出本算例物性使用范围，**不等于 GRI-Mech 在整个压力、温度、混合比区间已被试验验证**。GRI-Mech 是天然气气相反应机理，其高压纯氧甲烷点火适用性需要另行对照实验。

## 3. 库存、化学与能量方程

设 `V` 为固定容积，`m` 为总质量，`Y_k` 为组分质量分数，`M_k = mY_k`，`W_k` 为摩尔质量，`omega_k` 为摩尔生成速率，`U` 为气体总内能。所有流量都按其端口进入/离开控制体的方向记账：

```text
dm/dt   = mdot_O2 + mdot_CH4 - mdot_out

dM_k/dt = mdot_O2 Y_k,O2 + mdot_CH4 Y_k,CH4
          - mdot_out Y_k + V W_k omega_k

rho     = m / V
U       = m u(T,Y)
p       = rho R(Y) T
```

化学反应只改变组分分配，不能创造总质量或元素。原子组成矩阵应使 `Σ_k W_k omega_k = 0`，且每种元素的反应生成量为零。出口带走均匀容腔当前组分，入口组分则来自相应纯气体源。

刚性容积、无轴功时：

```text
dU/dt = mdot_O2 h_O2,in + mdot_CH4 h_CH4,in
        - mdot_out h(T,Y) + Q_ign - Q_wall

Q_wall = UA_wall (T - T_wall)
Q_amb  = UA_amb (T_amb - T_wall)

C_wall dT_wall/dt = Q_wall + Q_amb
```

`Q_wall` 为从气体进入金属壁的热流，可正可负。入口/出口使用焓，是开放控制体的流动能量约定；不能再对相同流动另加一次 `p/rho`。刚性壁没有移动边界功。

Cantera 积分器实际使用质量、体积、温度和质量分数。与上式等价的温度方程包含有限速率反应造成的 `-Σu_k dM_k,chem/dt` 项以及入口混合能量项。实现通过 `ExtensibleIdealGasReactor` 保留原生化学方程，再加入物理边界和壁面状态。[Cantera 理想气体控制体方程](https://www.cantera.org/3.2/reference/reactors/ideal-gas-reactor.html)

### 3.1 不重复计入化学能

Cantera 的物种内能和焓使用同一套热化学参考值，已包含与化学生成焓对应的参考能量。反应温升由组分变化和总能量守恒共同决定，**不能同时再向总内能方程增加燃料低热值、燃烧效率乘低热值或另一份平衡燃烧热**。

界面的“化学放热率”是根据反应速率和反应焓计算的诊断量，用来观察化学活动；它没有作为额外热源重复加入能量方程。它应与“外加点火功率”分别画图、分别命名。化学诊断放热与外加能量也不能合并后用作守恒审计的外部输入。

### 3.2 有限速率与无反应对照

化学反应设置有两种用途：

- **全程启用有限速率反应**：包括热脉冲之前；不会把预设时刻当作反应许可开关。
- **全程关闭反应的对照计算**：保留同一套物种热力学及边界流动，用来区分纯加热/充气与化学反应造成的变化。

关闭反应属于数值对照，不能被解释为实际混合物能够永远保持不反应。有限速率反应已经被积分，也不等于机理与点火器已经得到实验标定。

## 4. 规定热脉冲与阀门事件

对总热量 `E_ign`、起始时刻 `t_ign` 和持续时间 `tau_ign > 0`，矩形热脉冲为：

```text
Q_ign(t) = E_ign / tau_ign,  t_ign <= t < t_ign + tau_ign
           0,               其他时刻
```

热脉冲的开始和结束应成为积分分段边界，保证 `∫Q_ign dt = E_ign`，而不依赖用户选择的图表采样点恰好落在脉冲上。中途终止时只累计已经施加的能量，不能把全脉冲总能量提前记入。

两个供给阀分别有线性指令斜坡，实际开度按一阶响应与速率限制变化：

```text
da/dt = clip((a_command - a)/tau_valve, -rate_limit, rate_limit)
```

阀动作时间、斜坡完成时间和热脉冲起止列为**规定事件**。经过某个规定事件只说明仿真时间已经跨过该事件，不表示已经探测到火焰。即使最终指令为零、源压力不足或支路面积为零，事件时间仍可能经过，但流量可以保持为零。

## 5. 入口与出口流量

每个入口和出口采用准稳态气体节流关系。`p0,T0,R,gamma` 是该口上游气体的总态/冻结性质，`r = p_down/p0`，有效面积已包含流量系数：

```text
r_critical = (2/(gamma+1))^(gamma/(gamma-1))

mdot / CdA = p0 / sqrt(R T0) *
  sqrt[2 gamma/(gamma-1) * (r^(2/gamma) - r^((gamma+1)/gamma))], r > r_critical

mdot / CdA = p0 / sqrt(R T0) * sqrt(gamma) *
  (2/(gamma+1))^((gamma+1)/(2(gamma-1))),                       r <= r_critical
```

`p0 <= p_down` 时流量置零，对应明确声明的理想止回连接。该处理不代表开放喷管、喷注器或真实阀门中的反流已经建模。每个时间状态的容腔 `R,gamma` 随温度与组分更新，但单次节流求解沿流路仍采用冻结定比热近似，没有计算高温化学膨胀或两相闪蒸。

以上关系用于容腔流量及背压耦合：室压升高可能减少供给流量，超过源压则单向供给停止；出口在低压比时不壅塞，在足够压比下才达到临界通量。不把额定 `c*` 固定应用于整个建压过程。

本模块不输出整台发动机推力或完整喷管比冲。结构示意中的排气口仅说明流动连接，不能作为喷管几何设计结果。

## 6. 守恒账目与适用域检查

随主方程同时累计入口/出口质量、入口/出口焓、外加点火热、壁面热、环境热及每种元素的进出量。检查量分别为：

```text
R_mass  = (m-m0) - integral(mdot_in-mdot_out)
R_fluid = (U-U0) - integral(Hdot_in-Hdot_out+Q_ign-Q_wall)
R_wall  = C_wall(T_wall-T_wall0) - integral(Q_wall+Q_amb)
R_total = R_fluid + R_wall
R_elem  = (m Z_elem - m0 Z_elem,0) - integral(element_in-element_out)
```

流体能量、壁面能量与总能量分别审计，防止两个错误互相抵消。`Z_elem` 是该元素的质量分数；它不能与某个化学组分的质量分数混为一谈。

容差按本次输入、库存和累计能量的尺度设置。审计通过的含义是**该模型的守恒账目在数值容差内闭合**，不表示点火成功、实际部件安全或试验验证通过。应另用公开采样数据重新积分流量和能量通量，核对账目变量没有掩盖实现错误。

质量非正、不可计算状态、组分负值超过数值容差、阀行程异常以及用户声明的温压边界都会终止运行。终止时保存最后有效状态与原因，不通过钳制温度、压力或化学库存继续计算。积分器的事件分段、有效状态检查方法及实际时间分辨率随结果记录，不能把有限检查间隔的阈值时刻表述为无限精度事件根。

当前实现逐个检查积分器内部接受步。若一个接受步跨过规定的阀门或热脉冲事件边界，则恢复到此前的完整气相和附加状态，缩小步长重试；跨界试算不进入结果、审计峰值或累计热量。事件时刻容差为 `1e-12 * max(1, duration_s)` 秒。普通图表输出保存目标采样时刻之后的第一个接受步及其真实时间，不对压力、库存或组分插值；因此实际采样间距不必严格相等。适用域检查覆盖所有接受步，而不只覆盖图表点。刚好触及边界的连续时间并未通过事件根求解定位。

## 7. 输出与解释

结果应包括：

- 时间、压力、气体与壁面温度、质量、总内能、密度和焓。
- 氧气/甲烷供给流量、出口流量及各口是否壅塞。
- 两路阀指令和实际开度。
- 外加热功率、累计外加能量、诊断化学放热率及壁面交换。
- 完整组分质量分数，以及质量、各元素、流体/壁面/总能量残差。
- 规定事件表、完成/提前终止状态、模型范围及初态/末态快照。

压力参考线只用于观察首次达到时间。未到达应为缺失/未达到，而不是零秒；初态已经超过参考线则到达时间为零，并需由初态上下文理解。该时刻不是“点火延迟”。峰值也应说明采用实际保存/检查状态的时间分辨率，不能将它冒充完整高频压力波峰值。

当前点火成功、点火延迟和熄火判据均未启用；输出使用“未评价”语义。热脉冲施加完成、有限速率反应显著、压力达到参考线和守恒通过是不同信息，不应归并为一个绿色“点火成功”。

## 8. 初态/末态快照和后续耦合

快照保存气相组分、质量、总内能、容积、温度、压力、密度、壁温和实际阀位，并说明使用的机理与 Cantera 版本。由 `m/V` 和 `U/m,Y` 应能回算同一状态。这是气相研究台的可追溯状态记录，不是实机控制指令。

当前不支持把预冷模块液体/两相状态自动导入本气相模型，也不支持将本末态自动宣称为整机启动初态。后续耦合需要单独建立：液滴/液膜或汽化库存、两相供给及非凝气置换、一致的物理和化学生成焓参考、容积与接口映射、泵涡轮动力及反流、壁面能量和点火器能量沉积模型。未经这些转换，不可仅复制相同的压力和温度来假装初值一致。

## 9. 已建立的独立参考验证入口

`web_tests/test_ignition_reference.py` 从不同角度检查方程实现：

1. 密闭纯 N2 的给定热量，终态与独立 Cantera `UV` 热力学状态求解对照；脉冲端点故意不落在均匀输出网格上。
2. 密闭气体与有限热容量壁面换热，平衡温度与另行求解的总能量根对照。
3. 初始高温 CH4/O2 密闭反应，与原生、未扩展 `IdealGasReactor` 逐点对照；没有外加热量，检验化学不能被错误地延后到预设脉冲。
4. 由公开输出采样的流量、焓与热流做独立时间积分，分别检查质量、流体能量和壁面能量变化。
5. 从指定局部马赫数构建等熵温度、压力、密度和速度，以 `rho*velocity` 独立检查未壅塞及临界通量，而不复制实现中的压比流量公式。

这些参考共享 Cantera 机理/物性，可检验边界方程和积分实现；它们不能独立验证 GRI-Mech 化学速率，更不能代替实际喷注器/点火器试验。完成情况及数值误差应引用本轮验证报告，而不是由本文功能清单推断。
