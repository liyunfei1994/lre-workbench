# 关机与再启动研究模型：方程、接口及适用范围

本文对应 `src/shutdown_gas.py`、`src/shutdown_inventory.py`、`src/shutdown_rotor.py` 与 `webapp/shutdown.py` 的当前实现。建立的是三个物理边界明确、分别积分的研究单元；它们尚未连接为某一参考发动机的完整关机与再启动模型。

来源设计记录提供项目与方案追溯。默认容积、阀序、热容量、换热系数、泵图、转动惯量等属于独立研究算例，不能视为 Merlin、Raptor、天鹊或其他实机的已知数据。改变参考机型不会自动把这些假设变成实机参数。

## 1. 三个研究单元的职责

| 单元 | 主要连续状态 | 本次新增过程 | 当前边界 |
|---|---|---|---|
| 气相关机与给定再点火 | 气体质量、温度、物种质量分数、壁温、两个实际阀位 | 首次供给与热脉冲、关阀、余气排出与热浸、再次供给与第二次热脉冲 | 300–3000 K 理想氧气/甲烷化学体系；入口和出口带理想止回；无液体喷注与转子 |
| 残余工质泄放与再充填 | 质量 `m`、总内能 `U`、壁温、入口和出口实际阀位 | 关入口、开泄放、持续气液库存与壁面热交换、再次充填 | 纯工质均相热力学平衡；排出均相混合物；无空间液位、气袋、吹除气和反流 |
| 轴系惰转与液压反流 | 容腔压力、两支路有符号体积流量、阀位、有符号轴转速 | 驱动力矩撤除、关阀、转子惰转、反流、恢复驱动力矩与再开阀 | 满液单相、小压缩；冻结物性；外给驱动力矩；无热状态、气蚀或排空 |

这一区分避免两个物理错误：一是把满液小压缩容腔的质量变化当成液体排空；二是把 HEOS 的低温液体焓或两相末态直接接入 Cantera 理想气相反应器。

## 2. 事件、状态连续与结果含义

关阀、泄放、再次供给和点火均为用户给定事件。所有指令斜坡端点与热脉冲端点进入积分分段。重新初始化积分器用于处理边界条件变化，物理库存、温度、组分、实际阀位、转速与累计账目连续传递。

- 关阀指令到零不代表实际阀位瞬间归零。
- 撤除驱动力矩不代表轴转速瞬间归零。
- 再次供给不重置容腔质量、温度或组分。
- 再次驱动不重置轴转速。
- 第二次点火脉冲不强制修改气体温度，也不强制生成燃烧产物。
- `complete=true` 表示请求时间段在该模型适用域内完成计算；守恒 `pass` 表示数值账目闭合。两者均不是发动机再启动成功判据。

事件表的 `observed` 只表示积分已到达给定事件时刻。若提前越域，未到达事件保持未观测；相关再启动末态指标返回空值。最终快照明确禁止作为已验证整机初始化状态自动覆盖其他模块。

## 3. 气相关机、热浸与给定再点火

### 3.1 守恒与化学反应

固定容积、完全混合反应器复用 `IgnitionModel` 的 Cantera GRI-Mech 3.0 有限速率化学方程。物种质量和总内能满足：

```text
dm_k/dt = Σ(mdot_in Y_k,in) − mdot_out Y_k + V W_k omega_k
dU/dt   = Σ(mdot_in h_in) − mdot_out h + Q_ign − UA(T − T_wall)
C_wall dT_wall/dt = UA(T − T_wall) + UA_amb(T_amb − T_wall)
```

Cantera 物种热力学含生成焓，代码不额外添加低位热值。化学放热率作为诊断输出，不重复作为能量源项。化学机理在整个时间区间内保持启用，或作为对照在全过程关闭；没有以事件标签强制开关反应的替代模型。

两次给定热脉冲均按 `能量 / 持续时间` 输入。热脉冲开始与结束强制成为积分分段，不依赖绘图采样点是否恰好覆盖短脉冲。第二次脉冲允许能量为零，以研究热残留及再次供给自身的响应。

### 3.2 阀门和排气

阀位采用一阶执行机构并限制变化速率：

```text
da/dt = limit[(a_command − a)/tau, −rate, +rate]
```

关机指令把两入口目标开度降至零；再次供给恢复各自第一次供给的最终目标开度。气相入口和出口使用瞬时冻结比热比及气体常数的准稳态可压缩节流公式，含未壅塞与壅塞分支。逆压差由本单元明确的理想止回条件阻断，不能用本页结果解释燃气向供给端反灌。

停止供给后，残余气体仍可反应、排出并与壁面换热。当壁面比气体热时，壁面向气体回热；不把换热项强制截成单方向。壁温由同一热容量方程连续演化。

### 3.3 默认事件与限制

默认气相研究算例持续 6 s，初始为 1 L、0.1 MPa、300 K 氮气，给定壁温 600 K；首次外加热 1500 J，2 s 开始关阀，4 s 再次供给，4.3 s 施加 500 J 第二次热脉冲。该预热壁和热脉冲是研究输入，不代表实际发动机测量。

不含雾化、液滴蒸发、局部点火核、燃烧不稳定、火焰传播或喷管推力预测。300–3000 K 是本实现采用的共同气相热物性温度域，不能用温度钳制延长域外计算。压力响应参考线仍不是点火延迟、熄火或再点火成功判据。

## 4. 残余工质泄放、壁面余热与再充填

### 4.1 库存闭合

复用 `ChilldownModel` 的纯工质 HEOS 闭合与独立质量、总内能状态：

```text
dm/dt = mdot_in − mdot_out
dU/dt = mdot_in h_source − mdot_out h_cell + Q_wall
rho   = m/V
u     = U/m
(p,T,phase,quality,...) = HEOS(rho,u)
Q_wall = UA(T_wall − T)
C_wall dT_wall/dt = UA_amb(T_amb − T_wall) − Q_wall
```

同一工质的入口焓、出口焓及容腔内能使用同一个 HEOS 参考态。相变潜热已包含在 EOS 中，不另加潜热热源。两相时根据质量干度与饱和相密度换算气液质量和体积分数；超临界状态不虚构气液分界。

入口和出口采用准稳态 HEM 等熵孔口模型，并通过最大质量通量确定临界限制。它不是带流动惯性的管段模型。两侧均带理想止回，不允许该单元出现有符号反流。

### 4.2 排放口和阀序

出口取走容腔的均相混合物及其焓，不能解释为只抽走液体的低点排液口或只排出蒸气的顶部放空口。代码不解析分层、死区残液、液面位置、非凝气体置换或移动充填前沿。

入口和出口分别有“初始、关机、再次开启”三组目标开度。默认纯氧示例：

| 条件 | 默认值 |
|---|---:|
| 容积 | 0.1 L |
| 初始状态 | 0.4 MPa、质量干度 0.02 的纯氧平衡库存 |
| 初始壁温 / 壁面热容量 | 120 K / 20 J/K |
| 单液相储源 | 0.8 MPa、90 K |
| 背压 | 0.1 MPa |
| 初始入口 / 出口开度 | 0.2 / 0.1 |
| 0.3 s 后关机入口 / 出口目标 | 0 / 1 |
| 1.8 s 后再次入口 / 出口目标 | 1 / 0 |
| 指令斜坡 / 总时长 | 0.1 s / 3 s |

物性输入支持 Oxygen、Methane、n-Dodecane 纯工质。n-Dodecane 不是实际 RP-1 混合物。改变工质时必须同时给出在其无固相、物性有效域内的一致初态与储源条件。

### 4.3 排空和再充填指标

结果提供总质量、液相质量、蒸气质量、相态、壁温、累积进出质量及最小采样库存等。达到背压后不会把库存强制设成零；仍保留由 EOS、能量和边界流量确定的状态。

最小库存是输出采样的最小值，不能声称捕捉了所有采样间极值。当前 `complete_drain`、`ignition_success`、`restart_success` 均不自主判断。壁温与液相体积分数阈值只是研究检查条件，不构成实机再启动许可。

## 5. 轴系惰转、反流与再次驱动

### 5.1 水力方程与符号

每个独立回路包含固定压储源、泵支路惯性、满液容腔，以及执行阀出口支路惯性。`Q_in > 0` 表示储源经泵流向容腔，`Q_out > 0` 表示容腔流向背压端。负值保留为反流。

```text
C     = V/K
L_in  = rho*l_in/A_in
L_out = rho*l_out/A_out
C dp/dt       = Q_in − Q_out
L_in dQ_in/dt = p_tank − p + Delta_p_pump − R_in Q_in|Q_in|
L_out dQ_out/dt = p − p_back − R_out Q_out|Q_out| − Delta_p_valve
m = rho [V + C(p − p_initial)]
```

密度 `rho` 和体积模量 `K` 冻结为给定值。容腔是初始满液的小压缩模型，质量变化反映弹性库存，不能用于预测排空。管段固定液体库存不作为可排空状态。

阀面积比与压降为：

```text
A_effective/A_full = leak + (1 − leak)*a
Delta_p_valve = Delta_p_valve,ref * q_out |q_out| / (A_effective/A_full)^2
```

其中 `q_out=Q_out/Q_ref`。本单元零指令保留显式 `leak_fraction`，不能表述为理想完全封死。默认泄漏面积比为 0.02，属于研究假设。实际开度由一阶滞后与限速方程积分；只对积分器试探状态的流通面积作区间外延拓，不钳制实际输出阀位、流量或转速。

### 5.2 转矩平衡

新增独立转速状态 `omega`：

```text
J d(omega)/dt = torque_drive − torque_pump − torque_friction
torque_friction = b*omega + c*omega*|omega|
P_friction = torque_friction*omega >= 0
```

`J` 是给定转动惯量。`b,c >= 0` 保证摩擦耗散不为负。当前没有静摩擦、库仑摩擦、轴承间隙或卡止事件，所以不预测真实静止时刻；仅计算该摩擦假设下的连续惰转过程。

初始外给驱动力矩为：

```text
torque_drive,initial = drive_torque_scale *
    [torque_pump(initial n,initial q) + torque_friction(initial omega)]
```

默认倍数为 1，使初始转矩平衡；初始水力条件是否平衡仍由独立压力、流量和损失条件决定。关机斜坡将外给驱动力矩降至零，再驱动斜坡恢复原值。恢复的是力矩，实际转速始终通过动力学方程得到。

**外给力矩不是涡轮功率预测。** 当前没有预燃室、燃气发生器、涡轮排气、启动器、电机或控制器与轴系的耦合。它可以用于给定力矩撤除/恢复下的响应研究，不能证明 GG 或 FFSC 能够自行再启动。

### 5.3 四象限泵图

复用 `evaluate_pump_map`，归一化定义为：

```text
n = omega/omega_ref
q = Q_in/Q_ref
theta = atan2(q,n) mod 360 deg
WH = Delta_p_pump / [Delta_p_ref*(n^2+q^2)]
WB = torque_pump / [torque_ref*(n^2+q^2)]
torque_ref = Delta_p_ref*Q_ref/(eta_ref*omega_ref)
```

Suter 表要求 0°/360° 周期闭合、角度递增、45° 的 `WH=WB=0.5`，并检查顶点和实际分段线性插值的被动性。零转速没有除以当前转速的操作。

默认采用解析演示曲线：

```text
Delta_p_pump = Delta_p_ref [(1+s)n|n| − s*q|q|]
torque_pump = Delta_p_ref*Q_ref/omega_ref *
    [(1+s)|n|q + (1/eta_ref − 1 − s)n|n|]
```

约束 `0 < s <= 1/eta_ref − 1`，使所有象限的 `P_pump.loss = torque_pump*omega − Delta_p_pump*Q_in` 非负。这条曲线在 `n=0` 时给出零泵力矩，只保证演示模型有限、连续且被动；不能代表实际泵的静止流动力矩、自起转或反流起转特性。真实分析须导入具有出处和标度说明的全象限数据。

### 5.4 联合能量审计

液压储能采用与绝对边界压力一致的零压力参考：

```text
E_hyd   = 0.5*C*p^2 + 0.5*L_in*Q_in^2 + 0.5*L_out*Q_out^2
E_rotor = 0.5*J*omega^2
P_boundary = p_tank*Q_in − p_back*Q_out
P_hyd.loss = Delta_p_in.loss*Q_in +
    (Delta_p_out.loss + Delta_p_valve)*Q_out
P_pump.loss = torque_pump*omega − Delta_p_pump*Q_in

Delta(E_hyd + E_rotor) = integral[
    P_boundary + torque_drive*omega − P_hyd.loss − P_pump.loss − P_friction] dt
```

代码分别积分边界功、泵液压功、液压耗散、泵轴功、泵内损失、驱动功和摩擦功，并独立检查液压能、转动能及联合能量；不以两个较大错误相互抵消来接受结果。质量另以净边界质量积分核对。

反流时若 `torque_pump*omega < 0`，泵可向轴系返还机械功，符号不会被截断。是否发生及大小由泵图和给定压差决定。

### 5.5 默认事件、数值精度与观察指标

默认是两个互不耦合的研究回路：额定转速均 6000 rpm、额定泵压升 1 MPa；给定氧侧密度 1140 kg/m³、燃料侧 422 kg/m³。1 s 开始撤矩/关阀，3 s 再驱动/再开阀，指令斜坡均 0.15 s，总时长 5 s。

|---|---:|---:|---:|---:|
| 1e-6 | 31 | 5716.209879479657 | 1084811.0227782677 | 2.1461448795889737e-7 |
| 1e-6 | 1001 | 5716.209879479657 | 1084811.0227782677 | 2.1461448795889737e-7 |

## 6. 适用域终止与下一阶段接口

气相单元检查每个 CVODES 接受步的温度、压力、组分与阀位；库存单元检查 EOS、无固相温度域、压力及阀位；轴系单元检查满液压力下限、小压缩应变、泵图速度/流量域、泵被动性与阀位。越域时停止并保留有效结果。取消属于用户控制流，不伪装为数值或物理失败。

轴系采用 Radau 积分并定位连续适用域边界，守恒最大误差在内部接受步逐回路检查，独立于输出采样点数。集总惯性可以表示有限流动响应，但不等同于沿管路传播的水击波模型，不能直接用于预测实际水击峰值。

后续形成完整发动机模型需要：具有一致质量/组分/能量基准的液体喷注与蒸发接口；有气液相态与空化适用域的泵和涡轮模型；可追溯的阀序、转动惯量、低速/反流图和摩擦数据；经试验辨识的换热及余热模型；以及点火成功、延迟、熄火和再启动准入的独立实验判据。当前三个单元的快照保存用于追溯，不自动跨这些未建立的接口互相拼接。

## 7. 网页使用与记录追溯

1. 打开已完成设计记录，进入“系统仿真 → 关机与再启动分析”。来源只用于推进剂适用性与方案追溯；本页初态、容积、壁面、泵图、驱动力矩及事件参数独立设置。气相单元限氧气/甲烷，不使用煤油来源代替验证。
2. 选择研究单元，核对时间设置、关阀与再次供给时序，再展开相应的气体/气液/全液初态和边界。默认值为研究示例，不能当作参考发动机的实际关机或再启动程序。
3. 运行后查看事件表、时间截面、响应曲线及过程指标。比较关阀前后、停留末端和再次供给后的库存、壁温或转速；守恒表和终止原因用于判断当前模型的数值有效范围。
4. 使用历史记录选择器回看冻结输入和结果；修改上方参数不会改变已保存记录。可导出 CSV、SVG、完整 JSON 和末态快照 JSON。取消或越域留下的有效时间段不能解释为全过程完成。

页面同时保留原设计的约束状态。三个单元的计算完成、守恒通过或转速恢复，均不改变原设计结论，也不生成整机再启动成功判定。详细操作见 [本机网页版说明](WEB_LOCAL.md#关机与再启动分析)。
