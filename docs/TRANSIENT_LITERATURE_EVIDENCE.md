# 瞬态建模文献证据与适用边界

核读日期：2026-10-22。本文以 `literatures/` 中的本地原始 PDF 为依据，页码均为 **PDF 文件从 1 开始的页码**，另列印刷页码时会注明。批注属于阅读材料，不作为任务指令。已核读四篇核心论文和三篇补充论文的建模、初始条件、结果与验证章节，并渲染核查存在 OCR 歧义的公式页。本文提出的实现建议与作者原文结论分别标明；本文本身不构成本平台的试验验证。

## 1. 对平台建设的直接结论

应从稳态工作点进入有明确假设的 **热态、零维、集总参数动态响应分析**，逐步扩展到完整启动、关机和再启动。瞬态能力应来自质量/能量存储、流体惯性、轴系转动惯量、壁面热容及执行机构动态方程，不能把已有节流稳态结果沿时间轴插值或平滑后称为发动机启动仿真。

现有稳态记录可以提供初始压力、温度、流量、功率、组分、喉部面积和轴速；它不能唯一确定容腔体积、轴系惯量、低速泵图、阀门流量曲线、管路惯性、点火条件和预冷状态。因此，来自设计记录的值、用户输入、工程估计以及借用文献值必须分开标注。缺少试验数据时只能给出模型预测、敏感性或假设下的响应，不能给出“实机已验证”的结论。

## 3. 必须处理的原文公式歧义

下列内容已通过页面渲染核对，不能仅归因于文本提取错误。

1. **Zhou 2021 PDF p.3 Eq.(4)** 印成 `theta = pi + (nu/alpha)`，缺少反正切。Di Matteo 2011 p.7 Eq.(1) 与 Liu 2025 p.4 Eq.(4) 明确为 `pi + atan(nu/alpha)`。平台应按 Suter 曲线自变量定义及象限约定实现，记录来源差异，并用零速/反流连续性测试验证。
2. **Liu 2025 PDF p.4 Eq.(10)** 将流量导数写成压差除以 `P_pump`；该符号在同文 Eq.(11) 明确定义为机械功率，量纲不闭合。根据其 Eq.(3) 及动量守恒，集总体积流量模型应使用流体惯性 `I_Q = rho*L/A`，即 `I_Q*dQ/dt = delta_p_drive - delta_p_loss`，而非除以泵功率。Satoh 2020 PDF p.8 Eq.(28) 明确给出压差除以 `I` 的相同结构，可作独立参照。此处是本文的守恒重写，不声称是作者勘误。
3. **Liu 2025 PDF p.7 Eq.(32)** 将组分库存写成出口减入口；与其正向流量定义及 Eq.(33) 的入口减出口不一致。平台统一“进入控制体为正”：`dm_k/dt = sum(mdot_in*Y_in,k) - sum(mdot_out*Y_k) + source_k`。化学反应质量源总和为零，元素守恒单独检查。
4. **Liu 2025 PDF p.6 Eq.(30)** 文本提取会丢失分数线；页面实际为 `D_h = 4*A_tube / ((pi*W+2*(H-W))*n_tube)`，不是乘以周长。图像核对后无须将它列为作者错误。
5. 所有论文中的 `N`、`n`、`omega` 和 `rpm` 含义并不完全一致。平台机械功统一使用 `P = torque*omega`，`omega = rpm*2*pi/60`。近零速用转矩图，不能用未正则化的 `P/omega`。

## 4. 可执行的公共模型骨架（平台设计建议，非论文逐式复刻）

### 4.1 最小状态和守恒方程

| 对象 | 可积分的状态 | 基本关系及条件 |
| --- | --- | --- |
| 气体/液体容腔 | 质量 `m`、内能 `U`、必要的组分或元素库存 | `dm/dt=sum(mdot_in)-sum(mdot_out)`；`dU/dt=sum(mdot_in*h_in)-sum(mdot_out*h_out)+Qdot+Wdot`。用同一热力学基准求 `P,T`。 |
| 有惯性支路 | 质量或体积流量 | `I_Q*dQ/dt=delta_p_drive-delta_p_loss`；若用质量流量，惯性系数需对应变换，不能混用。 |
| 转子/轴系 | `omega` 或在适用范围内的转动能 | `J*domega/dt=tau_turbine-tau_pump-tau_loss+tau_start`；单轴共用一个状态，FFSC 双轴分别积分。 |
| 壁面 | 一个或多个 `T_wall` | `C_wall*dT_wall/dt=Q_hot-Q_cool+Q_conduction`；瞬态储热必须计入系统能量审计。 |
| 阀门执行机构 | 实际开度 `a` | 可从显式标记的一阶执行器 `da/dt=(command-a)/tau` 起步，有限行程/速率；流量仍由压差和阀门流量特性决定。不能把推力响应时间常数当物理执行器参数。 |
| 喷管 | 首版可无独立动态状态 | 按固定 `A_t`、当前主室状态和背压计算流量/推力；检查壅塞和有效域，拒绝无适用模型的低压/两相状态。 |

燃烧能量使用两种约定之一并固定下来：含生成焓的组分总能量，或显热加显式反应热。二者不可叠加，否则重复计算化学热。开放 GG 与 FFSC 需要明确各股质量与化学能的去向，尤其 GG 排气的外排以及 FFSC 预燃室-涡轮-主室之间的流体库存。

### 4.2 三个能力级别

1. **热态工作点响应研究**：从有效稳态状态启动；用户明确额外动力学参数；采用有边界的局部部件特性，输出质量/能量/轴功残差、超调、响应时间与热裕度。只能描述模型有效域内的扰动响应。
2. **完整热态节流与关机**：加入覆盖目标工况的图谱、容腔、执行器、管阻、状态相关物性和排空/反流处理。停止时仍需遵守库存守恒。
3. **冷启动与再启动**：在前两级之外，还需要预冷/残液/非凝气、点火器、最低点火条件、启动能量或扭矩、两相/空化/壅塞切换及事件逻辑。只有输入齐备且验证完成后，才开放相应实机分析声明。

### 4.3 GG/FFSC 迁移要求

- **开式 GG 单轴**：同轴氧泵、燃料泵与涡轮共享同一轴速；GG 质量外排及排气推力与主喷管分开；发生器初始容积/组分、主室/发生器点火时序应独立。
- **开式 GG 双轴**：两根轴分别有惯量和负载；并联燃气分流及共用入口/背压的假设必须显式。不能把一个总功率状态假装成独立轴动力学。
- **FFSC**：富氧/富燃预燃室均保留状态，两根轴分别积分；主室背压同时影响两涡轮；交叉供给支路压差与阀门流量需要同时满足；预燃室燃气组成与主室混合不能忽略。
- **氢氧膨胀循环**：热回路是启动动力来源，必须有热状态和相态描述；本平台当前液氧甲烷/煤油示例不能仅通过换燃料名称获得 RL10 模型。

## 5. 数据门槛、数值检查与验证记录

在每次任务记录中保存：源设计记录 ID/hash、模型版本、结构连接、物性库/机理版本、假设、参数单位/来源/不确定度、初始状态、边界/事件表、积分器/容差、采样间隔、有效域事件和已完成输出。

需要额外获取或明确估计的数据包括：泵四象限或至少覆盖工况的扬程/转矩/效率图；涡轮有效通流面积/转矩图；各轴等效惯量/摩擦；腔体与集流腔容积；管路长度/面积/粗糙度；阀门 `CdA(opening)`、行程和动作时间；壁面几何/材料热容/导热系数；供给动态；点火延迟和许可条件；预冷、初始相态与余量。**一条稳态结果无法辨识这些参数。**

验证分四层，各自给出状态：

1. **数值正确性**：步长/容差收敛，正质量/温度、有限数值，事件时刻一致，稳态初值的零指令漂移。
2. **物理守恒**：逐容腔及总系统累计质量、元素和能量余额；轴储能增量与净轴功积分一致；壁储热与净热流一致。积分残差阈值随量纲与规模定义。
3. **模型覆盖**：泵图、相态、燃烧组分、壅塞、阀门、冷却等是否处于有效域。越界停算或标为不可解释，不能静默钳制为漂亮曲线。
4. **试验验证**：相同硬件/边界/阀序/初始条件下的独立测量；分开标定集与留出验证集，报告误差带和传感器延迟。无实测时明确“未验证”。

敏感性应优先看轴惯量、容腔体积、阀动作时间、泵/涡轮特性、壁热容量和换热系数。试验对齐优先输出 `t10/t90`、10%-90% 上升时间、指定稳定带内的整定时间、超调、峰值温度/压力/轴速、累计推进剂消耗和冲量，并明确以命令还是点火时刻计时。

## 6. 对稳态功能的反哺

这些瞬态论文也说明现有稳态模块应逐步补足：固定硬件下部件图匹配、低推力冷却有效域、供给压差裕度、单独的燃烧/喷管/轴效率定义，以及名义点/实测点分离的误差表。瞬态积分的最终平衡点应与同一硬件、同一边界和同一物性口径的稳态方程比较；如果稳态模块允许重新设计几何或重新指定压降，不能直接拿那个结果当瞬态末点真值。

## 7. 三篇补充论文

### 7.1 Zheng 等 2025：直接针对液氧甲烷 FFSC 的启动研究

**书目。** Lihao Zheng、Nanjia Yu、Sihan Di、Chuang Zhou、Shan An、Haodong He，*Research on Start-up Characteristics of Liquid Oxygen Methane Full Flow Staged Combustion Cycle Rocket Engine*，收录于 P. Daponte 编 *Mechanical and Aerospace Engineering*，IOS Press，2025，pp.156-167，DOI `10.3233/ATDE250334`。本地 `literatures/ATDE-71-ATDE250334.pdf`，12 页。

- PDF p.2，§2：研究对象为以 Raptor 为参考的 2300 kN 级甲烷/氧 FFSC；包括两预燃室、两涡轮泵、四个预燃室供给阀、冷却阀、强迫启动装置。阀前管路和泵在启动前已经预冷。首阶段转子启动，再充填冷却通道，再依次预燃室/主室点火，最后撤去启动装置。**不是不带预冷假设的任意冷起动。**
- PDF pp.3-5，Eqs.(1)-(12)：真实流体物性、Suter 泵图、涡轮等效流通、集总质量/能量守恒、CEA 生成的产物表、分段冷却壁导热/热容。这些组成支持本平台的模块化路线。

- PDF pp.7-8，Table 2、Figs.4-5：给出压力延迟、上升、峰值、调整时间与超调，主室超调约 12.42%，两预燃室约 8.3%。这里的数值是所建模型的输出，不是平台校验真值。
- PDF pp.9-11，Figs.6-9：研究冷却阀开启时刻、两预燃室点火间隔、强迫启动功率及持续时间。可借鉴“事件表 + 参数扫描 + 超调/稳定时间/供给裕度”分析界面。
- PDF p.1 摘要写 **推迟** 富氧预燃室点火降低主室超调，p.12 结论第 3 条写 **提前** 富氧预燃室点火；p.10 正文又说明先固定富氧 0.4 s、改变富燃时刻。该方向性表述前后不一致，应回到各工况和图曲线核实，不能直接生成为普遍控制规则。

### 7.2 Satoh 等 2020：参数同化的价值与可辨识性限制

**书目。** Daiwa Satoh、Seiji Tsutsumi、Miki Hirabayashi、Kaname Kawatsu、Toshiya Kimura，*Estimating model parameters of liquid rocket engine simulator using data assimilation*，*Acta Astronautica* **177** (2020) 373-385，DOI `10.1016/j.actaastro.2020.07.037`。JAXA，在线发表 2020-08-04。本地同名 PDF，13 页。

- PDF p.3，Table 1：对象为液氢/液氧膨胀排放循环 RSR，40-100% 节流。27 个观测量来自 100 Hz 采样的地面试车，拟合输入取关机前最后 10 s 的 100% 工况平均值。它不是用时间序列自动辨识所有启动参数的工作。
- PDF p.4，Eq.(7)：`J*domega/dt = T_t - T_p - delta_T*k_dT`；PDF p.8，Eq.(28)：`I*dQ/dt = rho*g*H - (P2-P1)`。这两式是平台集总轴系/流体惯性模型的直接参考。
- PDF pp.5-6，Eqs.(20)-(27)：EnKF 使用观测模型、协方差、卡尔曼增益及归一化 RMSE；24 个参数对 27 个观测量。PDF p.9，§6.3 使用 100 个集合成员、20 次迭代。可借鉴自动标定、残差与参数不确定性展示，不应把仿真值充当观测值。

- PDF p.8 明确指出 `I`、`J` **按 Case A 瞬态手工调整**，涡轮效率用部件试验数据固定，并非由稳态 EnKF 自动识别。稳态方程中储能项为零，所以单稳态点本来无法确定这些惯性参数。
- PDF pp.9-11，Figs.11-13：标定的 100% 稳态主要量误差在 2.3% 内；40% 段出现偏差，温度预测尤其受热质量缺失和工况相关换热系数影响。关机转速衰减也有偏差。**100% 标定通过不能推出全节流、启动和关机均通过。**
- 平台建议：保留可辨识参数表、观测单位/不确定度/时间对齐、标定工况范围、留出验证记录及物理约束。当前没有用户试验数据时，只做接口和方法准备，不能产出“已完成 EnKF 验证”。

### 7.3 Majumdar 与 Flachbart 2003：管路水击需要空间离散

**书目。** Alok K. Majumdar、Robin H. Flachbart，*Numerical Modeling of Fluid Transients by a Finite Volume Procedure for Rocket Propulsion Systems*，NASA Marshall Space Flight Center，ASME 2003 会议论文。本地同名 PDF，8 页。文件首页与下载页脚可确认 2003/ASME，本文不推断未核实的 DOI 或论文编号。

- PDF pp.2-3，Eqs.(1)-(8)：节点解质量、能量、状态方程和必要组分，支路解动量；库存随时间变化，压力通过真实流体状态方程与可压缩性闭合。摩擦采用带方向的流量乘绝对值，保证总是阻碍流动；能量采用上风输运。
- PDF p.4，数值流程：质量/动量/库存方程用 Newton-Raphson，能量和组分逐次替代，物性与状态循环更新。归一化最大修正量小于 0.001 是该文使用的迭代标准，不是所有平台任务的通用精度证明。
- PDF pp.5-6，Table 1、Figs.4-5：比较 5/10/20 支路网格，水、液氧、液氢急关阀案例；与特征线法的周期和峰压作比较，网格加密使峰压接近特征线法，但衰减和波形仍存在差异。
- PDF p.8 结论：两相混合、冷凝和并联管路案例是数值展示，作者明确仍需更多试验或其他方法比较。应区分“和数值基准一致”与“已试验验证”。
- 对本平台的边界：一个总容腔/总惯性零维模型可以计算集总低频响应，不能解析沿管传播的水击、局部压力波峰或声学不稳定；这些功能需网格、物性可压缩性、时间步/网格收敛与单管基准。本文 PDF p.5 对 Courant 数的写法与常用 `a*dt/dx` 相反，不能按提取文本直接设定稳定性规则；应以具体离散格式和收敛研究为准。
