# 涡轮总体设计与 CFturbo 任务书

平台负责循环匹配、涡轮轴功需求和燃气物性，CFturbo 负责子午面、叶排和叶型设计，Fluent/CFX 等负责后续流场计算。导航“涡轮总体设计”读取选中的计算记录，优先显示设计点和燃气交接数据；“部件性能分析”保留循环中的涡轮状态和轴功概览，可直接跳转到同一台涡轮的任务书。

## 操作

1. 在参数分组“涡轮总体设计与交接”确认热力状态口径。默认“未指定”只交付系统节点量，不把它们自动改名为总压、总温。
2. 若项目采用零维总态储腔接口，可显式选择总总状态口径，再运行新设计点。该选项登记一个接口假设，不执行流速或总静转换，也不改变原循环数值。实际截面静态仍由部件设计确定。
3. 打开“涡轮总体设计”，选择对应计算记录及实际轴系。检查状态、来源、缺项和冲突，下载 JSON、CSV 或 Markdown 任务书。
4. 在 CFturbo 的 Global setup 中按已确认定义录入流量、转速、入口总态及总总压比，建立相同燃气物性，再设计子午面和叶型。任务书为数据交接文件，不能声称是 CFturbo 原生工程或直接导入接口。

历史记录不调用当前物性库补算，也不补默认燃气、总态或几何。新增采样必须运行新记录，旧数据继续保留。尚未收敛、缺少依据或存在冲突的数据会显示具体原因。

## 数值口径

- 输入的压力和温度使用 SI 保存，界面换算为 MPa、bar、K 或 °C。同一组件优先读取 Pa/W 原始字段，工程单位副本仅用于旧格式兼容。
- `πtt = pt,in / pt,out`。没有出口静压时不提供 `πts`，也不利用概念流道倒推静压。
- `ṁ Δhs` 是等熵参考功率；`ṁ Δh` 是涡轮流体做功。GG 机械传动效率再用于轴端可用功率与泵负荷比较，避免重复扣损。
- 循环的涡轮效率与 CFturbo 的附加总静效率不是同一参数。页面不把前者复制到 `ηts+`。
- FFSC 分别交付富氧和富燃涡轮；GG 单轴只有一台共轴涡轮；GG 并联双轴采用各自分流量、转速和出口状态。

## 燃气交接

每次求解按本次实际机制和冻结入口组成保存完整质量分数、分子量、气体常数、入口/出口物性，以及覆盖本次出口至入口温度区间的 11 点物性表。表中包含 cp、cv、γ、密度、比焓、比熵及可用的输运性质；表为固定入口压力下的冻结组成采样，不是沿程流动解。

记录同时保存机制文件、阶段名称、SHA-256、参与物种热力数据、温区及适用性说明。取值后恢复共享 Cantera 对象状态。读取历史记录只审计保存数据和指纹，不用新库版本重新生成数值。

当前燃气 EOS 仍是温度相关比热的理想气体混合物，不能因使用了 Cantera 就声称高压真实气体已验证。在 CFturbo 中应核对组成基准、cp(T)、焓熵基准和 EOS；选择不同模型后需要重新核对焓降和功率。范围外采样或缺失物性会明确标注。

## 可选均径一维初选

默认关闭，可选择等比功分配或自定义各级比功比例。输入包括保存级数、中径/转速、轴向速度系数、反动度目标；自定义比例数量须与级数一致且总和为 1，不自动归一化。GG 单轴使用燃料侧约束。

采用各级相同中径、相同轴向速度。给定 `ca = φU`、每级实际比功 `Δh` 和目标 `R` 后：

```
cu1 = U(1-R) + Δh/(2U)
cu2 = U(1-R) - Δh/(2U)
wu1 = cu1-U; wu2 = cu2-U
Δh = U(cu1-cu2)
```

角度从轴向量起，正切向与转动同向。输出绝对/相对速度、流角、级负荷系数及欧拉功闭合。`R = 动叶静焓降 / 级欧拉比功`；解释为级反动度还要求重复级 `c0=c2`。它是给定约束下的运动学解，不是反动度或负荷的优化结果。尚未求逐级压力、静温、马赫数、壅塞、损失、入射/落后角、叶片金属角和性能图。

## 一致性审计与概念几何

记录级提示检查同一物理量的单位副本、节点与部件、明确对应的汇总字段、输入快照及已保存几何。冲突列出两个来源和值；缺项表示无法判断，不当成通过。跨页面共用所选记录；切换时先清除上一记录，较慢返回的旧请求不能覆盖新选择。

概念环道仅在折叠区保留，原始快照和坐标不被修改。采用总态接口的新记录不再以总态密度冒充静态密度生成环道。原有近似几何方法详见 [涡轮概念几何说明](TURBINE_GEOMETRY.md)。一致性检查不代表气动、结构或高压燃气物性已验证。
