# 涡轮设计与建模交接

当前 Web 设计范围为液氧甲烷 FFSC，分别处理富氧侧和富燃侧涡轮。平台负责循环匹配、涡轮轴功需求和燃气物性，CFturbo 负责子午面、叶排和叶型设计，Fluent/CFX 等负责后续流场计算。导航“涡轮设计与建模交接”读取选中的计算记录，显示循环设计点、燃气物性和部件初选值，并允许在原记录之上进行独立方案初选；“部件性能分析”保留循环中的涡轮状态和轴功概览，可直接跳转到同一台涡轮的任务书。完整参数映射、Zweifel 方法与后续工作流见 [CFturbo 涡轮建模指南](CFTURBO_TURBINE_HANDOFF.md)。

## 操作

1. 在参数分组“涡轮方案与尺寸初估”确认热力状态口径。默认“未指定”只交付系统节点量，不把它们自动改名为总压、总温。
2. 若项目采用零维总态储腔接口，可显式选择总总状态口径，再运行新设计点。该选项登记一个接口假设，不执行流速或总静转换，也不改变原循环数值。实际截面静态仍由部件设计确定。
3. 打开“涡轮设计与建模交接”，选择对应计算记录及实际轴系。检查状态、来源、缺项和冲突，下载 JSON、CSV 或 Markdown 任务书。
4. 在 CFturbo 的 Global setup 中按已确认定义录入流量、转速、入口总态及总总压比，建立相同燃气物性，再设计子午面和叶型。任务书为数据交接文件，不能声称是 CFturbo 原生工程或直接导入接口。

历史记录不调用当前物性库补算，也不补默认燃气、总态或几何。FFSC 方案新增采样须运行新记录，旧数据继续保留。不支持的历史架构仅提供原始记录导出。尚未收敛、缺少依据或存在冲突的数据会显示具体原因。

## 循环需求与部件初选

“涡轮方案与尺寸初估”提供部件初选假设，“涡轮设计与建模交接”展示计算后保存的循环需求和初估结果。CFturbo 任务书是这些设计条件的一种导出文件。

- 流量、入口燃气状态、出口压力和所需功率来自循环设计点；转速沿用所在轴系的设计转速。FFSC 当前循环匹配不把涡轮速比、级数或反动度作为待求未知量。
- `U/C0` 是按整台等熵焓降定义的速比初选值，用于估算中径。结果中的速比由保存中径、转速和焓降计算，中径限幅可能使它偏离初选值；它不是经性能验证的最优速比。
- 级数来源可选“经验估算”或“指定初选级数”。经验估算保留现有整机速比区间规则，只生成候选级数，不确定冲动/反动类型或速度复合方案，也不证明气动可行。指定级数同样是待校核的部件方案。
- 反动度、轴向速度系数和可选比功分配用于均径运动学初选；节圆速度参考上限用于初步检查。这些假设不会自动通过叶排损失模型反馈为循环效率。

## 数值口径

- 输入的压力和温度使用 SI 保存，界面换算为 MPa、bar、K 或 °C。同一组件优先读取 Pa/W 原始字段，工程单位副本仅用于旧格式兼容。
- `πtt = pt,in / pt,out`。没有出口静压时不提供 `πts`，也不利用概念流道倒推静压。
- `ṁ Δhs` 是等熵参考功率；`ṁ Δh` 是涡轮流体做功。FFSC 当前未另建轴承／密封机械损失预算。
- 循环的整台涡轮等熵效率、机械效率与 CFturbo 的附加流动损失效率分别有独立含义。页面不把前者复制到 `ηm` 或 `ηadd`。
- 当前设计分别给出富氧、富燃涡轮条件。涡轮工作区仅保留富氧与富燃两侧。

## 燃气交接

每次求解按本次实际机制和冻结入口组成保存完整质量分数、分子量、气体常数、入口/出口物性，以及覆盖本次出口至入口温度区间的 11 点物性表。表中包含 cp、cv、γ、密度、比焓、比熵及可用的输运性质；表为固定入口压力下的冻结组成采样，不是沿程流动解。

记录同时保存机制文件、阶段名称、SHA-256、参与物种热力数据、温区及适用性说明。取值后恢复共享 Cantera 对象状态。读取历史记录只审计保存数据和指纹，不用新库版本重新生成数值。

当前燃气 EOS 仍是温度相关比热的理想气体混合物，不能因使用了 Cantera 就声称高压真实气体已验证。在 CFturbo 中应核对组成基准、cp(T)、焓熵基准和 EOS；选择不同模型后需要重新核对焓降和功率。范围外采样或缺失物性会明确标注。

## 随整机记录保存的可选均径初选

默认关闭，可选择等比功分配或自定义各级比功比例。输入包括保存的候选级数、中径/转速、轴向速度系数、反动度初选值；自定义比例数量须与级数一致且总和为 1，不自动归一化。

采用各级相同中径、相同轴向速度。给定 `ca = φU`、每级实际比功 `Δh` 和目标 `R` 后：

```
cu1 = U(1-R) + Δh/(2U)
cu2 = U(1-R) - Δh/(2U)
wu1 = cu1-U; wu2 = cu2-U
Δh = U(cu1-cu2)
```

角度从轴向量起，正切向与转动同向。输出绝对/相对速度、流角、级负荷系数及欧拉功闭合。`R = 动叶静焓降 / 级欧拉比功`；解释为级反动度还要求重复级 `c0=c2`。它是给定约束下的运动学解，不是反动度或负荷的优化结果。尚未求逐级压力、静温、马赫数、壅塞、损失、入射/落后角、叶片金属角和性能图。

## 独立交互方案初选

页面的“方案初选”从当前记录取得质量流量、转速与实际焓降，级数、中径、轴向流量系数、反动度约束、等/自定义比功分配、首静叶旋流、静/动叶轴向弦长与 Zweifel 系数作为显式局部方案输入。计算结果与来源记录绑定，但不回写循环、项目输入或历史快照，也不替代随整机保存的均径结果。局部方案不永久保存为整机记录；可下载 JSON/CSV 留存输入、结果、方法和缺项。

采用相同中径与轴向速度的 Euler 初选，显示逐级速度三角形、载荷、气体功率和气动力矩。首静叶入口旋流由用户指定，后续静叶入口承接上一动叶出口；区别 `动叶静焓降/欧拉比功` 与 `动叶静焓降/整级静焓降`，避免把非重复首级的约束参数称为已求解的整级反动度。

静叶与动叶分别按二维不可压 Zweifel 关系估算连续叶片数，给出整数候选并回算节距、轴向稠度和对应 Zweifel 值。这是受弦长和载荷系数影响的候选，尚未完成金属角、厚度、动静干涉或三维可压流动校核。流角自轴向量起，与 CFturbo 周向角度及相对速度符号约定须逐项核对。公式及来源见 [初选方法](CFTURBO_TURBINE_HANDOFF.md#zweifel-叶片数候选)。

初选不使用总态密度生成静态通流面积，不补造逐级压力、温度、马赫数、叶高或详细叶片实体；循环总态缺项也不会因局部方案算出三角形而消失。

方案工程筛查沿用原记录的 `ρmaterial U²` 离心应力量级模型，按 `(Uscenario/Usaved)²` 缩放，并用保存的材料屈服强度重算简化强度比。它不继承旧方案“通过”结论，所有有效结果均标记需复核；缺少依据时保留缺项。屈服强度仍采用原记录温度假设，当前模型以入口气温代替材料温度，未求实际金属温度、真实叶盘/叶根截面、热应力、蠕变、振动或疲劳，不能作为新方案 FEA 或定型依据。方法和限制见 [工程筛查说明](CFTURBO_TURBINE_HANDOFF.md#简化工程筛查)。

## 一致性审计与概念几何

记录级提示检查同一物理量的单位副本、节点与部件、明确对应的汇总字段、输入快照及已保存几何。冲突列出两个来源和值；缺项表示无法判断，不当成通过。跨页面共用所选记录；切换时先清除上一记录，较慢返回的旧请求不能覆盖新选择。

概念环道仅在折叠区保留，原始快照和坐标不被修改。采用总态接口的新记录不再以总态密度冒充静态密度生成环道。原有近似几何方法详见 [涡轮概念几何说明](TURBINE_GEOMETRY.md)。一致性检查不代表气动、结构或高压燃气物性已验证。
