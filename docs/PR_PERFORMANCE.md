# PR 求解性能与验证范围

PR 模型需要真实气体状态反算和非理想化学平衡，不能用理想气体计算的耗时估计整机任务。启用真实燃气受热喷管后，喷管积分中的状态反算也可能比预燃室平衡更耗时。

2026-11-10 的优化保持原 EOS、物种集、物性来源和求解容差：

- HP 化学平衡仅在一次求根内部复用**完全相同温度**的已验收状态，避免 Brent 重算端点和最终根；压力、目标焓或元素库存跨调用时不复用结果。取消任务检查仍在复用之前执行。
- PR-BM 在所有物种均超临界时直接计算相同 Boston–Mathias 表达式的吸引项平方根及其导数，避免同时计算不会使用的亚临界分支。
- 当前温度和组成的混合系数随状态失效；仅改变压力时不重算它们。
- 冻结 HP/SP 状态恢复先尝试有限步长 Newton，导数分别为真实气体的 `cp` 和 `cp/T`。残差和温度步长均满足原精度才接受，否则使用原括区间 Brent 方法。临界根选择、热容和机械稳定性检查仍保留。

本机 Python 3.14.10 / Cantera 3.2.0 的同一保存工况（PR-BM、120 格再生冷却、真实燃气受热喷管）前向闭合，优化前后都执行 8 次内部热力循环。开启相同 `cProfile` 测得 44.05 s → 31.14 s，耗时减少约 29%；其中受热喷管 37.03 s → 24.60 s。该数字包含分析器开销，是一次工况的前向评估，不代表所有方案或完整设计点迭代均有同样提速。

前后节点最大差值：温度 `3.42e-10 K`、压力 `4.59e-6 Pa`、焓 `9.78e-8 J/kg`，质量流量相同。所用工况固定原有解向量和混合比，没有重新完成整机配平；原有轴功率、总体能量和供给网络失败状态保持不变。性能比较不构成该方案的工程验收。

可复现的通用化学平衡微基准：

```powershell
.\.venv\Scripts\python.exe scripts/benchmark_pr_equilibrium.py --repeats 7 --output output/pr_equilibrium.json
```

微基准预热后分别计算相同 16 物种策略下的理想气体、原生 PR、PR-BM，覆盖富氧、富燃和主燃烧附近的氧燃比；每次实际求解，不使用跨工况结果缓存。用 `--profile` 查看热点，计时时应分别比较开启或关闭分析器的同类结果。私人方案与本机性能输出留在 `output/`，不随源码发布。
