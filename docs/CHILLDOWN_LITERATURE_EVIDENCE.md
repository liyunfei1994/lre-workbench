# 预冷与充填：文献证据、模型依据与验证边界

核读日期：2026-10-22。本文服务于平台“预冷与充填”研究模块，区分论文已经展示的能力、本轮采用的简化模型以及尚待建立的能力。文献页码均为 **PDF 文件页码，从 1 开始**；文本行号指 `.cache/literature-review/` 的对应提取文件。提取文本中存在 OCR 和公式排版问题，不能不经量纲、守恒与数值检查直接复制公式。

文档存在、方程守恒或调用物性库均不等于实机验证通过。功能实现和通过情况应以实际代码、计算记录与测试报告为准。

## 1. 研究结论与首版定位

预冷与充填是从供给子系统进入启动分析所必需的一步：需要同时求解金属热量、工质库存和工质热力学状态，不能仅给入口温度施加经验时间延迟。已有稳态设计点不能唯一给出初始壁温、残留气体、液体充填率、管腔体积和传热系数。

本轮合理的首版对象是：**纯推进剂、刚性集总容腔、壁面热容、均相平衡物性、准稳态压差驱动节流口**。它能计算所设边界与热导下的温度、压力、气液库存和壁面降温，并形成有来源记录的初值快照。它不能解析沿管推进的液体前沿、气液滑移、局部干涸、成核延迟、氮气/氦气置换或真实泵空化。

本轮与“供给网络动态”的惯性、四象限泵图及阀门执行机构是互补模块；只有在同一端口能量、相态和库存定义下完成耦合，才可称为两相供给网络。两个模块分别算出结果，并不等于已经形成统一发动机启动模型。

## 3. 首版模型的守恒合同

以下是本平台依据守恒关系重写的实现合同，并非任何论文的逐式复刻。

### 3.1 容腔和壁面

每个刚性容腔体积 `V` 固定，忽略容腔内宏观动能、重力位能和轴功。积分状态为工质总质量 `m`、总内能 `U`、均匀壁温 `Tw`，另积分守恒审计量。壁面热容量 `Cw` 与有效流固热导 `UA` 为明确的模型输入：

```text
ρ = m / V
u = U / m
(p, T, h, s, phase, x) = EOS_flash(ρ, u)

Qwf = UA × (Tw − T)
dm/dt = mdot_in − mdot_out
dU/dt = mdot_in × h0_in − mdot_out × h0_cell + Qwf
Cw × dTw/dt = Qambient − Qwf
```

流体和壁面总能量关系为：

```text
d(U + Ewall)/dt = mdot_in h0_in − mdot_out h0_cell + Qambient
ΔEwall = Cw × (Tw − Tw_initial)         # 常热容量模型
```

刚性容腔没有移动边界 `p dV/dt` 功；压力流动功已经包含在进出焓中，不能额外重复增加 `pQ`。入口射流动能在均匀容腔内耗散，进入容腔的能量应使用上游总焓，而不是节流口喉部静焓。容腔宏观速度视为零时 `h0_cell = h_cell`。焓和内能的零点可为负；应检查 EOS 一致性与能量变化，不能把负比焓或负比内能直接判为非物理。

`UA` 是用户提供或标定的等效热导，单位 W/K；它不是自动计算的沸腾换热系数。固定 `UA` 和固定 `Cw` 可用于研究敏感性、检查能量与建立计算流程，不能声称已预测膜态沸腾、过渡沸腾、核态沸腾的换热转变或淬冷时间。后续引入温变热容时，应积分材料焓得到 `Ewall(T)`，不能继续把 `mwall cp(T) T` 当作壁面总能量。

### 3.2 两相库存与显示量

纯工质平衡两相区取共同温度、压力，气液相热力学平衡。在本轮单容腔中不解析相对速度、分层或液面位置。令 `x` 为蒸气质量分数：

```text
m_vapor = x m
m_liquid = (1 − x) m
1/ρ = (1 − x)/ρ_liquid + x/ρ_vapor
α_vapor = (x/ρ_vapor) / [(1 − x)/ρ_liquid + x/ρ_vapor]
liquid_volume_fraction = 1 − α_vapor
```

质量干度 `x`、空隙率 `α`、液体体积分数必须分别标名。气体质量占比很小，也可能占据大部分容腔体积。不得用 `ρ=(1−x)ρ_liquid+xρ_vapor` 代替上式。

相变已经包含在 EOS 闪蒸和总内能守恒中，不能再把蒸发潜热添加一次。`dm_vapor/dt` 同时受流入、流出和相变影响，不能不扣除输运就标为“蒸发速率”。超临界单相区不定义饱和质量干度；物性库的单相质量干度哨兵值不能直接画成负干度。

当前出口若采用均相混合物状态，则流出携带混合焓，并同时带出气液两相。它应命名为“均相出口/排放”，不能命名为“只排气的放空阀”。只排蒸气需要独立相选择、蒸气出口焓、可用蒸气库存和气液界面模型。

### 3.3 准稳态 HEM 节流口与临界流

对上游静止边界的 `p0,h0,s0`，以平衡等熵路径计算候选截面状态：

```text
s(p) = s0
v(p) = sqrt[2 × (h0 − h(p,s0))]
G(p) = ρ(p,s0) × v(p)
mdot = Cd × A × G_selected
```

在物性有效的压力区间内搜索最大质量通量，判定临界截面。背压仍高于临界压力时采用背压对应状态；背压低于临界压力时保持临界通量，不沿峰值后的下降分支计算。单向阀边界中，反向压差应明确对应关闭，而不是伪称已经模拟反流。

这一流量模型有明确来源：[Waxman 等，NASA 收录的 *Mass Flow Rate and Isolation Characteristics of Injectors for Use with Self-Pressurizing Oxidizers in Hybrid Rockets*](https://ntrs.nasa.gov/api/citations/20190001326/downloads/20190001326.pdf)，PDF p.3 Eqs.(3)–(4)、p.5 Eq.(5)。文中同时指出短流道的非平衡闪蒸会使 HEM 偏离实验，原始曲线不能直接沿低背压下降支使用。其 N₂O/CO₂ 试验不能作为 LOX/CH₄ 阀门的验证。`Cd`、有效面积以及阀门开度关系仍需对应硬件数据。

HEM 假设流动在局部达到热力学平衡、两相无滑移、通过节流口的状态变化准稳态，忽略该流道的库存和动态动量。它没有预测真实气泡生成率，也不等价于已有单相惯性管路、泵图或阀门执行机构。若压力路径跨出物性支持域、闪蒸失败或未能可靠找到临界通量，应显式报错/停止并保留已完成片段，不能静默换成定密度液体公式或把失败结果置零。

### 3.4 初始条件与物性基准

- 单相初态可由 `(p,T)` 确定后得到 `ρ,u`；两相初态应由 `(p,x)` 或 `(T,x)` 确定。饱和线上只给 `(p,T)` 不能唯一确定库存。
- 初始质量和内能必须取 `m0=ρ0V`、`U0=m0u0`。不能在固定 `p,T,V` 之后另任意给一个矛盾的液体库存。
- 工质、EOS 后端、版本、参考态、初态、边界和热参数应随记录保存。不要在积分中切换 HEOS 与 REFPROP 的焓参考态。
- CoolProp 官方说明饱和线上应使用质量干度参数，并警告强行指定错误相态可能得到错误结果；两相路径不能始终强制液相。[高层接口文档](https://coolprop.org/coolprop/HighLevelAPI.html)
- 物性库给出平衡状态，不给出真实传热系数、相变速率、非凝气清除率或整机启动合格判据。[低层接口文档](https://coolprop.org/coolprop/LowLevelAPI.html)支持保留独立工质状态对象；具体可用输入对和有效域仍必须以当前安装版本实际测试。

本次查阅的线上 CoolProp 文档显示 8.0.0，工作区依赖为 7.2.0；引用仅用于概念与接口约定。实现应记录本机实际版本，并针对该版本做状态闭合和相变回归测试，不以网页版本覆盖本机信息。

## 4. 核验要求

| 层次 | 应验证的内容 | 不能替代的证据 |
|---|---|---|
| 初态闭合 | 从 `(p,T)` / `(p,x)` 构造 `m,U` 后反算状态一致；液体、蒸气、两相分别覆盖 | 不能替代工质物性实验误差评估 |
| 密闭绝热系统 | 关闭流口且无环境热量时，`m`、`U+Ewall` 不变；壁流温差驱动正确方向换热 | 不能证明 `UA` 是真实部件值 |
| 开放系统守恒 | 累计入口/出口质量与总库存闭合；边界总焓、壁热与流体内能变化闭合 | 单靠积分附加账本可能共同继承同一错误；还需独立极限算例或后处理积分 |
| 相库存 | `m_liquid+m_vapor=m`，两相总体积为 `V`；质量干度与体积分数相互一致 | 不表示预测了液面或液体前沿 |
| 节流口 | 零压差零流、单向阀反压关闭、非临界到临界连续、低背压通量平台、面积比例；弱可压液体与理想气体极限检查 | 不表示真实阀门 `Cd` 或两相临界流已标定 |
| 数值可靠性 | 减小容差/最大步长后主要结果稳定；相区切换、低库存与压力有效域停止可重复 | 求解器成功不代表模型正确 |
| 结束状态快照 | 每个容腔的 `m,U,V,p,T,phase`、相库存、壁温、工质和物性来源自洽；明确停止原因 | 单容腔快照不等于整机初态，也不证明可以点火 |
| 实验验证 | 对具体工质、几何、流率、边界和传感器位置做壁温、压力、出口状态/流量对比，报告测量与输入不确定度 | 不能把其他论文的发动机验证转移给本平台 |

“预冷目标达到”和“计算成功”应分别显示。用户设置的壁温、液体占比或稳定性门槛是本算例的判据，不是发动机通用启动许可。若未达到，应保留全过程曲线和终态，并显示具体不足；不能为了导出初值把结果改写为通过。

## 5. 后续扩展的必要条件

1. **空间预冷与充填前沿**：串联有限体积节点、支路动量、轴向/径向壁导热；网格与时间步收敛；区分局部湿润、非平衡闪蒸和相变松弛。NASA 2024 的研究指出壁面沸腾结构及温变固体热物性会显著影响低温预冷预测；其结果支持进一步研究这些机理，不能校准当前常数 `UA`。[NASA 研究记录](https://ntrs.nasa.gov/citations/20230016607)
2. **非凝气与置换**：分别积分推进剂和 He/N₂ 库存，求分压、混合物物性及扩散/对流；考虑溶解与释放所需数据。不能把容腔初始 300 K 的纯甲烷气体解释成被氮气吹除的管道。
3. **泵与气液供给耦合**：气相夹带、空化/汽蚀性能、NPSH 或局部饱和约束、诱导轮与低速两相图、转子/起动装置转矩。单纯加上一个温度状态不意味着原四象限泵图在两相条件下仍成立。
4. **真实阀门与排气**：实测 `CdA(position)`、执行机构、开启压力/回差；汽相选择性放空、液相出口、死区与泄漏；相分离和空隙率改变时的端口模型。
5. **发动机启动与关机**：建立匹配实际循环的管路连接、阀序、点火器、点火延迟、燃烧建立、涡轮转矩、主室背压和停机排空模型。每个阶段需要事件和适用域；不得直接用本轮独立容腔的终态替代全发动机初态。

## 6. 本轮参数来源原则

默认体积、热容量、热导、有效节流面积、初始壁温和时间线应明确为可修改的研究示例。没有对应硬件数据时，不冠以 Merlin、Raptor 或天鹊的真实部件参数。采用 `n-Dodecane` 时应持续标记“正十二烷纯组分替代物”，不能把相变、黏度和传热结果称为 RP-1 混合物的已验证性能。

进一步提高精度应首先补全可追溯输入与针对性实验数据，而不是仅增加积分状态或换一个物性库。HEOS/REFPROP 的状态对比、守恒检查、数值收敛和试验对比分别回答不同问题，应分别记录。
