# 涡轮概念几何参考

本功能现已收至“涡轮总体设计”的折叠参考区，设计点和燃气任务书优先展示，详见 [涡轮总体设计说明](TURBINE_DESIGN.md)。以下保留概念几何的定义与历史使用方式；它不约束 CFturbo 的子午面设计。显式采用总态接口的新记录不再生成基于旧静态参考假设的环道。

概念几何读取选中的计算记录，提供轴流涡轮的环形流道主尺寸、等比例二维子午面、可旋转三维流道边界和 CAD 参考数据，不是完整叶片设计或已经验证的 CFD 模型。

## 使用

1. 后端更新后，在无任务运行时重新启动本机服务，再刷新网页。
2. 在参数分组“涡轮总体设计与交接”检查速比、级数和几何假设。转速沿用同轴泵的系统计算结果；GG 单轴使用燃料侧涡轮假设和实际共轴转速。
3. 进入“涡轮总体设计”，选择已保存概念环道的计算记录与涡轮，展开概念流道参考。尺寸和导出读取保存结果，不随当前未计算的参数草稿变化。
4. 导出轮毂／机匣 TXT 或 DXF，在 CAD 中建立子午流道；结合 JSON 设计点继续气动设计。OBJ 用于三维曲面参考，不是制造实体。

旧记录未保存新增几何假设时，仅列出能追溯的系统设计点及缺失原因，不用最新默认值补造历史几何。必须确认参数并运行新设计点才能生成完整流道。

## 布局与尺寸口径

| 循环布局 | 涡轮及输入 |
|---|---|
| FFSC | 富氧、富燃各一台，分别读取对应组件流量与转速。 |
| GG 单轴 | 一台共轴涡轮，使用 `fuel_turbine_*` 几何假设；实际转速从该涡轮组件读取。 |
| GG 并联双轴 | 氧泵轴、燃料泵轴各一台；两台均使用富燃燃气，分别读取分流后的流量。 |

中径 `Dm` 和节圆速度 `U` 读取保存组件，并验证 `U=πDmN/60`。现有系统的中径初选含 0.05–0.80 m 限幅；页面保留该已记录结果并说明目标速比偏离，不把它当成最优几何。级数采用用户指定或已记录的系统经验推荐，仅确定叶排包络数量，不代表各级压比和功率已经匹配。

几何采用等中径、全周进气、无堵塞和无泄漏的概念假设：

- 轴向速度：`cm1=φ1 U`、`cm2=φ2 U`。
- 参考密度：`ρ=p/(RT)`，`R=8314.462618/MW`；分子量单位为 kg/kmol，出口沿用冻结组成。入口和出口分别使用各自保存的 P/T。
- 端面连续性：`A=ṁ/(ρ cm)`；环形通道高度 `b=A/(πDm)`。
- 轮毂直径 `Dh=Dm-b`，机匣流道直径 `Ds=Dm+b`。要求正轮毂半径，尺寸无效时返回原因，不截断叶高。
- 静、动叶轴向弦长及相邻叶排间距按 `Dm` 的指定比例构造。中间子午面为几何过渡，不是逐站流动解；叶排区域仅表示位置包络。

默认入口／出口速度比分别为 0.60／0.70，静叶／动叶轴向弦长比分别为 0.12／0.15，间距比为 0.04。这些数值是可编辑的项目示例假设，未经过优化，不是 NASA、CFturbo 或发动机厂商推荐值。

**压力与温度口径：**当前循环未解析涡轮端口速度和总静态转换。几何约定 `system_pt_as_static` 仅将系统节点 P/T 当作静态参考量估算密度。不得直接把这些值填写为 CFD 总压／总温；进入专业软件后须确认口径、物性和进排气条件。

## 导出与后续工作

导出与图形使用同一份保存坐标，轴为 `z`、长度单位为 m，原点在流道入口。

| 格式 | 用途 |
|---|---|
| JSON | 保存设计点、假设、主尺寸、轮廓、叶排位置、来源和校验信息。 |
| CSV | 轮毂／机匣的 `z,r` 坐标。 |
| 轮毂 TXT、机匣 TXT | 分别导入 CFturbo 等支持二维点列的软件；每行 `z,r`，单位 m。 |
| DXF | 子午面两条流道边界，导入后核对长度单位。 |
| OBJ | 环形流道的完整周向开放曲面；三维查看中的剖开设置不裁剪导出。 |

后续还需设计速度三角形、各级负荷与反动度分配、叶片数量、叶型、安装角、厚度、叶顶间隙、端壁、轮盘、轴与密封。建立带叶片实体及网格后，才能开展对应的叶栅 CFD 和结构分析；本页不根据环形通道宣称效率、强度或寿命已通过。
