# 冷却通道方案筛选：依据与适用边界

核查日期：2026-10-28。本说明支持系统级候选方案比较，不提供通用制造尺寸或材料许用温度。阅读了下列五篇本地 PDF 的相关原文页，并核对 NASA、DLR 和期刊的原始来源。未把本地已有的精读报告作为原文证据。

## 设计逻辑

冷却需求确定约束和评价目标，通道数、宽度、高度、肋宽、壁厚共同构成待选硬件。热负荷或质量守恒本身不能给出唯一的通道数。

一维模型可以批量评价候选几何，在壁温、压降、流量和制造边界之间筛选。未定义的壁温或制造限制应显示“未评估”，不能用缺省值自动宣布方案合格。材料热物性数据温区、方案壁温约束与计算壁温是三个不同对象；其中任一个都不能替代疲劳寿命或结构验证。

## 本平台本轮采用的最小范围

以下是结合现有模型能力作出的实现选择，不是论文中的统一规范。

1. **先确定筛选边界。** 从选定的已保存稳态记录取热侧状态分布、冷却入口状态、冷却流量、统一型面及覆盖范围。各候选使用同一组边界、材料和关联式版本，便于比较。
2. **把几何作为候选变量。** 枚举整数通道数 `N`、喉部宽度 `w`、高度 `H` 和热壁厚度 `t`。搜索范围由用户或有来源的工艺约束提供。每批最多 64 个组合是计算资源限制，不是物理适用范围。
3. **先排除无效几何，再积分冷却回路。** 检查正尺寸、整数通道数、沿程节距与肋宽，并按配置检查最小肋宽、最大高宽比。几何不重叠只证明几何可构造，不证明可制造或承载。
4. **报告实际计算结果。** 给出最大热壁温度、总压降、出口状态、入口/喉部/最大沿程速度、节距和最小肋宽，同时保留求解失败、物性或材料越界信息。不能将失败候选静默删掉。
5. **比较而非自动认证。** 温度与压降的非支配候选仅表示本批候选在这两个指标上的取舍，不代表全局最优。未设限值时仍可比较，但不能称“满足冷却需求”。即使全部已设约束满足，也保留关联式、HTD/热分层、制造与寿命尚未验证的状态。
6. **选择后再做整机闭合。** 用户选定候选后生成新草稿，保存为新方案版本，再运行设计点。单向固定边界筛选会遗漏几何变化对泵功、供压、预燃室入口及热侧状态的反馈；必须明确标注这一限制。
7. **硬件定型后冻结几何。** 变工况、节流或瞬态计算不能随流量重新自动定深；应沿用保存的几何，在新的边界下检查全程状态。

## 速度定义与暂不增加的物理模型

局部速度应满足 `u(s) = mdot_c / [rho(s) N w(s) H(s)]`。如果使用入口速度定尺寸，密度和宽度都必须来自入口截面；如果使用喉部目标速度，喉部密度受加热和压降影响，需要联立迭代。选定固定 `N/w/H/t` 的候选筛选直接计算速度，不把参考速度当成沿程恒定值。

本轮不凭文献中的单个经验常数新增“HTD 自动认证”、材料许用温度或制造资格判断，也不把当前主体温度模型包装成可可靠预测任意高宽比通道的工具。后续应以有覆盖的甲烷试验验证热侧、冷侧与横向热分层，再扩展轴向变高/变宽、分支通道、并联分配和热结构寿命。
