## 方程与数值的独立检查

- 密闭氮气输入 37 J，脉冲端点不在均匀采样网格上，末态与独立 `UV` 热力学求解一致。
- 密闭气体与有限热容量壁面交换，平衡温度与独立总能量根一致。
- 高温 CH4/O2 密闭初态、无外部热脉冲，与原生未扩展 `IdealGasReactor` 逐点对照；化学反应没有被人为延后到规定事件。
- 对公开时间采样中的流量、焓和热流另行积分，核对总质量、流体与壁面能量，不仅检查随状态积分的账目变量。
- 由独立 Mach 数及局部等熵状态的 `rho*v` 验证孔口流量；核对等压零流、反向压差止回、临界连续性及壅塞饱和。
- 默认开放反应算例按 `rtol=1e-7` 与 `2e-8` 计算，1 s 末态压力、温度、质量与水质量分数在测试声明容差内一致；两次审计通过。
- 只有两个请求输出点时，快速超温仍被内部接受步检查截停；没有靠图表采样密度发现越界。
- 分别检查流体与壁面能量残差。人为加入等量反向错误时，总能量虽可相消，审计仍返回需复核。

这些测试检验方程实现与数值一致性。共享 Cantera 机理的求解器对照不验证反应速率数据库的真实性，不替代高压纯氧甲烷点火实验。

## 实际队列算例

仅在 `.cache/web-ui-qa/workspace.sqlite3` 的合成验收项目运行，没有向用户正式项目插入示例计算。共同基线为 1 L 气体容腔、初始氮气、300 K、0.1 MPa；气体源和其余参数采用记录中的默认研究值。除超温提前停止例外，仿真均到 3 s。

| 算例 | 末态压力 / MPa | 有效积分步气温峰值 / K | 累计外加热 / J | 状态 |
|---|---:|---:|---:|---|
| 默认有限速率反应与给定热脉冲 | 0.910744 | 2111.785 | 1500.000 | 完成，守恒通过 |
| 外加点火热量设为零 | 0.341959 | 326.318 | 0 | 完成，守恒通过 |
| 全程关闭化学反应，保留热脉冲 | 0.363637 | 1563.139 | 1500.000 | 完成，守恒通过 |
| 气体温度上限设为 600 K | 0.232596 | 595.041 | 286.884 | 提前停止，保留有效段，守恒通过 |

默认例最大总质量残差约 `1.20e-17 kg`、各元素最大残差约 `2.28e-11 kg`、总能量最大残差约 `1.78e-4 J`。相应数值容差约为 `2.29e-8 kg` 与 `2.63e-2 J`。这些值仅说明本例的守恒闭合，不能被解释为实际发动机预测误差。

无外加热例也在约 2.432 s 达到用户 0.3 MPa 参考线，因此界面没有把压力达标改名为点火成功。默认例参考线首次观察时刻约 0.306431 s，同样只记录压力响应；接受步最大间隔为 0.002 s，不声称这是精确的点火延迟。

600 K 上限例最后有效时刻为 0.303825 s。越界观察单独保留，结果不把温度钳成 600 K 后继续运行，也不补齐剩余热脉冲能量。取消例在有效时刻约 0.491 s 保留 50 条样本；已经经过的脉冲起止事件正确标为已到达，守恒审计保持待完成，未冒充全时段通过。

四个完成/受限例和取消例均核对来源记录、输入冻结与导出；原稳态结果没有被改写。历史记录 ID 与完整参数保存在本地验收 JSON 中，便于复算。

## 界面与记录一致性

界面已核对：非法低温气相输入能够更正并重新提交；煤油来源不能悄悄改为甲烷；历史结果按自身冻结参数导出，后续编辑不改变历史；时间截面显示实际保存的接受步时刻；给定事件和已到达事件分开；密集事件编号合组显示，但各事件竖线、说明和明细仍保留。

浏览器下载文件经本地解析确认：CSV 有 301 条数据，SVG 包含全部 11 幅图，末态 JSON 为同一记录的 3 s 状态，且明确 `engine_initialization_supported=false`。图中点火成功、点火延迟及熄火均为未自主判定。

最后从实际页面“运行点火事件与建压分析”按钮再次提交默认例，记录 `bdd175ad…` 完整生成 301 条时间样本；没有捕获浏览器错误，独立验收服务在任务结束后正常关闭。

本轮实际队列检查曾发现 NumPy 布尔值不能直接写入中间 JSON 的问题，已在核心与持久化边界修正，并增加每次进度序列化回归；另修正了取消记录事件状态和额外事件采样导致进度分母偏小的问题。修复后上述队列与导出检查重新通过。

## 本机部署与数据保护

正式服务更新前确认无排队或运行任务，使用 SQLite 一致性备份，再通过既有 `stop.request` 流程退出并重新启动 8765 本机服务。更新后健康检查、新接口鉴权及静态资源检查通过。

数据库中 1 个用户、1 个项目、7 个修订版本和 23 条计算记录的逐表内容摘要与更新前完全一致。备份位置及摘要保存在 `.cache/ignition-restart-manifest.json`。本轮新增能力可通过刷新本机页面进入，不需要重做已有方案。

## 尚未完成的物理验证

此模块仍是给定外部热事件的气相容腔研究台。尚未把两相预冷、低速供给网络、液体喷注和雾化汽化、涡轮泵轴动力及燃烧腔连接为完整发动机启动模型。默认结构、阀特性、热输入和换热参数未经目标发动机标定。

点火成功、延迟和熄火判据仍需对应工质、初态、喷注结构与点火器的实测数据、明确的观测定义及适用范围。本轮保留这些量的“未评价”状态，没有以收敛、压力达标或守恒闭合代替试验判定。
