# 预冷与充填：模型、数据口径与验证

本模块面向冷态初值研究，独立于单相“供给网络动态”和“热态瞬态响应”。文献依据及不能移植的假设见 [文献核读](CHILLDOWN_LITERATURE_EVIDENCE.md)。模型通过数值守恒检查，不等于完成实机预冷试验验证。

## 分析对象与界面

从一个已完成的设计记录确定氧化剂、燃料及默认供给温度，在“系统仿真 → 预冷与充填分析”分别设置等效容腔、壁面、供给与排出边界。来源可以是 GG 或 FFSC；来源整机约束失败会原样保留，独立单元计算不能将其变为通过。

```text
固定液体储源 → 有执行机构的入口节流孔 → 刚性均相容腔 → 有执行机构的出口节流孔 → 固定背压
                                          ↕ 壁流换热
                                      集总金属壁面 ↔ 环境
```

每个工质只有一个容腔与一个壁面温度，可表示一段管路、一个泵腔或一个冷却通道的等效单元。它们尚未串联成空间离散网络。图中的气液占比表示均相平衡体积分数，不能理解为已求出空间液位或推进剂前沿。

默认面积、容积、金属热容量和换热导纳只是可编辑研究工况。不能由稳态流量唯一确定这些参数，也不把文献中的 RL10 修正系数直接赋给甲烷或煤油发动机。

## 守恒方程

每个单元积分流体总质量 `m`、流体总内能 `U`、壁温 `Tw`、入口/出口实际开度，并累计各质量与能量边界通量。

```text
ρ = m / V ; u = U / m
(p,T,h,s,phase) = EOS(ρ,u)

dm/dt = ṁin − ṁout
dU/dt = ṁin hin − ṁout h + Qwf
Cw dTw/dt = Qamb − Qwf
Qwf = UAwf (Tw − T)
Qamb = UAamb (Tamb − Tw)
```

刚性容腔没有移动边界功。焓通量已经包含流动功，不得再额外叠加 `pQ`。入口节流/混合采用上游总焓供能；出口带走容腔混合物焓。壁流换热在流体与壁面账目中符号相反，在总能量审计中抵消。

总能量的审计量为 `U + Cw Tw`（同一固定参考零点），外部输入是入口焓通量减出口焓通量，再加环境热量。EOS 的绝对内能可因参考零点而为负，不把负焓或负内能自动判为物理错误。需检查正质量、有效状态及闭合关系。

## 气液库存与物性

使用安装版本的 CoolProp HEOS 纯工质状态方程。PT 初始化仅用于明确单相状态；PQ 初始化用绝对压力与蒸气质量分数指定饱和状态。积分中由密度和比内能重新闪蒸，不能同时把压力、温度、干度全都作为独立约束。

两相区中，蒸气质量分数 `x` 与气相体积分数 `α` 满足：

```text
mv = x m ; ml = (1−x)m
Vv = mv/ρv ; Vl = ml/ρl
α = Vv/V ; liquid_volume_fraction = Vl/V
```

在均相平衡假设下可以获得库存变化与相变结果，不能区分有限速率汽化、界面换热、气泡滑移或膜态沸腾历史。初始气体仅为推进剂自身蒸气；不接受氮气或氦气混合气。n-Dodecane 是煤油的纯工质代理，不是 RP-1。

单液相或单气相输出中的 `quality=0/1` 只用于库存记账，并非饱和干度。真正超临界状态和临界点不划分气液库存，相应结果为空；页面显示该状态的具体解释。

## 节流孔与执行机构

按上游静止储态的 `h0,s0,p0`，沿等熵路径求质量通量：

```text
G(p) = ρ(p,s0) √[2(h0−h(p,s0))]
ṁ = CdA × a × max G(p),  p ∈ [pdown,p0]
```

如果最大值在区间内部，排出流已达到该模型的临界流量；降低背压不再无限增加流量。入口与出口均按上游状态计算，不跨两相区使用冻结密度的不可压缩公式。`CdA` 已包含流量系数；不要另乘第二个 `Cd`。

两条边界均带理想止回功能：上游压力不高于下游时，流量为零。这是明确的部件假设，不是把可反流管路的负流量强行删除。面积为零时可用于隔离和封闭容腔验证。实际开度按一阶滞后与速率限制响应用户斜坡指令。

出口抽取的是均匀混合物，因此不能称为“只排蒸气的放空阀”。选择性排气需要单独的相分离、取流位置和蒸气焓模型。HEM 也不含短节流孔非平衡闪蒸延迟；通过数值极值检查不代表流量系数已试验标定。

## 结果、记录与初值交接

结果包括温度、压力、流入/排出流量、气液质量、体积分数、换热功率、实际阀位，以及每个单元的质量和总能量误差。初始和终点快照保存 `m,U,V,Tw`、EOS 信息、状态、阀位、来源记录与请求指纹。

末态的“目标达到”只表示用户设置的壁温上限、液相体积分数等本页判据得到满足。记录是否完整、物性是否有效、守恒是否闭合和目标是否达到要分别显示。被取消或超出模型范围的任务保留已经返回的有效采样，不能标为完成。

末态快照是后续网络初始化的输入材料，尚未自动注入供给网络或热态整机模型。要形成整机冷启动初值，还必须匹配所有连接容腔、管路流量、轴速、壁温、阀位和边界压力，并检查一致性。尚未建立燃烧点火、转子自启动、NPSH/汽蚀和整机阀序控制。

## 验证与后续精化

数值验证包含封闭绝热单元、壁流能量交换、两相库存重建、节流孔临界流和守恒、初值往返一致性、边界停止与部分结果、容差敏感性，以及 API 历史隔离和网页交互。具体测试结果以本轮执行日志为准。

本轮执行的测试、实际任务队列算例和浏览器导出检查见 [验证记录](CHILLDOWN_VALIDATION.md)。

进一步提高物理精度需要：带来源和适用域的膜态/过渡/核态沸腾关联式、轴向多容积离散、不凝气体与选择性排气、管路动量和泵空化、真实金属温变比热、试验时序及测量不确定度。精化应逐级比较壁温、出口温度、压差、排出质量和预冷时长，不能仅凭一条平滑温度曲线判定准确。
