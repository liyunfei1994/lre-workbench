# 推力室内型面：数据来源与坐标交接

此页面是所选计算记录的燃气侧内型面工作区。它使用已保存的设计点数据，不随尚未保存或重新计算的参数草稿变化。二维剖面、三维旋转曲面和坐标导出共用同一组轴向位置与半径；三维显示只是该母线绕轴旋转，不另造一套尺寸。

## 哪些是输入，哪些由循环给出

| 类别 | 数量 | 数据来源 |
| --- | --- | --- |
| 设计输入 | 喷管面积比、燃烧室收缩比、特征长度 L*、收缩半角、钟形长度比、指定起始角和出口角 | 该次计算保存的 `calculation.inputs` |
| 循环与热力匹配输出 | 喉部面积 | `calculation.components.nozzle.outputs.At_m2` |
| 推导尺寸 | 喉径、燃烧室内径、出口内径、直筒段长度、收缩段和膨胀段长度 | 最终喉面积结合上述设计输入，通过共享的尺寸与型面函数确定 |
| 展示与导出坐标 | 完整内轮廓母线 | 优先使用 `cooling_channel.profile.geometry.full_nodes`，其范围包括完整喷管，不能用仅覆盖冷却段的逆流坐标代替 |

因此，该页并不是循环迭代独立优化出来的一套喷管。循环给出工作点及喉面积，几何假设用于确定其余型面。当前采用圆弧连接与抛物线钟形构造，不代表已完成推力最优型面设计。

预算模式或早期记录没有完整冷却型面时，只能由该条记录保存的喉面积和几何输入重建，并明确显示“由本记录尺寸与输入重建的型面”。已有型面损坏时，不使用当前默认值补图。

## 几何一致性

`webapp/nozzle_geometry.py` 对坐标严格递增、半径、分段位置、直段尺寸、喉部、出口、长度及坐标校验值进行检查。已有几何快照也必须重新通过这些检查，不能因为它已经保存就直接信任。

页面另行对照同一记录中的喷管喉面积、面积比、主燃烧室尺寸、冷却几何、型面构造输入和特征长度：

- **一致**：已有证据在数值容差内相符。
- **证据不全**：历史字段缺失；坐标可用，但不能宣称与所有循环字段均已核对。
- **不一致**：记录之间存在矛盾。保留原坐标供核查，暂停坐标导出。

喉面积比较采用相对容差 `2e-8`，与当前再生冷却／燃气耦合的几何收敛阈值一致。它是数据与数值闭合判据，不是 CAD 加工公差或试验误差保证。所有检查只生成派生视图，不修改历史计算结果。

## 向建模软件交接

导出的是燃气内边界的母线点，不包括喷注器面板、材料壁厚、冷却槽、承力壳或外部流场边界。

1. 选择所需的已完成计算记录，查看几何一致性状态。
2. 选择米或毫米，以及喷注面原点或喉部原点。
3. 对通用 CAD 点导入，使用数值型 XYZ CSV：`x` 为轴向，`y` 为正半径，`z=0`。旋转轴为 X 轴。
4. 对需要追溯和分段处理的交接，使用带分段、关键位置、记录 ID 和坐标摘要的 CSV。单位写入列名，原始坐标摘要对应保存的米制型面。
5. 导入后按点序构造母线，核对喉部和出口尺寸，再旋转生成内表面；轴对称 CFD 可直接使用母线构造子午面域。入口、出口、轴线、实体壁和计算域需由后续建模步骤补全。

导出保留保存点的顺序和精度，只作显式的单位换算与原点平移，不加密、不重新拟合、不通过新参数改变型面。离散点间的样条插值可能改变喉径、局部曲率或出现过冲；后续软件应检查插值方法与关键尺寸。该坐标文件不是完成的 CAD 实体或已生成网格。

## 喷管设计与性能工作区

“设计与配置 → 喷管设计与性能”独立于内型面页面，共用同一条保存的计算记录。内型面负责二维/三维几何和 CAD 坐标交接；喷管页负责工作点、性能定义、轴向流动、环境特性、热负荷与后续验证任务。旧“设计匹配扫描历史”入口已归入“结果与诊断 → 历史记录”，数据和只读导出保留。

喷管页的五个页签：

1. **设计点与校核**：Pc、质量流量、At/Ae、面积比、出口状态、特征速度、当前环境/真空 Cf 与 Isp、动量和压力推力。逐项检查 `F=ṁVe+(pe−pa)Ae`、`Isp·g₀=c*·CF`、真空修正、出口节点和几何来源。
2. **轴向流动**：显示保存的准一维 Mach、静压、静温、速度，并标识几何喉部与模型声速点。没有保存流场的历史记录保持缺项，不从轮廓伪造气动分布。
3. **环境背压**：固定 Pc、质量流量、几何、出口速度/压力，仅计算压力推力变化。可设置采样上限与点数，切换推力、比冲、Cf，并导出保留原始 SI 精度、记录标识及适用范围的 CSV。
4. **热与损失**：读取本记录冷却模型的喷管分区热负荷及扩张段热流/壁温；区分整条再生回路压降与喷管段。材料物性超温区如实标示。逐项列明换热是否已计入，以及化学、发散、摩擦、分离等模型边界。
5. **方法与交接**：给出文献、方法来源和 CFD/有限元所需信息；分析 JSON 包含本页数据及当前环境曲线。

`c*=Pc·At/ṁ` 是主室热化学和喉部流量的接口量，不是仅由喷管型面决定的效率。当前 Cf 来自同记录推力；没有同基准理想计算和试验时，不填默认喷管效率或 c* 效率。已在热耦合求解中扣除的换热不能再次乘经验热损效率。

环境特性假设满流且内部状态不受背压影响，不是节流求解、轨迹计算或启动/关机仿真。`pe/pa<0.4` 只触发早期经验筛查，图中相关段用橙色虚线表示代数外推；未触发也不证明无分离。截面平均出口压力不是局部壁压，不能据此给出实际分离点、FSS/RSS 转换、侧向载荷或结构安全结论。采样上限 `min(5 MPa, 0.2 Pc)` 是软件数值保护，不是经验证的物理包线。

保存值发生矛盾、剖面损坏或冷却单元坐标超出型面时，页面报告异常并停止环境特性派生；已有非法值不会被另一个派生值静默替换。上述派生和导出均不修改原始计算记录。修改面积比、端角或长度比仍通过既有参数编辑器，并重新运行循环计算，生成新的设计记录。

文献分析见 [NASA SP-8120 逐项审读](NOZZLE_NASA_SP8120_REVIEW.md) 和 [NASA/DLR 等后续资料](NOZZLE_MODERN_REFERENCES.md)。本次建立总体设计分析链路，没有声称实现 MOC/TOP 最优型面、黏性 CFD 或有限元求解。

## 代码位置

- `src/lre_workbench/components/nozzles/performance.py`：固定内部状态的环境特性与经验筛查标签。
- `webapp/nozzle_design.py`：同记录只读分析、数据一致性和交接信息；`GET /api/jobs/{id}` 附加 `nozzle_design`，`POST /api/jobs/{id}/nozzle-ambient` 返回只读场景。
- `webapp/static/nozzle-design.js/css`：喷管性能工作区、曲线和数据导出。
- `web_tests/test_nozzle_design.py` 与 `web_tests/test_nozzle_design.mjs`：定义恒等式、数据扰动、只读 API、权限、曲线与导出回归。

- `src/lre_workbench/components/nozzles/heated.py`：当前沿程冷却模式下，与冷却剖面耦合求取最终喉面积和热气流动；`src/lre_workbench/components/nozzles/model.py` 负责不采用沿程热耦合的预算模式喷管计算。
- `src/lre_workbench/components/chambers/sizing.py`：根据喉面积、收缩比和 L* 确定主室尺寸。
- `src/lre_workbench/components/nozzles/geometry.py` 与 `src/lre_workbench/components/cooling/geometry.py`：共享燃气侧规范型面及冷却覆盖坐标。
- `src/lre_workbench/systems/regenerative.py`：热气／冷却几何耦合残差。
- `webapp/nozzle_geometry.py`：冻结记录的几何视图与一致性校验。
- `webapp/static/nozzle-export.js`：坐标转换及 CSV 数据交接。
