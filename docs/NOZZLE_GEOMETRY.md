# 喷管几何模型：系统级抛物线钟形

本平台将喷管表示为轴对称燃气侧内轮廓，用于总体尺寸设计、热侧流动、冷却覆盖及面积和水力长度计算。当前构造名称为 **抛物线钟形喷管——系统级工程近似**。它没有执行特征线优化或 CFD 优化，不声明为已验证的 TOP 最优推力型面，也不复刻 Raptor 或其他具体发动机。

## 方法依据与适用边界

[NASA SP-8120《Liquid Rocket Engine Nozzles》](https://ntrs.nasa.gov/citations/19770009165)提供以下相关设计指导：

- §2.1.2.1.2、图5，正文第15页（PDF第29页）：倾斜抛物线近似及入口、出口壁角图。[原文页](https://ntrs.nasa.gov/api/citations/19770009165/downloads/19770009165.pdf#page=29)
- §3.1.2.1.2，正文第67页（PDF第81页）：可选择候选入口／出口角度构造抛物线，再计算和比较各构型的性能。[原文页](https://ntrs.nasa.gov/api/citations/19770009165/downloads/19770009165.pdf#page=81)
- §2.1.1、§2.1.2，正文第9–12页：喉部曲率应综合考虑流动、冷却与制造；钟形长度比以同面积比的15°半角锥形喷管长度为参考。[原文页](https://ntrs.nasa.gov/api/citations/19770009165/downloads/19770009165.pdf#page=23)

这些资料支持参数化抛物线的构造方式，**不为本项目默认角度或历史对数表达式提供最优性证明**。NASA 文献前言也说明此类资料是设计指导，除非被项目正式规定采用，并非自动成为项目要求。

Bell 表示钟形外形；TOP、TOC、TIC 指具体的设计方法或型面族，不能仅凭外形认定。[用户提供的型面研究](https://doi.org/10.1155/2019/4926413)区分了这些方法，并通过流动计算评价其设计；本平台当前不实施该论文的优化流程。

## 新方案的显式角度构造

方法标识：`parabolic_bell_explicit_v1`；角度来源：`specified_design_angles`。

主要输入为喉部半径 `Rt`、面积比 `ε`、钟形长度比 `Lf`、起始角 `θn`、出口角 `θe`。出口半径满足 `Re = Rt √ε`。长度采用本项目明确的直锥参考定义：

```text
L = Lf × (Re − Rt) / tan(15°)
```

喉后圆弧半径当前为 `Rd = 0.382 Rt`，这是可追踪的构造假设，不是所有发动机都必须采用的值。圆弧末点 N 与出口点 E 为：

```text
N = (Rd sin θn, Rt + Rd (1 − cos θn)) = (xn, rn)
E = (L, Re)
```

两点的指定切线相交于控制点 Q；钟形段由二次 Bézier 表示：

```text
Qx = (Re − rn + tan θn × xn − tan θe × L) / (tan θn − tan θe)
Qr = rn + tan θn × (Qx − xn)
B(t) = (1 − t)² N + 2(1 − t)t Q + t² E，0 ≤ t ≤ 1
```

这种构造提供端点位置和切线的确定关系。曲线与喉后圆弧相切，属于 C¹ 连续；不声明连接处曲率 C² 连续。

有效性检查包括：

- 尺寸与角度有限，半径为正，面积比与半径一致。
- `0 ≤ θe < θn < 90°`，`L > xn`，`Re > rn`。
- `tan θe < (Re − rn)/(L − xn) < tan θn`，保证切线交点在端点之间，避免型面回折。
- 新显式模式拒绝收缩段入口圆角 R1 退化为零的组合，避免将圆筒与收缩段的尖角当成平滑连接。

不满足条件时明确报错，不将平行切线静默替换为中点，也不静默改变用户指定角度。默认35°／10°为设计示例，可调整；它们不是实机测量值或优化结果。

## 统一几何与显示

`geometry.nozzle.full_hot_gas_geometry` 是完整燃气侧轮廓的规范构造入口；收缩段取自 `chamber_contour`。圆筒、收缩段、喉部圆弧和扩张段组成同一轮廓，热侧与冷却计算应使用同一方法、尺寸、角度及实际曲率。

完整轮廓以喷注面为 `x = 0`；桌面喷管局部图和坐标导出以喉部为 `x = 0`。比较数据时须按记录的喉部轴向位置平移，不能把两个坐标原点混用。

二维剖面和绕轴旋转的三维曲面用于尺寸核对与方案沟通。三维曲面表示燃气侧内壁，不包含已经验证的壁厚、冷却通道、外壳、制造公差或结构寿命。几何检查通过也不代表流动分离、侧向载荷、推力效率或可制造性验证通过。

## 历史兼容

- 旧输入未保存方法字段时，按 `legacy_log_v1` 读取；其角度来源记为 `historical_log_rule_unvalidated`，不自动替换为新显式角度。
- 历史对数角度算法保留用于旧方案复现，不再声称其为已有证据的 Rao 图拟合。旧收缩段几何裁剪算法未重写；新显式模式额外拒绝入口圆角退化。
- 没有方法／来源元数据的旧几何图明确显示“历史轮廓；角度来源未记录”，不从旧 `TOP` 类型字符串推断已完成优化。
- 修改构造方法会改变轮廓及可能的冷却结果，应保存新方案版本并重新计算；原计算记录保持其保存结果。

建议后续补充可追溯的图表数字化数据或特征线／CFD 性能评价，并记录适用范围与误差，再引入有证据支持的角度推荐或优化模式。

## 网页使用与记录追溯

左侧“推力室与喷管几何”读取上方选中的设计点记录。提供等比例二维剖面、尺寸表、可旋转缩放的三维内壁曲面，以及原始坐标 CSV 和二维 SVG 导出。喷注面为网页与 CSV 的坐标原点。冷却覆盖仅在记录保存了对应范围时绘制。

新方案在“推力室型面与覆盖”中选择构造方法和角度；型面参数只有这一处编辑入口。修改草稿不会改变已经保存的图示，运行新设计点后查看新轮廓。旧记录保存完整坐标时直接展示；未保存完整轮廓的预算模式记录按自身尺寸与冻结输入重建，并明确标注来源。已有坐标损坏或尺寸不一致时显示原因，不使用当前草稿补造图形。

节流分析继续使用来源设计记录的固定硬件，冻结方法、角度、面积比与长度。旧版冷却几何按历史方法校核；新版同时检查新增的方法元数据。冷却计算和几何图使用同一份完整内轮廓，部分再生冷却不截掉喷管未冷却延伸段的几何显示。

本轮验证包含端点和切线、无反折、面积比、记录复现、冷却范围、固定硬件节流、只读接口以及浏览器二维／三维交互和导出。一个采用35°／10°示例角的完整 FFSC 设计点已完成实际计算及显示检查；这不构成型面最优性或实机性能验证。
