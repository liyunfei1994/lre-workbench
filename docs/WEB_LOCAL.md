# 本机网页版：系统仿真与总体设计

当前网页版专用于**液氧甲烷全流量补燃循环（FFSC）发动机的系统仿真与总体设计**。新建、参数修改和计算提交只接受这一循环与推进剂组合。其他架构的旧方案仅保留原始数据查看与导出，页面提示不支持，不再绘制专用图纸或提供部件分析。新概念设计任务使用仅含 FFSC 字段的 v3 契约；旧 FFSC 参数中的其他循环冗余字段在归一化时清理。
网页按五个工程阶段组织任务树：**总体方案与循环设计 → 部件设计与特性建模 → 整机集成与基准确认 → 固定硬件稳态分析 → 瞬态运行分析**。校核、记录、模型资料和帮助为辅助入口。任务树表达设计与求解流程；系统图和部件对象解释参数归属与相互影响。每个阶段包含自己的输入、运行和结果入口。

总体阶段从“发动机定义与设计工况”进入，定义只读构型身份、推力、室压、总氧燃比、环境和供给边界。总体模型、循环匹配条件、喷管总体面积比以及求解设置、初始化均在本阶段。计算后可查看总体性能、流路状态及“部件设计要求”，以同一保存记录的状态和负荷开始部件设计。

部件要求、工作区、整机反馈和候选快照分别显示数值收敛证据。执行完成但残差未达标的记录可保留用于诊断和草案迭代，不能作为已确认的部件设计依据；多个部件修改可纳入同一次后续复算，反馈表区分原目标版本复算和后续合并修改复算。

新建项目可选择设计起点，默认采用“概略热负荷 · 随工况与受热面估算”；也可显式沿用工程示例的模型与几何。采用概略模型时需确认参考壁温、压降估计、概略型面和冷却范围。此选择只作用于新项目，不改写示例、已存方案或历史结果。

“冷却与循环耦合模型”可选择概略热负荷、详细部件耦合或外部指定。切换保留各模式输入，不改写旧结果。概略模式共用型面与冷却范围，通道和材料作为后续草案；详细模式需确认参与循环的通道及材料；外部指定模式只使用给定吸热功率与压降。泵、涡轮的尺寸初选仍不作为常效率总体循环的必填确认步骤。

部件阶段按推力室与喷管、再生冷却、泵与轴系、涡轮、预燃室与喷注器、阀门供给部件组织。每个部件工作区连接唯一参数编辑器、保存结果、已有局部研究与整机反馈。喷管总体面积比保留在总体阶段；完整内型面、泵涡轮初选参数、冷却通道及材料归部件阶段。缺少实际部件模型的页面仍只提供已有设计交接，不新增不可执行的模型选择。

“保存本部件修改并进入整机复核”只提交该部件拥有的字段，记录来源设计点、修改前后值及目标版本。其他未保存编辑继续保留；版本冲突拒绝提交。普通保存后仍可补记反馈，输入未变化时不制造新版本。整机复算完成后，反馈记录关联包含这些修改的保存记录，并区分输入完全一致与包含后续修改的复算；执行成功仍待检查数值收敛和工程约束。

整机集成页可把选定的已完成设计记录保存为不可变的**候选硬件与模型快照**，包括来源、实际保存的几何、部件证据、模型数据及缺项。快照不混入当前草稿；可重复打开和导出。候选快照不是已经通过固定硬件名义工况复核的运行基准：当前完整固定硬件稳态求解尚未开放，局部节流与瞬态研究继续声明自身范围。不会通过改名或保存快照自动解锁求解器。

求解设置集中管理非线性方法、收敛容差和离散分辨率；初始化管理迭代起点。数值配置通过检查即可使用，不要求工程确认。工程视图在这两页展示给定量、待求量与完整判据，其余参数页展示系统图和对象关联设置。瞬态物理初始条件在瞬态任务中另行定义。

### 帮助文档与上下文查阅

“资料与帮助 → 帮助文档”提供用户手册、理论与模型说明、参数参考、分析模式参数对照、示例教程及版本与故障排查六类内容。目录和文档搜索只切换阅读内容；进入帮助不创建方案、不保存草稿，也不提交计算。

参数页保留单位、必要的简短提示、输入校验及本组确认状态。页面上方“本页帮助”和组内“参数定义与依据”定位对应参数参考；返回按钮恢复原工作页、参数组与滚动位置，未保存编辑和确认状态保持不变。示例教程仅说明操作；可在新建项目时选择起始工程示例，也可在“模型与资料库 → 工程示例与来源”中浏览，明确执行替换后才改变当前草稿。

压力输入、部件压力结果、桌面流程图及 CFturbo 交接报告采用 MPa，原以 bar 显示的参数按 `1 bar = 0.1 MPa` 换算数值。求解器和方案文件继续使用 Pa；历史结果中的 `*_bar` 字段在读取时换算，原始记录及 JSON 导出不改写。外部参考数据仍允许带明确单位导入，第三方接口按其声明单位转换。压力残差、容差及专门的环境背压分析保留各自明确标注的数值尺度。

帮助文档由 `webapp/static/help-manual.js` 组织，参数参考复用 `parameter-editor.js` 与后端参数定义；计算方法和模式对照复用已有渲染器。文档标注参数定义版本，并随程序安装版本提供。当前草稿对应的说明与历史计算记录的输入快照分别标识。开发环境、代码维护和测试流程继续由仓库开发文档维护。

左侧树按“设计阶段 → 参数类别 → 设置项”逐层缩进，父级文字不小于子级，折叠箭头位于左侧。桌面宽屏可拖动导航右侧分隔条调整宽度；用 Tab 聚焦分隔条后，按左右方向键微调，双击恢复默认 340 px。调整范围为 280–560 px，并随窗口可用空间收限；宽度记忆保存在本机浏览器。手机窄屏仍使用可展开的导航抽屉，不显示拖动条。

“总体方案与循环设计 → 发动机定义与设计工况”依据当前草稿显示推进剂与循环身份，右侧系统简图展示连接关系，尚未计算时也可查看；编辑工况仍使用原有唯一输入字段。历史构型标识保留，不用当前默认身份补写历史记录。

所选计算记录的详细循环图从工程视图的“保存结果”或“总体结果与部件要求”进入，原 `topology` 路由保留。详细图使用该记录的输入、版本和流路状态，不随草稿编辑改变，也不表示当前草稿已经计算。

各参数页仅承担输入编辑、本组校验、必要的工程确认和保存，不直接提交设计点计算。当前组的问题在字段及本组状态中显示，左侧树保留各组状态；完整的输入检查清单集中在“总体设计点计算 → 输入检查与运行”。阀门参数页、方案摘要等处的检查入口也只负责跳转，不自动保存或启动任务。

完成设置后进入“总体设计点计算 → 输入检查与运行”，集中核对当前草稿、分组确认状态与数值配置，再提交设计点计算。存在输入错误、未完成的检查或待确认物理分组时不能运行；正式提交时仍重新检查并保存当前输入，生成独立的计算记录，并进入“收敛监视”。设置树可以随时往返，首个总体设计点不要求先完成全部部件详细设计。稳态工况和瞬态分析继续使用各自任务设置；瞬态物理初始条件与设计点迭代初值分开。

总体结果位于“总体方案与循环设计 → 总体结果与部件要求”，部件结果位于各部件工作区，两者绑定同一选定记录。部件参数修改通过整机反馈复算形成新的记录。

- **04 固定硬件稳态分析**：定义独立的工作点任务；完整求解尚未开放，局部节流估算仍使用基准标定模型。
- **05 瞬态运行分析**：保留预冷、点火、热态响应、供给网络及关机研究，各任务使用自身初始条件与适用范围。

切换阶段不会提交计算或重设硬件。旧导航位置继续映射到对应工作页，模型与特性缺项在候选基准及运行任务中显示。

方案摘要为方案名称旁的按需入口，只保留方案身份、说明和继续工作的入口，不列入编号任务树。页顶紧凑状态条显示当前输入版本与保存状态、所选计算记录版本与执行状态及输入一致性；“查看差异”列出当前草稿与保存输入的差异并定位参数。模型、数据文件和校验标识移至“校核与记录 → 方案与计算记录 → 模型与数据来源”，只展示所选记录保存的证据。输入完整性、数值收敛、工程约束与模型验证仍分别判定，执行成功不能代替这些结论。

修改燃气模型、设计目标或部件参数后，平台比较当前草稿与所选记录的实际输入快照，标记变更组以及依赖该设计点的部件和运行入口“待更新”。旧结果及其模型标识保留；运行任务仍须在各自页面核对来源设计点。仅修改名称、说明或另存相同输入不会误标计算过期。空或不完整历史快照显示“一致性待确认”，不使用当前默认值补成一致。

总体和部件设计允许往返迭代：以总体状态提出部件要求，部件参数反馈后复算，再保存候选基准。实际特性数据接入与固定硬件名义工况复核是后续模型工作，候选快照不代替它们。
新建方案默认采用“概略热负荷”：由当前工况、概略型面、冷却范围及参考热面壁温估算沿程热流并积分，不要求指定总吸热功率或先完成通道设计。详细通道耦合与外部指定模式继续保留，旧方案不自动切换。参考壁温是输入假设，压降是独立估计；实际壁温与冷却能力由后续部件模型校核。详见[概略冷却模型与流程](CONCEPT_COOLING.md)。

“推力室内型面”提供所选计算记录的二维尺寸图、三维旋转面和坐标导出；与冷却计算共用保存的内轮廓。型面参数统一在“概略型面与冷却范围”中设置，部件页引用同一组参数；概略模式不从内型面推定壁厚或通道几何。方法与适用边界见[喷管几何说明](NOZZLE_GEOMETRY.md)。旧记录有完整轮廓时，刷新页面即可查看，无需重新计算。
“校核与记录”中的“热力学校核”提供同条件 CEA–Cantera 对比、系统守恒、真实流体物性与试验验证，详见[校核口径与限制](THERMODYNAMIC_VALIDATION.md)。
“涡轮设计与建模交接”汇总记录绑定的循环设计点、富氧／富燃燃气物性、功率匹配与部件初选值，可导出 CFturbo 设计任务书，支持可选均径速度三角形和逐级比功分配。概念流道移至折叠参考区，历史记录不按最新默认值补算；详见[涡轮设计条件说明](TURBINE_DESIGN.md)。
详细部件设计、推力室详细分析、有限元和 CFD 不在本阶段网页范围内。

## 主燃烧室设计与分析

进入“部件设计与特性建模 → 主燃烧室设计与分析”，选择已完成的 FFSC 计算记录。五个页签分别查看入口与设计点、平衡热化学与组成、主室几何、冷却与材料、方法与交接。入口采用真实保存的富氧和富燃涡轮排气；页面不按当前草稿补算或改写历史结果。

主室二维尺寸图与三维旋转参考面只使用喷注面至喉部的原始内壁母线。坐标导出需通过保存几何一致性检查，可选择 m 或 mm，保持点序和坐标原点。设计参数、完整组分、主室冷却单元可分别导出 CSV，JSON 保留记录来源、模型、核对项与交接说明；这些资料不包含网格、实体壁厚或完整 CFD 边界条件。

冷却曲线仅来自同记录主室范围的已保存单元，缺失样本保留断点；材料身份、分区和声明温区另行核对。HP 平衡状态、L*、名义容积更新时间及声学频率不能证明燃尽或稳定性。页面可跳转“热力学校核 → 燃气交接与筛查”，按实际入口的元素、焓、压力及允许物种进行 CEA／Cantera 独立对照。详细定义和后续验证边界见[主燃烧室总体设计与分析](MAIN_CHAMBER_DESIGN.md)。

## 喷注器初步设计与三处接口

“喷注器初步设计”读取同一保存记录，分别展示主燃烧室、富氧预燃室和富燃预燃室三处喷注接口。部件性能分析中的相关对象可跳转到对应接口，也可返回原部件。

主喷注器当前是中心圆孔＋外环缝的同轴概念构型；中心为富氧涡轮排气，外环为富燃涡轮排气。它不是针栓，未完成切向孔或旋流槽设计，原模型中的旋流数仍为经验假设。面板直径、启发式单元数、中心孔径、中心管外径、外环流道外径、径向缝宽及壁厚假设统一来自 `components.injector`；网页、桌面几何和图示不再独立估算单元数。面积等效间距不是完成孔位排布后的节距。横截面按保存直径等比例绘制，不补造轴向长度、缩进量、旋流槽或外筒壁厚。

环缝使用精确关系 `A = πδ(d_post + δ)` 反解，程序采用避免薄缝消减误差的等价形式。保留现有不可压缩孔口关系 `v_effective = Cd*sqrt(2Δp/ρ)`；`ṁ = Nρv_effective A` 中 Cd 只计一次。返回的内外径独立回算面积与质量流量。原中心孔径 1–50 mm、环缝 0.2–5 mm 仅为历史参考范围，越界保留计算值并告警，不静默裁剪后声称闭合。气体可压缩性、阻塞、混合／燃烧性能及制造可行性仍需后续验证。

两处预燃室各自有喷注器。其入口来自氧化剂／燃料供给支路，不是主室使用的两股涡轮热排气；相态应以局部压力、温度和物性判断。当前预燃室只保存各支路流量、喷注压降及集总支路状态，尚未给出结构、单元数、Cd 和喷孔入口局部状态，因此本页不生成预燃室孔径，也不套用主喷注器几何。这里的集总支路温度不是已解析的喷孔入口静温。

历史记录不改写。缺少新版几何合同、密度和所需面积时，页面标为旧记录／依据不足；有矛盾则显示不一致。重新运行设计点才获得修正后的尺寸。JSON 导出保留各站边界、尺寸、假设与回算状态，不是 CAD 或可直接求解的 CFD 模型。

一致性检查覆盖主喷注器面积与流量、涡轮排气状态，以及主室／推力室／冷却热壁的喷注面内径。预燃室另按供给源压力减去管路、阀门和目标室压力，独立校核喷注压降；设计模式核对保存压降比，固定阻力模式核对保存阻力关系。缺少依据不显示为通过。

## 程序更新与重新计算

- 仅修改已登记的界面文字、样式和图表显示方式后，刷新网页即可重新加载。首页、静态资源和 API 均设置 `Cache-Control: no-store`，不需要通过运行设计点来更新界面；刷新前先保存参数草稿。
- Python 后端、参数定义或数据读取逻辑修改后，需要先在无运行任务时停止并重新启动本机服务，再刷新网页。仅刷新网页或重复打开启动器不会替换长驻进程里已加载的模块；提交设计点也不是更新服务的方法。
- 本次分区工作台新增 `partitioned-workspace.css`，并修改后端静态资源白名单。从旧服务升级时，需确认没有运行任务后停止并重新启动一次服务，再刷新网页；只刷新旧服务可能无法加载新增样式。
- 已保存的计算与校核记录保持原结果，不因代码更新或网页刷新而改写。要用新方程生成系统结果，运行设计点；要更新 CEA–Cantera 等独立校核，运行校核页的“运行扫描对比／运行本项校核”。两类记录分别保存。
- 新版本的默认参数不会自动覆盖现有方案。需要变更方案参数时，明确编辑、保存后再计算。

## 参数分组确认与刷新恢复

“确认并保存本组参数”保存本组确认记录；当前有未保存编辑时，同时将当前草稿保存为新版本。仅确认已有版本的参数时，不增加方案版本。确认记录按方案及版本保存在本机数据库，刷新网页或重新登录后恢复，恢复时仍进行输入校验。

确认状态与分组参数、循环构型和参数定义版本关联。修改相关参数后，该组恢复为“待确认”；未修改的分组保留确认状态。选择“自定义方案（沿用当前值）”保留参数值并清除草稿的确认状态，需要保存或逐组确认。选择工程示例属于显式采用示例值，保存后可恢复“采用示例”状态。

“输入校验通过”与“已确认”分别表示输入检查结果和用户确认记录。打开分组、存在默认值或选择导航项，不代表已确认。升级前未持久化的确认记录无法追溯，需确认一次；本次升级含后端数据库读取逻辑，需重新启动工作台服务后使用。

## 预燃室热力匹配条件与工程限值

“预燃室热力匹配条件”只规定预燃室在总体循环中的设计工作条件。指定出口燃气温度时，在系统入口焓和压力条件下反求氧燃质量比；指定氧燃质量比时计算出口燃气温度。支路流量、预燃室压力与两侧轴功率联立匹配。数值初值统一在“总体设计点计算 → 初始化”管理，切换模式保留已有数值和历史自由分流模式的兼容行为。

主表单仅保留“设计工作条件”。出口燃气温度上限不是循环匹配的必填输入；有明确工程要求时，在“校核与记录 → 工程限值与校核”中登记两侧限值、状态与适用依据。该设置随方案保存，通过输入校验即可，无需额外的分组确认。选择“依据已登记”却缺少依据时自动展开依据输入，并阻止提交矛盾或不完整的已启用限值。修改限值不使预燃室工作条件的确认失效。

新建自定义方案和新载入工程示例均默认不启用上限。启用后，给定温度模式会在输入检查时拒绝目标高于上限的设置；氧燃比模式在计算后检查出口温度是否超限。上限不进入循环残差或优化目标，不会自动调节工作点，也不是求解器的温度裁剪边界。

右侧工程视图的“关联模型与参数来源”按需展开供给、压力、冷却、热化学、部件效率、初始化及工程限值说明，指向各自唯一编辑入口。点击“定位来源”后，可使用返回入口继续编辑。任务树与参数查找均将限值定位到“校核与记录”，系统图仍高亮对应预燃室对象。

在工作条件页或工程限值页点击右侧“保存结果”，默认显示预燃室匹配摘要。目标、计算值、偏差、已启用的温度上限、裕量和依据全部来自同一所选记录；输入改变时沿用工程视图的一致性提示，不用当前草稿补齐历史值。未收敛或收敛证据缺失时，数值只供诊断，不能将温度未超限表示为已通过。未设置限值时只显示未评估说明，不显示停用的保留数值或空裕量、依据表格；暂定限值满足仍提示依据待核实。

“完整结果与部件交接”定位到“总体结果与部件要求 → 部件设计要求”的预燃室交接段，包含两侧流量、压力、温度、轴功率和已保存的入口支路状态。支路端口是供给损失后的集总参考态，不能当作喷注器上游总压；完整组成、焓参考与物性来源随流路状态交接。喷注、混合、局部热环境、稳定性、材料与寿命留给后续部件设计。本次调整不改变求解方程、容差或历史数据。

两侧温度上限各自有状态与依据，独立于设计目标：

| 状态 | 计算和验收行为 |
|---|---|
| 未设置 | 隐藏上限与依据输入；保存的旧限值不参与目标校验、涡轮限值或超限判断；该项尚未评估。 |
| 设计暂定 | 检查暂定数值；超限为未通过，数值满足仍为依据待核实，不能显示工程通过。 |
| 依据已登记 | 必须填写约束来源与适用工况，再按该方案限值检查；来源登记不构成材料、寿命或氧相容性认证。 |

为保持旧方案行为，网页及桌面读取缺少约束状态的历史保存方案时，保留原限值并按“设计暂定”处理；显式保存的“未设置”保持停用，已有方案明确启用的限值和依据继续保留。工程示例为兼容保留 800 / 900 K 数值，但新载入示例时状态为“未设置”，保留数值不参与校核。750 / 850 K 工作目标仍是本项目的概念设计选择，不是 Raptor 3 测量值。未设置约束时，可进行设计计算，但不能把“没有发现超限”写成约束已通过。燃气整体出口温度、局部热点、涡轮金属温度及材料许可范围是不同的量。

状态与依据随方案版本和计算输入保存。历史结果不重算、不修改原始判定；网页对历史缺依据的预燃室检查补充暂定说明。需要新版系统验收结果时，再运行一次设计点。本轮执行策略版本为 4。

设计依据的使用边界：

- [RPA 官方《Configuring and running rocket engine cycle analysis》](https://www.rocket-propulsion.com/blog.htm?id=13)（2014 年，面向 Standard v2.x）以燃烧装置工作温度、部件效率、供给条件和压降等配置循环；其补燃循环示例给定预燃室工作温度并求解压力及轴功匹配。本平台借鉴这一输入职责划分，不将示例温度当作通用工程上限，也不据此断言所有 RPA 版本的界面相同。
- [NASA SP-8081《Liquid Propellant Gas Generators》](https://ntrs.nasa.gov/citations/19730018978)讨论涡轮驱动燃气、温度影响及控制，不能据此给当前甲烷 FFSC 套用一个通用温度上限。
- [DLR 2022 SLME 研究](https://elib.dlr.de/186560/1/SP-2022_Systematic_Studies_on_Reusable_Staged-Combustion_Rocket_Engine_SLME_for_European_Applications.pdf#page=8)第 8 页将混合比选择与涡轮入口温度限制联系起来；该方案使用液氧/液氢，具体数值不能直接转用于甲烷。
- [EADS 2006 可重复使用发动机研究报告](https://edocs.tib.eu/files/e01fb08/565308254.pdf#page=61)印刷第 57–58 页 §2.4.8.1 给出特定液氧/甲烷研究的富燃 900–950 K、富氧 700–750 K 选取范围。图 2-28 与 2-29 的甲烷入口分别为 240 K、140 K，液氧入口均为 122 K，效率假设也不同；报告的单轴、单预燃室基线不是 FFSC 双预燃室的一对设定，不作为本平台默认限值的证据。
- 本轮查阅的 [SpaceX 官方 Raptor 3 更新](https://www.spacex.com/updates/reusability)未提供可追溯的两侧预燃室出口温度。仅靠公开推力、比冲等整机指标不能唯一反求两侧温度；还需入口状态、压降、流量分配和涡轮泵性能等条件。基于自选条件的计算应标为概念方案，不标为实机重建。

kg/s 刻度，轴功率图分别显示泵负荷和可用涡轮功率；独立双轴分别比较，
功率差额保留正负号与记录中的校核容差。数据缺失时显示缺失提示。
这些图展示当前稳态设计点，求解诊断可展开查看。

稳态结果页增加“完整收敛与残差轨迹”。内层 Newton、主室热力反馈、预燃室温度外环、
延续法目标工况分别显示终值、容差、次数和终止原因；全部启用层通过才能显示完整数值收敛。
各层使用各自保存的验收准则。内层推力和两侧轴功率分别按任务物理容差验收，
归一化验收残差以 1 为阈值；数值缩放范数另行记录。热反馈和预燃室外环的单位、
容差与启用状态以该次计算记录为准，不能用一个内层残差代替整机完整收敛。

计算完成后可以查看各预燃室外环的热反馈曲线，以及每次 Newton 求解的残差范数和各方程残差。
横轴是迭代步，不是物理时间；不同外环和延续阶段不连接为一条连续收敛曲线。
默认展开最后一次 Newton 求解，其他调用和逐步数值表可以展开。对数纵轴的零值单独标记，
缺失值不补零。轨迹随结果 JSON 保存，切换计算记录可回看。

“输入检查与运行”同时提供实时收敛监控。提交后停留在本页，浏览器约每秒增量读取
当前任务已写入的过程事件。内层接受点、每次模型求值内的热闭合、预燃室外环及延续阶段
具有独立调用标识和上下文；热闭合试算不等同于内层接受点，各调用之间不连线。
监控与最终结果独立存储于 `job_monitor_events`，每条事件写入后即提交。
任务失败、取消、超时或服务中断不清除已有事件；终止时尚未写入的计算不能补录。
重新打开页面可从数据库读取历史，并导出原始监控记录；没有逐步数据的旧任务不生成模拟曲线。
监控接口使用 `/api/jobs/{id}/monitor?after={seq}&limit=500`，按任务递增序号分页读取，
终态仍需读取至 `has_more=false`。访问权限与任务记录一致。任务执行状态和各层收敛状态分开判读。

历史计算保持原始结果不变，但展示时会按已保存残差重新复核。旧记录缺少完整证据时显示
“历史收敛证据不完整”，已知外环残差超限时显示未收敛；不能凭旧的绿色内层状态建立新的节流/瞬态基准。
重新运行设计点会生成含完整证据的新记录。数值收敛与供给压力等系统约束仍分别判定。

“计算结果”与“计算结果总览”明确展示单工况计算范围，工况栏从所选计算记录读取燃烧室压力、
环境压力、指定总 O/F 和主喷管面积比，缺失项显示“—”。性能卡片区分计算真空值与指定环境压力下的计算值，
不把所有环境工况统一称作海平面。“瞬态分析 → 瞬态响应研究”提供零维热态小扰动积分入口，适用范围与稳态扫描分别标示。结果使用主区域的完整宽度，图表和指标按实际宽度调整列数。

“概念设计”中的“发动机定义与设计工况”集中设置设计环境、目标推力、指定室压和总氧燃比；用于流量初始化的比冲估计在“总体设计点计算 → 初始化”中设置。
参数页仅显示左侧设置树选中的分组。需要跨组定位时，使用树顶部的“查找参数”；
查找窗口列出参数名称、单位及所属路径，选择结果后进入相应设置组，展开并标出目标参数。
查找范围为当前方案适用的概念设计参数，查询不会改变输入或确认状态；输入检查发现错误时也直接定位到对应设置。
环境压力采用绝对压力：0 MPa 显示为真空，0.101325 MPa 显示为标准海平面，其余有效取值显示为自定义背压。

## 发动机节流分析

选择已完成且通过来源检查的 FFSC 设计记录，进入“固定硬件稳态分析 → 发动机节流扫描”。当前可运行的是基准标定局部节流估算：扫描保持已标定部件关系和喷管几何不变，通过两侧等效通流系数求解新的稳态状态，不调用概念设计的预燃室温度反求，也不在各点重设计硬件。

推力指令百分比以来源记录的实际已求解推力为 100%，不是输入框中的目标推力；环境压力和推力口径随基准固定。请求推力、实际达到推力、氧燃比、方程残差、模型域和几何冻结检查分别保存。横轴表示独立稳态工况，不表示时间；缺失或失败点不补值、不跨点连线。

任务与来源设计分别保存，修改当前草稿不会改变所选基准或既有扫描。页面提供性能曲线、逐点诊断和数据导出；100% 点用于检查局部模型能否重现来源。完整固定硬件分析仍受独立的数据和部件模型接入门槛约束；局部估算收敛不能证明完整硬件可实现、深节流无分离、燃烧稳定或实机节流包线。

旧设计匹配扫描仅在“校核与记录”保留只读历史，不能与新算法结果混用。模型方程、固定量、执行机构近似、入口要求和验证边界见[发动机节流分析说明](ENGINE_THROTTLE_ANALYSIS.md)。

原设计若采用完整 53 物种，不直接充当本页理想基线；
也不能将两端差值与物种删减造成的差异混为一谈。

新的 PR–BM 对比还在两端共同设置 `hot_side_thermo_method=same_eos`：统一冻结组成准一维加热算法、
单元中心取值及实际总温／静温比 Bartz 修正。此设置只进入新对比记录，不改来源设计或旧理想气体默认算法。
报告核对两侧实际热侧剖面的模型标识；固定热载荷、未启用分布加热时标为不适用。
缺少共同算法证据的历史 PR–BM 报告保留两端数值，但不展示差值或宣称单一 EOS 敏感性。

对比任务独立保存来源项目、方案版本、设计记录及输入/结果哈希，当前未保存草稿不参与计算。
模型身份记录机制文件 SHA-256、物种策略与清单指纹、PR 参数指纹、混合规则及各段实际模型；
PR–BM 另保存高温 alpha 公式版本、来源和 `eos_model_sha256`，对比会核对全燃气站点的模型指纹。
完整证据可随 JSON 导出。两端均收敛并通过独立流量、压力、能量与模型身份检查后才显示差值；
失败端保留原因和已取得的数值，不生成替代结果。

任务执行时间采用有界预算：普通任务 600 秒，PR–BM 设计点 3600 秒，来源为 PR–BM 的理想气体 / PR
整机对比 4200 秒。对比预算依据同项目、同方案版本的已保存来源模型，排队等待不占执行预算。
若启动程序显式传入 `job_timeout`，该值统一覆盖上述预算，包括较小的测试或管理员限额。

本页用于比较同物种集合下的模型敏感性，不是高压实验验证。默认混合规则、高压化学平衡、相稳定性
及高压输运尚未获得独立验证。Cantera 的[物种热力学说明](https://www.cantera.org/stable/reference/thermo/species-thermo.html)

## 热态瞬态分析与文献依据

选择数值收敛、系统约束通过的稳态记录，进入“瞬态响应分析”。先检查初始化准备度，设置时间、输出采样数和两侧相对有效阀口面积，再展开容积、转动惯量与局部泵斜率，核对参数来源。提交后使用独立任务、可取消队列和不可变来源快照，提供六组时间曲线、时间截面检查、守恒审计以及 CSV / SVG / JSON 导出。

Web 热态瞬态研究仅从液氧甲烷 FFSC 来源初始化。`src/lre_workbench/operations/transient.py` 对燃气容腔质量、热内能和轴系动能进行 Radau 刚性积分。当前研究固定主喷管有效面积，使用名义点拟合的局部泵、液阻和涡轮关系，燃气 cp/R/组分冻结。90%–110% 是阀口有效面积相对值，不是发动机推力范围；输出采样数不控制自适应内部步长。压力、温度、转速偏离名义值或喷管失去壅塞时，通过连续事件终止，保留此前有效结果。

转动惯量、预燃室与排气容积、泵斜率默认值是研究假设，未经实机标定。入口热焓按支路名义温度形成一致的局部热能账目，不直接混用不同物性库的原始焓零点。该模型未实现冷态点火、两相充填、液柱惯性、水击、壁面蓄热和控制器，不能据此给出实机启动时序或安全操作限值。数值闭合不代表试验验证。

节流稳态分析新增“有限区间节流响应增益”：以有效100%点归一化，相邻扫描点计算割线增益；不跨失败点或几何失效点。它是耦合节流路径的响应指标，不是独立设计参数的偏导数。

逐篇文献证据与后续计划见 [瞬态文献依据](TRANSIENT_LITERATURE_EVIDENCE.md) 和 [稳态文献差距](STEADY_LITERATURE_GAPS.md)。

## 供给网络动态

选择已完成的设计记录后，进入左侧“供给网络动态”。该记录提供液氧/甲烷或液氧/正十二烷的泵标度与入口温度，编辑区中的管路、容腔、阀门和背压则是独立研究参数。默认 2 s 时间线在 0.2 s 开始，将规定转速与阀指令从 100% 逐渐降至 80%；这不是整机推力节流命令。

分别检查液氧与燃料的边界/初值、管长管径及额定损失、容腔容积、阀门滞后/限速/泄漏和泵图，再点击“运行供给网络动态分析”。可观察压力、带符号流量、液体库存、阀门指令与实际开度、规定转速、泵转矩及功率、逐回路守恒误差。可切换工质和时间截面，取消任务，查看独立历史，导出 JSON、CSV、SVG。初始容腔压力改变后，由后台按来源入口温度重新计算并冻结参考密度/体积模量，以最终结果快照为准。

解析泵图仅用于接口和数值演示，未经实测标定。真实图可在“低速与反流泵图”中导入 `theta_deg,head,torque` CSV；必须采用页面标注的角度、归一化、完整周期及额定点约定，后台检查插值耗散和适用域。低压、压缩应变、泵图域或阀行程越界会停止积分并保留有效结果。库存变化不是液位，能量审计是液压机械能余额。

原设计整机约束未通过时仍可研究独立供给支路，但原失败状态不会被改为通过，热态整机瞬态初始化门槛也不放宽。本页尚不包含真实流体热状态演化、汽蚀/两相、预冷、水击传播、驱动轴自启动、点火或关机阀序。详细说明见 [供给网络模型与证据](FEED_NETWORK_DYNAMICS.md)。

## 预冷与充填分析

打开已完成设计记录后，选择“系统仿真 → 预冷与充填分析”。设计记录提供工质种类和默认供给温度；容腔初温、气液库存、金属壁温与热容量、壁流换热导纳及节流面积在本页独立设置。PT 初态用于单相，PQ 初态用于饱和气液状态。选择回路和时间截面查看壁温/流体温度、压力、库存、气相体积分数及各边界通量，结合守恒结果和用户目标判据判断结果。

记录可取消、回看并导出。末态快照含质量、内能、壁温和物性信息，只为后续网络初始化提供材料，不会覆盖原设计或自动开启点火。当前只计算纯推进剂均相平衡单元，不能模拟氮/氦吹除、选择性排气、空间充填前沿或完整发动机冷启动。详见 [模型说明](CHILLDOWN_MODEL.md) 与 [文献依据](CHILLDOWN_LITERATURE_EVIDENCE.md)。

## 点火事件与建压分析

打开已完成的液氧/甲烷 FFSC 设计记录，进入“系统仿真 → 点火事件与建压分析”。记录只提供推进剂种类与来源标识；本页使用独立的气态氧/甲烷压力源、有限容积和阀门，不继承低温液体温度。来源设计约束未通过时可研究独立容腔，原设计的失败状态保留；煤油来源不可替换为甲烷运行。

依次核对容腔与初态、气体供给、两侧阀门时序、外部点火热脉冲、金属壁面以及停止边界。可选择初始氮气或未燃氧/甲烷混合物，分别开关化学反应并设置脉冲能量，比较相同边界下有无外部点火能量、反应与纯气体充填的差别。GRI-Mech 3.0 共同热力学温域采用 300–3000 K；越界保留最后有效结果，不按数值截断继续积分。

结果提供压力、气体/壁温、进出口流量、阀位、外加点火功率、化学放热率、主要组分、库存、壁面传热和守恒曲线。给定事件与已到达的事件分开显示，时间滑块查看单一截面；可取消任务并导出已有数据。默认采样点之外保留事件时刻，输出点数不控制内部自适应积分精度。

本页不预测点火成功、延迟或熄火；参考压力首次达到时间只描述压力响应。末端快照不能作为完整发动机启动初值直接执行。实验对照、适用域与后续判据接入要求见 [模型说明](IGNITION_STARTUP_MODEL.md)、[证据表](IGNITION_STARTUP_EVIDENCE.md) 和 [本轮验证](IGNITION_STARTUP_VALIDATION.md)。

## 稳态数值方法与完整收敛（2026-10-23 第二轮）

“总体设计点计算 → 求解设置”默认使用缩放 Newton 与回溯线搜索，可选择有界信赖域 TRF
作为对照。两种方法使用相同物理方程、变量边界、缩放规则和残差验收标准；TRF 的
优化器停止标志不替代方程残差与完整外环判定。旧方案缺少 `nonlinear_solver` 字段时
按 `newton` 载入；既有计算历史不补造轨迹。重新运行设计点后查看新增证据。

“完整收敛与迭代历程”显示四层判据、内外环残差曲线、循环残差求值次数、雅可比次数、
未接受试探、热启动以及延续接受／拒绝明细。每次内层调用独立绘图，可以展开其固定
缩放与有单位的容许误差。内层曲线仅画实际接受点；热反馈拒绝试探在曲线上断开，在
数值表中保留残差、松弛系数及拒绝状态。Newton 回溯控制残差平方和下降，图示最大分量
范数可以短暂上升，不能据此单独判定算法失效。

完整热启动在同一次温度目标外环内传递流量／压比、Tc、γ、摩尔质量；失败时重试冷启动
延续。独立计算不会继承陈旧缓存，临时输入在正常、失败及取消退出时恢复。延续失败缩步、
成功增步，分别记录成功到达比例和最后尝试比例；热反馈采用受保护的自适应松弛与振荡抑制。
取消仍通过任务控制传播，固定供给边界的非法工质相态仍直接拒绝。

所有真实循环残差评价（含差分、拒绝和异常试探）共享每次内层调用的预算：
`max(1, 2 * (变量数 + 1) * (最大接受步数 + 1))`。默认 50 步时，三变量为 408 次、
两变量为 306 次；耗尽后保存最后接受点并标注 `max_evaluations`。这不是整个嵌套任务的
总预算，也不包括温度反求中单独调用的热化学函数次数。

实算、输入快照、计数及复现脚本在 `diagnostics/numerical_methods_20261023/`：

- `compare.py`：原截图额定点、不同数值初值、低推力设计点的 Newton/TRF 对照。
- `check_warm_start.py`：仅关闭完整热启动，隔离其减少重复计算的效果。
- `check_throttle.py`：同一主喉部／冷却几何下，40% 和 100% 两工况回归；仍显示供给约束失败。
- `check_jacobian_steps.py`：差分步长减半敏感性检查。
- `convergence_preview.html`：使用生产页面渲染器生成的 Newton/TRF 实算交互预览。

运行上述 Python 脚本使用 `.venv-web/Scripts/python.exe -X utf8`。本轮 175 项 Python
回归和 310 项前端测试通过，桌面入口已作编译检查；当前环境缺少 PySide6，未执行桌面
交互测试。浏览器自动化连接失败，预览已生成并通过静态渲染和前端测试，未宣称完成截图验收。


## FFSC 燃气交接与逐点筛查（2026-10-29）

进入“热力学校核 → 燃气交接与筛查”，选择已保存的设计记录后运行。
新设计记录保存四条预燃室支路、两预燃室出口、两股涡轮排气及主室的完整组成、
元素质量分数与流量、化学焓／熵、端口总静态约定、EOS、相、机制 SHA-256 和参考基准。
主室读取真实涡轮排气；组成缺失、非有限焓、质量流量不符或已知模型身份冲突会拒绝交接。
旧记录只有可核实的已保存文件身份才能重算元素；未记录的总静态保持缺失。

本页三类结果分别保存，不改写来源设计：

- 交接审计：各部件气相元素与焓流守恒，分开显示完整性、内部一致性和模型准确性。
- 实际主室 HP 复核：用保存排气的完整组成、元素和焓，扣除保存抽热，复现经验温升折减前的主室平衡；
  再以相同元素／焓／压力做共同 CHO16 理想气相 Cantera—CEA 对照。等效元素入口卡仅用于数据库比较，
  不替换生产组成；保存逐物种温域证据、元素和焓残差。纯推进剂一次燃烧仍保留为独立理论基线。
- 候选 EOS 与相集合筛查：四站 Cantera PR／RK、REFPROP 固定组成物性及冻结膨胀；
  同元素、总焓和压力的气相／气相加石墨平衡。石墨质量分数的分母为最终气固总质量，不能解释为沉积速率。

PR／RK 只使用可追溯临界参数，记录缺参数的全部物种。完整组成不支持时另列约简候选、
每个移除物种、移除质量及元素／焓偏差；不静默丢弃。对照计算密度、Z、焓、熵、热容、声速和
等熵焓降，而非仅修正密度。REFPROP 使用本机授权数据库，通过 CoolProp 调用；共享原生锁内
禁止估计缺失的二元参数和隐式 EOS 替换，结束后恢复配置。各组分温压范围单独检查。
REFPROP 焓熵在共同固定组成参考态作常数平移，不能跨组成用于化学平衡。

生产燃气仍采用明确披露的 `ideal-gas` 化学平衡基线。本次没有把不完整、未验证的非理想
混合物参数推入循环，也未验证高压化学势／逸度对平衡组成、输运、有限速率燃烧和实际积碳。
`gri30_highT` 扩展热化学温域不等于真实气体 EOS。后续生产切换需完整候选物种参数及相互作用、
参考态一致性、密度／焓／声速／平衡数据和循环敏感性验证，不能只修改 YAML 的 EOS 名称。

接口：`POST /api/projects/{id}/validations` 增加 `gas_screening: {enabled: true}`；
状态和组成仅由 `source_job_id` 指定的不可变记录读取，禁止请求覆盖。响应含
`gas_handoff`、`chamber_handoff_comparison`、`gas_screening`，沿用独立任务、取消、历史和 JSON 导出。

实现入口：`src/lre_workbench/integrations/gas_handoff.py`、`webapp/chamber_handoff_compare.py`、`webapp/gas_screening.py`。
参考：[Cantera 气相模型](https://cantera.org/stable/reference/thermo/phase-thermo.html)、
[EOS 物种参数](https://cantera.org/stable/yaml/species.html)、
[Cantera 气相加石墨平衡示例](https://cantera.org/stable/examples/python/thermo/adiabatic.html)、
[CoolProp REFPROP 接口](https://coolprop.org/coolprop/REFPROP.html)。

### 供给边界、效率假设与主室热化学（2026-10-29）

原“入口与效率”在网页中分为“推进剂供给条件”“泵与涡轮效率假设”及
“主室燃烧与能量模型”。详细定义集中在帮助文档的“参数参考”，各组提供“参数定义与依据”入口；数值键和旧方案
输入保持不变。供给组继续使用 `inlet` 导航标识，刷新时仍能恢复。

- 贮箱出口液温是发动机/供给系统接口条件，不是主泵入口温度或自动求解的贮箱温度。
  页面按液氧、液甲烷分列“贮箱出口接口条件”与“前置泵与供给管路假设”，
  压力统一显示为 MPa（内部仍用 Pa）。两路独立设置出口绝对压力、前置泵出口设计压力、
  等熵效率和设计点管路压降。给定值参与本次设计点计算，不是迭代初值。
  气枕自生增压、贮箱液柱/加速度及吸入管损未单独求解；这些简化必须纳入接口评审。
- 前置增压泵是当前供给构型假设，不是 FFSC 的必要组成；也不等同于主泵诱导轮。
  它的焓升和供功已计算，功率属于外部输入，不分摊给两根主涡轮轴。
  改变真实驱动连接前必须重做轴功和整机能量账，不能仅在图上更名。
- 常效率适合初步设计点，但需要来源及敏感性研究。

  当前的供给短管固定压降也不是由管径、阻力系数和流量求出的水力特性。
- 两路新字段以 `fuel_` / `ox_` 为前缀，后缀为 `tank_pressure_pa`、
  `boost_outlet_pressure_pa`、`feed_line_dp_pa`、`boost_pump_efficiency`。
  空值或旧方案缺少字段时，分别沿用原 `tank_pressure_pa`、`inlet_pressure`、
  `feed_line_dp_pa`、`boost_pump_efficiency`，不改写旧方案或历史结果。
  表单显示实际采用值及继承说明；编辑只影响本路，清空恢复原共用值。
  压降为 0 是有效独立设定，不能被当作空值。
- “推进剂供给条件”的工程视图区展开两条供给链，区分给定值与压力关系计算。
  主泵入口压力为前置泵出口压力减去管路压降；入口温度由求解后的保存状态读取，
  当前草稿不将贮箱出口温度复制为主泵入口计算结果。
- 主室“定压焓平衡化学平衡”用实际入口完整组成及统一化学焓做 HP 平衡。
  FFSC 接收两股涡轮排气；零维能量约束为 `m_out*h_out = sum(m_in*h_in) - Q`。
  这里的焓包含生成焓，不再次叠加燃料低热值。预算冷却在主室扣热，准一维冷却
  在沿程热侧扣热，不重复计入。化学平衡包含解离；无附加温升折减不代表
  c* 效率、燃尽率或燃烧稳定性已经验证。历史温升模型继续保留，不自动转换。

### 物性资料与工程示例

工程示例入口移至新建项目和“模型与资料库 → 工程示例与来源”。选择条目只浏览，必须明确执行替换才改写当前草稿；替换可撤销，原计算记录保持原样。

“工质与热物性模型”负责方案配置，“热物性与材料数据”负责查阅安装数据与保存依据，帮助文档解释方法。资料页读取实际 Cantera YAML 的来源、生成器版本、运行时版本、候选物种、NASA7 分段系数与输运参数；CoolProp HEOS 分别显示纯流体 EOS 和输运文献键；壁面数据保留试样制造状态、原始出处与各性质温区。

只读接口 `GET /api/property-library` 和 `POST /api/property-library/curve` 均要求登录；曲线请求仅接受登记数据集、有限温压、2–121 个点和可选的数据指纹。查询不会修改项目、模型默认值、参考态或求解器状态；拒绝越界外推和指纹不一致，逐点查询失败保留缺项，相态变化不跨段连线。物种曲线单位为 J/mol、J/(mol·K)，是声明参考压力下的标准态性质；不进行化学平衡或发动机复算。

新设计计算的 `thermodynamic_applicability.data_manifest` 保存热化学数据快照、实际候选物种、使用的纯流体数据及壁面导热使用身份。各燃气节点单独保存质量组成。历史结果缺少这些字段时仅展示原有证据，不从当前安装库补写。概略冷却或给定热量模式中的材料配置标为未参与壁面导热。
