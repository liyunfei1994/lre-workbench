# 本机网页版：系统仿真与总体设计

当前网页版专用于**液氧甲烷全流量补燃循环（FFSC）发动机的系统仿真与总体设计**。新建、参数修改和计算提交只接受这一循环与推进剂组合。其他架构的旧方案仅保留原始数据查看与导出，页面提示不支持，不再绘制专用图纸或提供部件分析。新概念设计任务使用仅含 FFSC 字段的 v3 契约；旧 FFSC 参数中的其他循环冗余字段在归一化时清理。
网页采用正式的分区工作台：左侧按“模型与数据、设计与配置、工况与运行、结果与诊断、文档与维护”组织入口，主区域显示当前任务。概念设计分为“设计输入、计算结果、收敛诊断”，参数编辑和结果查看分别占用主区域。
“推力室内型面”提供所选计算记录的二维尺寸图、三维旋转面和坐标导出；与冷却计算共用保存的内轮廓。型面参数统一在“推力室型面与覆盖”中设置，方法与适用边界见[喷管几何说明](NOZZLE_GEOMETRY.md)。旧记录有完整轮廓时，刷新页面即可查看，无需重新计算。
“结果与诊断”中的“热力学校核”提供同条件 CEA–Cantera 对比、系统守恒、真实流体物性与试验验证，详见[校核口径与限制](THERMODYNAMIC_VALIDATION.md)。
“涡轮设计与建模交接”汇总记录绑定的循环设计点、富氧／富燃燃气物性、功率匹配与部件初选值，可导出 CFturbo 设计任务书，支持可选均径速度三角形和逐级比功分配。概念流道移至折叠参考区，历史记录不按最新默认值补算；详见[涡轮设计条件说明](TURBINE_DESIGN.md)。
详细部件设计、推力室详细分析、有限元和 CFD 不在本阶段网页范围内。

## 主燃烧室设计与分析

进入“设计与配置 → 主燃烧室设计与分析”，选择已完成的 FFSC 计算记录。五个页签分别查看入口与设计点、平衡热化学与组成、主室几何、冷却与材料、方法与交接。入口采用真实保存的富氧和富燃涡轮排气；页面不按当前草稿补算或改写历史结果。

主室二维尺寸图与三维旋转参考面只使用喷注面至喉部的原始内壁母线。坐标导出需通过保存几何一致性检查，可选择 m 或 mm，保持点序和坐标原点。设计参数、完整组分、主室冷却单元可分别导出 CSV，JSON 保留记录来源、模型、核对项与交接说明；这些资料不包含网格、实体壁厚或完整 CFD 边界条件。

冷却曲线仅来自同记录主室范围的已保存单元，缺失样本保留断点；材料身份、分区和声明温区另行核对。HP 平衡状态、L*、名义容积更新时间及声学频率不能证明燃尽或稳定性。页面可跳转“热力学校核 → 燃气交接与筛查”，按实际入口的元素、焓、压力及允许物种进行 CEA／Cantera 独立对照。详细定义和后续验证边界见[主燃烧室总体设计与分析](MAIN_CHAMBER_DESIGN.md)。

## 喷注器初步设计与三处接口

“喷注器初步设计”读取同一保存记录，分别展示主燃烧室、富氧预燃室和富燃预燃室三处喷注接口。部件性能分析中的相关对象可跳转到对应接口，也可返回原部件。

主喷注器当前是中心圆孔＋外环缝的同轴概念构型；中心为富氧涡轮排气，外环为富燃涡轮排气。它不是针栓，未完成切向孔或旋流槽设计，原模型中的旋流数仍为经验假设。面板直径、启发式单元数、中心孔径、中心管外径、外环流道外径、径向缝宽及壁厚假设统一来自 `components.injector`；网页、桌面几何和图示不再独立估算单元数。面积等效间距不是完成孔位排布后的节距。横截面按保存直径等比例绘制，不补造轴向长度、缩进量、旋流槽或外筒壁厚。

环缝使用精确关系 `A = πδ(d_post + δ)` 反解，程序采用避免薄缝消减误差的等价形式。保留现有不可压缩孔口关系 `v_effective = Cd*sqrt(2Δp/ρ)`；`ṁ = Nρv_effective A` 中 Cd 只计一次。返回的内外径独立回算面积与质量流量。原中心孔径 1–50 mm、环缝 0.2–5 mm 仅为历史参考范围，越界保留计算值并告警，不静默裁剪后声称闭合。气体可压缩性、阻塞、混合／燃烧性能及制造可行性仍需后续验证。

两处预燃室各自有喷注器。其入口来自氧化剂／燃料供给支路，不是主室使用的两股涡轮热排气；相态应以局部压力、温度和物性判断。当前预燃室只保存各支路流量、喷注压降及集总支路状态，尚未给出结构、单元数、Cd 和喷孔入口局部状态，因此本页不生成预燃室孔径，也不套用主喷注器几何。这里的集总支路温度不是已解析的喷孔入口静温。

历史记录不改写。缺少新版几何合同、密度和所需面积时，页面标为旧记录／依据不足；有矛盾则显示不一致。重新运行设计点才获得修正后的尺寸。JSON 导出保留各站边界、尺寸、假设与回算状态，不是 CAD 或可直接求解的 CFD 模型。

一致性检查覆盖主喷注器面积与流量、涡轮排气状态，以及主室／推力室／冷却热壁的喷注面内径。预燃室另按供给源压力减去管路、阀门和目标室压力，独立校核喷注压降；设计模式核对保存压降比，固定阻力模式核对保存阻力关系。缺少依据不显示为通过。

## 程序更新与重新计算

- 仅修改已登记的界面文字、样式和图表显示方式后，刷新网页即可重新加载。首页、静态资源和 API 均设置 `Cache-Control: no-store`，不需要通过运行设计点来更新界面；刷新前先保存参数草稿。
- Python 后端、参数定义或数据读取逻辑修改后，需要先在无运行任务时停止并重新启动本机服务，再刷新网页。仅刷新网页或重复打开启动器不会替换长驻进程里已加载的模块；提交设计点也不是更新服务的方法。
- 本次分区工作台新增 `partitioned-workspace.css`，并修改后端静态资源白名单。从旧服务升级时，需确认没有运行任务后停止并重新启动一次服务，再刷新网页；只刷新旧服务可能无法加载新增样式。
- 已保存的计算与校核记录保持原结果，不因代码更新或网页刷新而改写。要用新方程生成系统结果，运行设计点；要更新 CEA–Cantera 等独立校核，运行校核页的“运行扫描对比／运行本项校核”。两类记录分别保存。
- 新版本的默认参数不会自动覆盖现有方案。需要变更方案参数时，明确编辑、保存后再计算。

## 参数分组确认与刷新恢复

“确认并保存本组参数”保存本组确认记录；当前有未保存编辑时，同时将当前草稿保存为新版本。仅确认已有版本的参数时，不增加方案版本。确认记录按方案及版本保存在本机数据库，刷新网页或重新登录后恢复，恢复时仍进行输入校验。

确认状态与分组参数、循环构型和参数定义版本关联。修改相关参数后，该组恢复为“待确认”；未修改的分组保留确认状态。选择“自定义方案（沿用当前值）”保留参数值并清除草稿的确认状态，需要保存或逐组确认。选择工程示例属于显式采用示例值，保存后可恢复“采用示例”状态。

“输入校验通过”与“已确认”分别表示输入检查结果和用户确认记录。打开分组、存在默认值或选择导航项，不代表已确认。升级前未持久化的确认记录无法追溯，需确认一次；本次升级含后端数据库读取逻辑，需重新启动工作台服务后使用。

## 预燃室热力设计：条件、接口、结果与可选约束

全流量补燃循环的参数统一在“预燃室热力设计”中编辑。指定出口燃气温度时，在当前入口焓和压力下求解预燃室氧燃质量比并进行循环匹配；指定氧燃质量比时计算出口燃气温度。仅显示当前生效的设计条件，氧燃质量比迭代初值与压力初猜收在高级设置。两种方式是设计任务的不同闭合条件。预燃室氧燃质量比与整机氧燃质量比分别按各自入口流量定义。

页面按“设计条件、系统接口、匹配结果、设计约束（可选）”排列。系统接口卡链接到供给边界、压力网络、再生冷却和部件效率的原设置分组，不另建重复输入。匹配结果读取当前选中的计算记录，显示两侧预燃室流量、压力、燃气温度及轴功率差；草稿参数变化后保留记录数值并提示重新计算。无结果或数据缺失时不以设计目标代填。

可选约束默认折叠，摘要显示两侧设置状态；展开后分别设置两侧约束。字段搜索和错误定位会展开相关设置。新建自定义方案默认两侧均为“未设置”；从工程示例切换为自定义方案时，按原有操作语义保留当前输入。

两侧温度上限各自有状态与依据，独立于设计目标：

| 状态 | 计算和验收行为 |
|---|---|
| 未设置 | 隐藏上限与依据输入；保存的旧限值不参与目标校验、涡轮限值或超限判断；该项尚未评估。 |
| 设计暂定 | 检查暂定数值；超限为未通过，数值满足仍为依据待核实，不能显示工程通过。 |
| 依据已登记 | 必须填写约束来源与适用工况，再按该方案限值检查；来源登记不构成材料、寿命或氧相容性认证。 |

为保持旧方案行为，网页及桌面读取缺少约束状态的历史保存方案时，保留原限值并按“设计暂定”处理；显式保存的“未设置”保持停用。工程示例显式保留 800 / 900 K 暂定上限。750 / 850 K 目标也是本项目的概念设计选择；不是 Raptor 3 测量值。未设置约束时，可进行设计计算，但不能把“没有发现超限”写成约束已通过。燃气整体出口温度、局部热点、涡轮金属温度及材料许可范围是不同的量。

状态与依据随方案版本和计算输入保存。历史结果不重算、不修改原始判定；网页对历史缺依据的预燃室检查补充暂定说明。需要新版系统验收结果时，再运行一次设计点。本轮执行策略版本为 4。

设计依据的使用边界：

- [NASA SP-8081《Liquid Propellant Gas Generators》](https://ntrs.nasa.gov/citations/19730018978)讨论涡轮驱动燃气、温度影响及控制，不能据此给当前甲烷 FFSC 套用一个通用温度上限。
- [DLR 2022 SLME 研究](https://elib.dlr.de/186560/1/SP-2022_Systematic_Studies_on_Reusable_Staged-Combustion_Rocket_Engine_SLME_for_European_Applications.pdf#page=8)第 8 页将混合比选择与涡轮入口温度限制联系起来；该方案使用液氧/液氢，具体数值不能直接转用于甲烷。
- [EADS 2006 可重复使用发动机研究报告](https://edocs.tib.eu/files/e01fb08/565308254.pdf#page=61)印刷第 57–58 页 §2.4.8.1 给出特定液氧/甲烷研究的富燃 900–950 K、富氧 700–750 K 选取范围。图 2-28 与 2-29 的甲烷入口分别为 240 K、140 K，液氧入口均为 122 K，效率假设也不同；报告的单轴、单预燃室基线不是 FFSC 双预燃室的一对设定，不作为本平台默认限值的证据。
- 本轮查阅的 [SpaceX 官方 Raptor 3 更新](https://www.spacex.com/updates/reusability)未提供可追溯的两侧预燃室出口温度。仅靠公开推力、比冲等整机指标不能唯一反求两侧温度；还需入口状态、压降、流量分配和涡轮泵性能等条件。基于自选条件的计算应标为概念方案，不标为实机重建。

## 第一次使用

1. 双击项目根目录的 `start_web_windows.bat`。优先检查本机全局 Python 3.14（标准版、64 位），
   包括用户默认安装目录、Python 启动器及 PATH；也可通过 `LRE_PYTHON` 指定基础解释器。
   全局环境必须通过 `requirements-web.txt` 版本检查、模块导入及科学库功能检查。
   缺包、版本不符或模块无法加载时，自动切换到项目 `.venv-web`；后备环境缺失或缺包时在其中创建／安装，
   不会自动向全局环境安装包。启动窗口显示 `Using global Python` 或 `Using project virtual environment`
   及实际解释器路径。`setup_web_windows.bat` 始终用于准备或修复 `.venv-web`。
   如尚无可用 Python 3.14，请先安装。已经运行的网页服务需要先停止再启动，才能切换解释器。
2. 浏览器打开 `http://127.0.0.1:8765`。首次创建个人账号：用户名为
   3–32 位字母、数字、下划线或短横线；密码必填，最多 128 位。没有内置默认密码。
   已有工作区继续使用原管理员账号；原方案、版本和计算结果保留。
3. 点击“新建项目”，选择已有参考工况，或打开已有方案。进入“设计与配置 → 概念设计 → 设计输入”。
   参数表单在主区域完整展开，按分组选择或搜索参数、单位；参数区采用单层滚动，不再与结果并排挤在三栏中。
   表单显示液氧甲烷 FFSC 的设计输入及系统热边界假设，循环与推进剂为既定架构，采用固定架构。参数定义与显示单位共用桌面声明，存储与求解仍用 SI 单位。
   后台保存完整参数，普通操作只需编辑表单；旧方案缺少 `propellant_pair` 时默认液氧/甲烷。
4. 修改后点击概念设计页顶部的“运行设计点”。网页先保存修改为新版本，再提交
   对应版本计算，并切换到“计算结果”分区更新任务状态和结果；在“收敛诊断”查看残差、迭代与失败位置。仅保存时点击“保存方案”。
   “结果与诊断”中的“计算结果总览”和“收敛诊断”也可直接查看同一条已保存记录，流路、部件和校核页面继续使用该记录。
   “模型与数据”按“工程部件、特性与关联模型、物性与材料、数值工具”四类整理现有入口与接入状态；分类本身不会导入模型或生成部件特性。
   同一方案内切换功能页或分区会保留参数草稿，不会因查看历史结果而替换当前输入。未保存时刷新或关闭网页会触发浏览器离开提醒；导航记忆不保存参数草稿，请先保存方案。
   关闭网页后，只要服务仍在运行，计算会继续。

## 发动机节流分析

选择已完成且通过来源检查的 FFSC 设计记录，进入“工况与运行 → 发动机节流分析”。当前可运行的是基准标定局部节流估算：扫描保持已标定部件关系和喷管几何不变，通过两侧等效通流系数求解新的稳态状态，不调用概念设计的预燃室温度反求，也不在各点重设计硬件。

推力指令百分比以来源记录的实际已求解推力为 100%，不是输入框中的目标推力；环境压力和推力口径随基准固定。请求推力、实际达到推力、氧燃比、方程残差、模型域和几何冻结检查分别保存。横轴表示独立稳态工况，不表示时间；缺失或失败点不补值、不跨点连线。

任务与来源设计分别保存，修改当前草稿不会改变所选基准或既有扫描。页面提供性能曲线、逐点诊断和数据导出；100% 点用于检查局部模型能否重现来源。完整固定硬件分析仍受独立的数据和部件模型接入门槛约束；局部估算收敛不能证明完整硬件可实现、深节流无分离、燃烧稳定或实机节流包线。

旧设计匹配扫描仅在“结果与诊断”保留只读历史，不能与新算法结果混用。模型方程、固定量、执行机构近似、入口要求和验证边界见[发动机节流分析说明](ENGINE_THROTTLE_ANALYSIS.md)。

## 稳态数值方法与完整收敛（2026-10-23 第二轮）

参数区新增“数值求解”：默认使用缩放 Newton 与回溯线搜索，可选择有界信赖域 TRF
作为对照。两种方法使用相同物理方程、变量边界、缩放规则和残差验收标准；TRF 的
优化器停止标志不替代方程残差与完整外环判定。旧方案缺少 `nonlinear_solver` 字段时
按 `newton` 载入；既有计算历史不补造轨迹。重新运行设计点后查看新增证据。

“完整收敛与迭代历程”显示四层判据、内外环残差曲线、循环残差求值次数、雅可比次数、
未接受试探、热启动以及延续接受／拒绝明细。每次内层调用独立绘图，可以展开其固定
缩放与有单位的容许误差。内层曲线仅画实际接受点；热反馈拒绝试探在曲线上断开，在
数值表中保留残差、松弛系数及拒绝状态。Newton 回溯控制残差平方和下降，图示最大分量
范数可以短暂上升，不能据此单独判定算法失效。

完整热启动在同一次温度目标外环内传递流量／压比、Tc、γ、摩尔质量；失败时重试冷启动
延续。独立计算不会继承陈旧缓存，临时输入在正常、失败及取消退出时恢复。延续失败缩步、
成功增步，分别记录成功到达比例和最后尝试比例；热反馈采用受保护的自适应松弛与振荡抑制。
取消仍通过任务控制传播，固定供给边界的非法工质相态仍直接拒绝。

所有真实循环残差评价（含差分、拒绝和异常试探）共享每次内层调用的预算：
`max(1, 2 * (变量数 + 1) * (最大接受步数 + 1))`。默认 50 步时，三变量为 408 次、
两变量为 306 次；耗尽后保存最后接受点并标注 `max_evaluations`。这不是整个嵌套任务的
总预算，也不包括温度反求中单独调用的热化学函数次数。

实算、输入快照、计数及复现脚本在 `diagnostics/numerical_methods_20261023/`：

- `compare.py`：原截图额定点、不同数值初值、低推力设计点的 Newton/TRF 对照。
- `check_warm_start.py`：仅关闭完整热启动，隔离其减少重复计算的效果。
- `check_throttle.py`：同一主喉部／冷却几何下，40% 和 100% 两工况回归；仍显示供给约束失败。
- `check_jacobian_steps.py`：差分步长减半敏感性检查。
- `convergence_preview.html`：使用生产页面渲染器生成的 Newton/TRF 实算交互预览。

运行上述 Python 脚本使用 `.venv-web/Scripts/python.exe -X utf8`。本轮 175 项 Python
回归和 310 项前端测试通过，桌面入口已作编译检查；当前环境缺少 PySide6，未执行桌面
交互测试。浏览器自动化连接失败，预览已生成并通过静态渲染和前端测试，未宣称完成截图验收。


## FFSC 燃气交接与逐点筛查（2026-10-29）

  同元素、总焓和压力的气相／气相加石墨平衡。石墨质量分数的分母为最终气固总质量，不能解释为沉积速率。

### 供给边界、效率假设与主室热化学（2026-10-29）

原“入口与效率”在网页中分为“推进剂供给边界”“泵与涡轮效率假设”及
“主室燃烧与能量模型”。详细定义放在各组“参数说明与依据”，数值键和旧方案
输入保持不变。供给组继续使用 `inlet` 导航标识，刷新时仍能恢复。

- 贮箱出口液温是发动机/供给系统接口条件，不是主泵入口温度或自动求解的贮箱温度。
  当前两路共用一个贮箱出口绝压、一个前置增压出口绝压和一项短管压降预算。
  气枕自生增压、贮箱液柱/加速度及吸入管损未单独求解；这些简化必须纳入接口评审。
- 前置增压泵是当前供给构型假设，不是 FFSC 的必要组成；也不等同于主泵诱导轮。
  它的焓升和供功已计算，功率属于外部输入，不分摊给两根主涡轮轴。
  改变真实驱动连接前必须重做轴功和整机能量账，不能仅在图上更名。
- 常效率适合初步设计点，但需要来源及敏感性研究。
  泵采用 `eta_p = (h_out,s - h_in)/(h_out - h_in)`；
  涡轮采用 `eta_t = (h_in - h_out)/(h_in - h_out,s)`。
  外部数据必须匹配总/静态和机械损失口径。固定硬件变工况最终需要部件图谱；
  当前的供给短管固定压降也不是由管径、阻力系数和流量求出的水力特性。
- 主室“定压焓平衡化学平衡”用实际入口完整组成及统一化学焓做 HP 平衡。
  FFSC 接收两股涡轮排气；零维能量约束为 `m_out*h_out = sum(m_in*h_in) - Q`。
  这里的焓包含生成焓，不再次叠加燃料低热值。预算冷却在主室扣热，准一维冷却
  在沿程热侧扣热，不重复计入。化学平衡包含解离；无附加温升折减不代表
  c* 效率、燃尽率或燃烧稳定性已经验证。历史温升模型继续保留，不自动转换。

新计算在 `thermodynamic_applicability.pure_fluid_states[].supply_screen` 保存六个供给端口
的 HEOS 相态、版本、饱和温度、过冷度、可用熔化线和 NPSH 静压分量。
“稳态性能分析 → 模型与物性 → 供给边界、过冷度与增压功”展示同一记录。
超临界区不填虚构饱和值；非法液相、超范围状态仍拒绝，旧记录不回填新筛查。
静压分量 `(p-p_vap)/(rho*g)` 不是完整 NPSHa/NPSHr 校核，不显示“抗汽蚀通过”。
