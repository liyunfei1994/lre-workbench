# 本机网页版：系统仿真与总体设计

当前阶段聚焦可重复使用火箭发动机数字化平台的**稳态系统仿真与总体设计**。
网页提供设计点参数、稳态性能分析、节流稳态性能分析、发动机循环原理图、流路状态分析和部件性能分析，沿用桌面式三栏布局。
“推力室与喷管几何”提供所选计算记录的二维尺寸图、三维旋转面和坐标导出；与冷却计算共用保存的内轮廓。型面参数统一在“推力室型面与覆盖”中设置，方法与适用边界见[喷管几何说明](NOZZLE_GEOMETRY.md)。旧记录有完整轮廓时，刷新页面即可查看，无需重新计算。
系统仿真导航中的“热力学校核”提供同条件 CEA–Cantera 对比、系统守恒、真实流体物性与试验验证，详见[校核口径与限制](THERMODYNAMIC_VALIDATION.md)。
详细部件设计、推力室详细分析、有限元和 CFD 不在本阶段网页范围内。

当前交付是运行在一台 Windows 电脑上的浏览器入口。服务固定监听
`127.0.0.1`，默认端口 `8765`。只需服务电脑安装 Python；这版尚不接受其他电脑连接，
也没有修改防火墙、路由器、Ubuntu 服务器或公网部署设置。

## 程序更新与重新计算

- 界面文字、布局和图表显示方式更新后，刷新网页即可重新加载。首页、静态资源和 API 均设置 `Cache-Control: no-store`，不需要通过运行设计点来更新界面。
- Python 后端、参数定义或数据读取逻辑修改后，需要先在无运行任务时停止并重新启动本机服务，再刷新网页。仅刷新网页或重复打开启动器不会替换长驻进程里已加载的模块；提交设计点也不是更新服务的方法。
- 已保存的计算与校核记录保持原结果，不因代码更新或网页刷新而改写。要用新方程生成系统结果，运行设计点；要更新 CEA–Cantera 等独立校核，运行校核页的“运行扫描对比／运行本项校核”。两类记录分别保存。
- 新版本的默认参数不会自动覆盖现有方案。需要变更方案参数时，明确编辑、保存后再计算。

## 预燃室设计：目标、初值与运行约束

FFSC 参数统一在“预燃室设计”中编辑。指定出口温度时，在当前入口焓和压力下反求局部 O/F 并进行循环匹配；指定 O/F 时计算出口温度。仅显示当前生效的目标，混合比迭代初值与压力初猜收在高级设置。两种方式是设计任务的不同闭合条件，都不是固定硬件瞬态运行的控制指令。局部 O/F 也不等于发动机总 O/F。

两侧温度上限各自有状态与依据，独立于设计目标：

| 状态 | 计算和验收行为 |
|---|---|
| 未设定 | 隐藏上限与依据输入；保存的旧限值不参与目标校验、涡轮限值或超限判断；该项尚未评估。 |
| 示例暂定 | 检查暂定数值；超限为未通过，数值满足仍为依据待核实，不能显示工程通过。 |
| 已有依据 | 必须填写依据与适用条件，再按该方案限值检查；这只是用户登记，平台不自动认证材料、寿命或氧相容性。 |

为保持旧方案行为，缺少状态的方案及原示例仍保留 800 / 900 K 数值，并解释为“示例暂定”。750 / 850 K 目标也是本项目的概念设计选择；不是 Raptor 3 测量值。未设置约束时，可进行设计计算，但不能把“没有发现超限”写成约束已通过。燃气整体出口温度、局部热点、涡轮金属温度及材料许可范围是不同的量。

状态与依据随方案版本和计算输入保存。历史结果不重算、不修改原始判定；网页对历史缺依据的预燃室检查补充暂定说明。需要新版系统验收结果时，再运行一次设计点。本轮执行策略版本为 4。

设计依据的使用边界：

- [NASA SP-8081《Liquid Propellant Gas Generators》](https://ntrs.nasa.gov/citations/19730018978)讨论涡轮驱动燃气、温度影响及控制，不能据此给当前甲烷 FFSC 套用一个通用温度上限。
- [DLR 2022 SLME 研究](https://elib.dlr.de/186560/1/SP-2022_Systematic_Studies_on_Reusable_Staged-Combustion_Rocket_Engine_SLME_for_European_Applications.pdf#page=8)第 8 页将混合比选择与涡轮入口温度限制联系起来；该方案使用液氧/液氢，具体数值不能直接转用于甲烷。
- [EADS 2006 可重复使用发动机研究报告](https://edocs.tib.eu/files/e01fb08/565308254.pdf#page=61)印刷第 57–58 页 §2.4.8.1 给出特定液氧/甲烷研究的富燃 900–950 K、富氧 700–750 K 选取范围。图 2-28 与 2-29 的甲烷入口分别为 240 K、140 K，液氧入口均为 122 K，效率假设也不同；报告的单轴、单预燃室基线不是 FFSC 双预燃室的一对设定，不作为本平台默认限值的证据。
- 本轮查阅的 [SpaceX 官方 Raptor 3 更新](https://www.spacex.com/updates/reusability)未提供可追溯的两侧预燃室出口温度。仅靠公开推力、比冲等整机指标不能唯一反求两侧温度；还需入口状态、压降、流量分配和涡轮泵性能等条件。基于自选条件的计算应标为概念方案，不标为实机重建。

## 第一次使用

1. 双击项目根目录的 `start_web_windows.bat`。首次会准备 `.venv-web`；
   如尚无 Python 3.14，请先安装，或通过 `LRE_PYTHON` 指定解释器。
2. 浏览器打开 `http://127.0.0.1:8765`。自行创建管理员：用户名为
   3–32 位字母、数字、下划线或短横线；密码至少 10 位。没有内置默认密码。
3. 点击“新建项目”，选择已有参考工况；已有方案时，登录会直接打开最近更新的方案。
   网页采用桌面版的三栏布局：左侧设计导航、中间参数设置、右侧分析结果。
   表单显示系统设计输入及系统热边界假设，支持搜索参数或单位；切换 FFSC / GG 后
   只显示适用分组。参数定义与显示单位共用桌面声明，存储与求解仍用 SI 单位。
   后台保存完整参数，普通操作只需编辑表单；旧方案缺少 `propellant_pair` 时默认液氧/甲烷。
4. 修改后点击顶部或参数栏底部的“运行设计点”。网页先保存修改为新版本，再提交
   对应版本计算，右侧自动更新状态和结果。仅保存时点击“保存方案”。
   左侧可切换稳态性能分析、节流稳态性能分析、发动机循环原理图、流路状态分析、部件性能分析、热力学校核和日志与警告。
   关闭网页后，只要服务仍在运行，计算会继续。
5. 在“成员管理”创建其他账号。可用另一浏览器的独立会话登录，
   验证同一项目和结果共享；这只能验证本机多会话，不能代替两台电脑验收。

“参考机型”区分可加载的工程示例和仅供查阅的公开资料。“机型资料”可查看
Raptor 3、天鹊 TQ-12A 与 Merlin 1D 的公开信息、来源和模型适用范围。
Merlin 1D 使用液氧/RP-1；网页常规入口仅供查看其公开资料，既有 GG 预算方案继续兼容，采用明确标注的正十二烷替代工质。除公开推力量级外，内部参数为示例假设，不代表真实 RP-1 或 Merlin 实机。

选择可计算的参考机型会**立即载入整套示例参数**，同步循环方式、推进剂组合和 GG 轴系，也同步入口温度、冷却设置等配套输入，无需再次点击加载。FFSC 不显示 GG 轴系选项。此时只修改草稿，保存或运行时才生成新版本，历史计算结果保持原来的输入。
“撤销机型切换”可恢复切换前的参数草稿；继续编辑或保存后，撤销入口消失。“恢复示例参数”可再次加载当前机型的原始示例。
手动改变循环方式、推进剂组合或 GG 轴系后，参考机型显示为“自定义方案”，避免机型名称与当前架构不一致；修改推力等设计点参数可以继续以原机型为参考。重新打开保存的自定义参数时，只有与整套示例完全一致的输入才自动识别机型。实机轴系的证据与示例假设见“机型资料”。

在“循环方式”分组**手动**切换推进剂组合时保留当前数值，不自动把甲烷的低温入口参数改成煤油参数；不相容时会显示原因并禁止提交计算。有适用的常规示例时可加载其完整输入；煤油预算示例不作为新设计快捷入口。
煤油当前仅支持 GG、指定冷却吸热量与指定压降；实际泵和冷却工质物性随工质切换，不使用甲烷回退。物性超出适用温压范围时计算报错。
工质、气相机理指纹与适用范围随每次计算保存，历史结果使用其自身输入显示。详见[推进剂模型与适用范围](PROPELLANT_MODELS.md)。
现有示例已标注工程假设，包括 TQ-12A 类示例 O/F=3.4 与官方公开值 2.9 的区别；
原输入没有因资料核对而自动改写。完整依据见 [循环术语与参考机型](ENGINE_REFERENCES.md)。

结果区采用紧凑的工程表格，分列参数、符号、数值和单位。流量分配使用统一
kg/s 刻度，轴功率图分别显示泵负荷和可用涡轮功率；独立双轴分别比较，
功率差额保留正负号与记录中的校核容差。数据缺失时显示缺失提示。
这些图展示当前稳态设计点，求解诊断可展开查看。

稳态结果页增加“完整收敛与残差轨迹”。内层 Newton、主室热力反馈、预燃室温度外环、
延续法目标工况分别显示终值、容差、次数和终止原因；全部启用层通过才能显示完整数值收敛。
主室热反馈同时检查温度（5 K）、比热比和摩尔质量（各相对误差 1e-4），预燃室目标温差
容差为 3 K，内层归一化最大残差容差为 1e-4。给定吸热量且给定冷却压降时，热反馈层明确显示未启用。

计算完成后可以查看各预燃室外环的热反馈曲线，以及每次 Newton 求解的残差范数和各方程残差。
横轴是迭代步，不是物理时间；不同外环和延续阶段不连接为一条连续收敛曲线。
默认展开最后一次 Newton 求解，其他调用和逐步数值表可以展开。对数纵轴的零值单独标记，
缺失值不补零。轨迹随结果 JSON 保存，切换计算记录可回看；当前不逐步实时推送曲线。

历史计算保持原始结果不变，但展示时会按已保存残差重新复核。旧记录缺少完整证据时显示
“历史收敛证据不完整”，已知外环残差超限时显示未收敛；不能凭旧的绿色内层状态建立新的节流/瞬态基准。
重新运行设计点会生成含完整证据的新记录。数值收敛与供给压力等系统约束仍分别判定。

“稳态性能分析”明确展示单工况计算范围，工况栏从所选计算记录读取燃烧室压力、
环境压力、指定总 O/F 和主喷管面积比，缺失项显示“—”。性能卡片区分计算真空值与指定环境压力下的计算值，
不把所有环境工况统一称作海平面。左侧“瞬态响应分析”现已提供零维热态小扰动积分入口，适用范围与稳态扫描分别标示。图表和指标按结果区实际宽度调整列数，收起参数栏后自动扩展。

参数栏“设计目标与工况”集中设置目标推力、指定室压、指定总氧燃比和环境压力边界；
目标推力对应同栏的环境压力，比冲初值置于折叠的“高级设置 · 迭代初值”。
主喷管面积比统一移入“推力室型面与覆盖”，与收缩比、特征长度及轮廓参数共同管理。
冷却终点面积比在同一型面上定位覆盖边界，不是第二个喷管出口面积比；GG 排气喷管面积比为独立几何输入。
历史方案存在沿程通道表时，通道组展示保存的表定义并隐藏被覆盖的标量尺寸、自动定深及目标流速。
原表与标量均原样保留；无效或空表字符串明确提示，不静默切回另一套几何。

参考工况沿用桌面版，包含模型假设和标定参数。计算完成、数值收敛、
系统约束通过分别显示；任何未通过或缺失信息都会保留。完整结果 JSON 包含
计算范围、原提交参数、求解器有效参数、环境版本、机理文件哈希、状态点和警告。

甲烷物理冷却模式使用唯一系统级准一维内核，沿程吸热、压降、出口状态与热气侧反馈参与循环闭合，
不再另算一套沿程后处理。系统约束校核包括供给压力、轴功率平衡及预燃室 / 燃气发生器出口温度。
稳态与部件结果页同时展示已保存的冷却压力、温度、焓、壁温和热流曲线，以及守恒/热侧耦合诊断；
曲线来自本次循环的同一份 profile。预算模式和旧记录没有沿程解时明确提示，不使用当前参数补算历史曲线。
模型、物性与未验证边界见[统一再生冷却说明](UNIFIED_REGENERATIVE_COOLING.md)。
网页常规设计仅使用统一准一维冷却，“再生冷却模型”显示只读摘要。冷却结果页增加保存轮廓上的覆盖与流向图、通道尺寸和材料摘要、换热方法及检查状态；详细方法从本次记录展开查看。旧预算方案保持原模型，可显式建立准一维草稿再保存为新版本。操作与兼容规则见[再生冷却工作流程](COOLING_WORKFLOW.md)。
“日志与警告”中的“原始部件说明与诊断”保留原始说明，完整数据可通过结果导出查看。
历史任务保留原结果及原工程校核状态，并标识为历史记录；重新运行会生成当前系统范围的新记录。

顶部“打开方案”返回共享项目列表。“方案与计算记录”集中管理方案名称、说明、历史版本与计算记录；
名称、说明和当前完整参数一同保存为新版本，载入旧版本只生成草稿，不覆盖历史记录。
该页“更多操作”提供导出参数备份、导入参数备份和重新载入已保存方案。
备份使用 JSON 格式，包含完整参数、名称、说明、基准版本及是否未保存的标记，不包含历史计算结果。
导入只替换参数草稿，保留当前名称与说明；参数类型、选项或整数校验失败时保留原草稿。
稳态参数栏不再提供原始 JSON 编辑器，也无需执行“应用 JSON”。后台仍保留完整参数与模型选择，
每次计算继续保存输入快照、有效模型及环境版本，旧方案的模型身份按既有兼容规则恢复。
右侧计算记录选择器可直接查看某次运行。编辑参数或切换历史结果后，会提示结果是否对应当前版本。
同一浏览器标签页内按 Ctrl+R 刷新，会恢复所在功能页面、方案及选中的设计计算记录，导航位置按登录账号隔离。
这项记忆只保存导航位置；参数修改仍需保存方案，刷新前的未保存提醒继续保留。
“收起参数”可扩大分析区域，窄屏上参数和结果上下排列。

可点击的导航仅保留当前可用的系统设计与工作区功能。详细部件设计、推力室设计、CFD 和材料库
等桌面入口不出现在网页导航中；既有桌面实现继续保留。网页已恢复节流稳态性能分析；
参数敏感性和方案对比属于后续系统分析工作。瞬态相关入口覆盖热态扰动及若干独立供给、充填、点火、关机与再启动研究单元；完整发动机过程耦合、动态控制与复用寿命评估尚待实现。

## 节流稳态性能分析

选择已完成且数值收敛的设计点计算记录，再打开左侧“节流稳态性能分析”。设置最低节流比例与
扫描点数后运行；扫描从最低比例等间隔增加至 100%，比例表示目标推力占来源设计点目标推力的比例。
当前最低比例可设 5%–99%，点数为 2–15；这些是输入范围，不表示发动机可在整个范围内稳定工作。
例如最低比例 40%、5 点，对应 40%、55%、70%、85%、100% 五个独立稳态工况，横轴不是时间。

来源采用设计记录内的实际计算输入与主喷管喉部面积，并记录来源任务、方案版本、输入与结果哈希。
修改左侧参数不会改变已选来源，也不会覆盖原设计结果；要研究新的设计参数，应先运行新的设计点，
再以该记录建立扫描。节流任务拥有独立的执行状态、历史记录与结果导出，并与其他计算共用本机队列。
取消时保留已经返回的工况，剩余点保持未完成；失败点保留错误原因，不补值、不跨失败点连接性能曲线。

页面提供推力跟随、比冲、室压、总质量流量和温度变化的曲线，以及逐点数据表和诊断。
可导出 CSV 数据、SVG 图表与完整 JSON。曲线和导出都来自所选扫描记录；修改扫描设置后需重新运行，
旧记录不会自动变为新条件的结果。

逐点区分三类判断：**数值收敛**表示循环求解达到残差要求；**喉部闭合**检查面积是否满足来源基准；
**系统约束**检查已有供给压力、轴功率平衡与预燃室／燃气发生器温度限制。某点完成计算不代表三类
判断都通过，约束通过也不构成可用节流范围的试验验证。

模型按固定**主喷管**喉部面积与膨胀比反解室压，室压比例不必等于推力比例；自动定尺寸的冷却通道高度
冻结为来源设计结果。环境压力、整机 O/F、入口条件、效率和压降假设沿用来源记录。推力与比冲采用
来源环境压力；GG 包含排气喷管贡献，主燃烧室 O/F 可随 GG 分流变化，GG 排气喷管仍按各点重算。
因此，这不是完整固定整机硬件的非设计工况模型，也未引入完整泵／涡轮特性图、实际阀门调节规律、
深节流喷管分离与侧向载荷。最低通过点不能解释为已验证的最低节流能力。

液氧／甲烷支持 FFSC、GG；液氧／煤油仍仅支持 GG 正十二烷替代模型，保留既有物性边界和外推警告。
甲烷物理冷却模式在节流各点继续使用同一沿程内核，保留来源设计点的固定冷却几何，重新求吸热、压降和热气耦合。建立基准时检查保存的模型版本、几何、端口、守恒与热侧证据；缺少新模型完整记录时要求重算设计点。指定吸热/压降的预算模式不因此成为固定冷却硬件预测。“瞬态响应分析”仅覆盖已点火热态工作点附近的局部扰动；后文的预冷、点火及关机研究单元也未连接为整机过程模型。上述能力均不能替代完整冷启动、关机、节流动态、燃烧稳定性或寿命验证。

### 发动机循环原理图

原“流程拓扑”入口改名为“发动机循环原理图”。按计算记录中的循环和轴系布局绘制 FFSC、GG 单轴或 GG 双轴示意，使用贮箱、泵、涡轮、预燃室／燃气发生器、冷却通道和推力室符号。彩色实线表示工质流路，虚线表示机械传动；有圆点才表示分流或汇流，交叉线不自动连接。

推力室采用连续的拉瓦尔轮廓：主燃烧室连接收敛段，经最小截面的喉部平滑过渡至钟形扩张段。
喉部有专用标注；主燃烧室与主喷管可分别选择。该轮廓用于解释循环，不使用示意比例代替实际喷管尺寸或型面设计。


## 热态瞬态分析与文献依据

选择数值收敛、系统约束通过的稳态记录，进入“瞬态响应分析”。先检查初始化准备度，设置时间、输出采样数和两侧相对有效阀口面积，再展开容积、转动惯量与局部泵斜率，核对参数来源。提交后使用独立任务、可取消队列和不可变来源快照，提供六组时间曲线、时间截面检查、守恒审计以及 CSV / SVG / JSON 导出。

`src/transient.py` 对 GG 单轴、GG 双轴及 FFSC 的燃气容腔质量、热内能和轴系动能进行 Radau 刚性积分。固定主喷管及 GG 排气喷管有效面积，使用名义点拟合的局部泵、液阻和涡轮关系，燃气 cp/R/组分冻结。90%–110% 是阀口有效面积相对值，不是发动机推力范围；输出采样数不控制自适应内部步长。压力、温度、转速偏离名义值或喷管失去壅塞时，通过连续事件终止，保留此前有效结果。

转动惯量、预燃室与排气容积、泵斜率默认值是研究假设，未经实机标定。入口热焓按支路名义温度形成一致的局部热能账目，不直接混用不同物性库的原始焓零点。该模型未实现冷态点火、两相充填、液柱惯性、水击、壁面蓄热和控制器，不能据此给出实机启动时序或安全操作限值。数值闭合不代表试验验证。

节流稳态分析新增“有限区间节流响应增益”：以有效100%点归一化，相邻扫描点计算割线增益；不跨失败点或几何失效点。它是耦合节流路径的响应指标，不是独立设计参数的偏导数。

逐篇文献证据与后续计划见 [瞬态文献依据](TRANSIENT_LITERATURE_EVIDENCE.md) 和 [稳态文献差距](STEADY_LITERATURE_GAPS.md)。

## 供给网络动态

选择已完成的设计记录后，进入左侧“供给网络动态”。该记录提供液氧/甲烷或液氧/正十二烷的泵标度与入口温度，编辑区中的管路、容腔、阀门和背压则是独立研究参数。默认 2 s 时间线在 0.2 s 开始，将规定转速与阀指令从 100% 逐渐降至 80%；这不是整机推力节流命令。

分别检查液氧与燃料的边界/初值、管长管径及额定损失、容腔容积、阀门滞后/限速/泄漏和泵图，再点击“运行供给网络动态分析”。可观察压力、带符号流量、液体库存、阀门指令与实际开度、规定转速、泵转矩及功率、逐回路守恒误差。可切换工质和时间截面，取消任务，查看独立历史，导出 JSON、CSV、SVG。初始容腔压力改变后，由后台按来源入口温度重新计算并冻结参考密度/体积模量，以最终结果快照为准。

解析泵图仅用于接口和数值演示，未经实测标定。真实图可在“低速与反流泵图”中导入 `theta_deg,head,torque` CSV；必须采用页面标注的角度、归一化、完整周期及额定点约定，后台检查插值耗散和适用域。低压、压缩应变、泵图域或阀行程越界会停止积分并保留有效结果。库存变化不是液位，能量审计是液压机械能余额。

原设计整机约束未通过时仍可研究独立供给支路，但原失败状态不会被改为通过，热态整机瞬态初始化门槛也不放宽。本页尚不包含真实流体热状态演化、汽蚀/两相、预冷、水击传播、驱动轴自启动、点火或关机阀序。详细说明见 [供给网络模型与证据](FEED_NETWORK_DYNAMICS.md)。

## 预冷与充填分析

打开已完成设计记录后，选择“系统仿真 → 预冷与充填分析”。设计记录提供工质种类和默认供给温度；容腔初温、气液库存、金属壁温与热容量、壁流换热导纳及节流面积在本页独立设置。PT 初态用于单相，PQ 初态用于饱和气液状态。选择回路和时间截面查看壁温/流体温度、压力、库存、气相体积分数及各边界通量，结合守恒结果和用户目标判据判断结果。

记录可取消、回看并导出。末态快照含质量、内能、壁温和物性信息，只为后续网络初始化提供材料，不会覆盖原设计或自动开启点火。当前只计算纯推进剂均相平衡单元，不能模拟氮/氦吹除、选择性排气、空间充填前沿或完整发动机冷启动。详见 [模型说明](CHILLDOWN_MODEL.md) 与 [文献依据](CHILLDOWN_LITERATURE_EVIDENCE.md)。

## 点火事件与建压分析

打开已完成的液氧/甲烷设计记录，进入“系统仿真 → 点火事件与建压分析”。记录只提供推进剂种类与来源标识；本页使用独立的气态氧/甲烷压力源、有限容积和阀门，不继承低温液体温度。来源设计约束未通过时可研究独立容腔，原设计的失败状态保留；煤油来源不可替换为甲烷运行。

依次核对容腔与初态、气体供给、两侧阀门时序、外部点火热脉冲、金属壁面以及停止边界。可选择初始氮气或未燃氧/甲烷混合物，分别开关化学反应并设置脉冲能量，比较相同边界下有无外部点火能量、反应与纯气体充填的差别。GRI-Mech 3.0 共同热力学温域采用 300–3000 K；越界保留最后有效结果，不按数值截断继续积分。

结果提供压力、气体/壁温、进出口流量、阀位、外加点火功率、化学放热率、主要组分、库存、壁面传热和守恒曲线。给定事件与已到达的事件分开显示，时间滑块查看单一截面；可取消任务并导出已有数据。默认采样点之外保留事件时刻，输出点数不控制内部自适应积分精度。

本页不预测点火成功、延迟或熄火；参考压力首次达到时间只描述压力响应。末端快照不能作为完整发动机启动初值直接执行。实验对照、适用域与后续判据接入要求见 [模型说明](IGNITION_STARTUP_MODEL.md)、[证据表](IGNITION_STARTUP_EVIDENCE.md) 和 [本轮验证](IGNITION_STARTUP_VALIDATION.md)。

## 关机与再启动分析

选择已完成的设计记录，进入“系统仿真 → 关机与再启动分析”，再选择一个独立研究单元。设计记录用于推进剂适用性检查和来源追溯，本页的初态、时序与边界独立设置，默认值不是所选参考发动机的关机程序。来源设计未通过的系统约束继续保留，不能通过独立单元计算将其改为通过。

| 选择项 | 先核对的输入 | 主要结果与边界 |
| --- | --- | --- |
| 气相关机与给定再点火 | 气体初态、供给压力/温度、关阀和再次供给时刻、两次给定热脉冲、壁面参数 | 氧气/甲烷反应、余气库存、壁温与压力；仅接受液氧/甲烷来源，不继承其低温液态初值 |
| 残余工质泄放与再充填 | PT/PQ 初态、壁温、进出口边界与三个阶段的阀位指令 | 纯工质 HEOS/均相平衡气液库存和余热；排出均相混合物，入口和出口采用理想止回，不证明彻底排空 |
| 轴系惰转与液压反流 | 全液初态、泵特性与适用域、转动惯量、摩擦、外给驱动力矩和关阀/再开阀时序 | 积分实际转速、有符号支路流量与液压/转子能量；不含两相排空、汽蚀或涡轮驱动预测 |

点击“运行本研究单元”后，通过事件时间轴、时间截面、响应曲线与守恒表检查全过程。再次供给、再驱动和第二次热脉冲均从本单元连续演化的停留状态出发，不把库存、壁温或转速重置到初态。输出采样密度与内部积分精度分别设置；曲线上的采样极值不等于所有内部瞬时极值。

任务进入独立历史并保存冻结输入、来源、初末态快照与有效结果，可取消并回看；切换上方研究单元或修改参数不会改写既有结果。支持 CSV 数据、SVG 曲线、完整 JSON 和末态快照 JSON 导出。越域时保留有效时间段和终止原因；未到达的事件保持未观测，缺失值不补成零。

三个单元尚未互相耦合，不自动将 HEOS 与 Cantera 的不同能量基准拼接，也不将末态直接认定为整机再启动初值。计算完成与守恒通过只说明当前模型的数值过程；不判定实机再启动成功、点火延迟或熄火。见 [模型与方程](SHUTDOWN_RESTART_MODEL.md)、[文献证据](SHUTDOWN_RESTART_EVIDENCE.md) 与 [验证记录](SHUTDOWN_RESTART_VALIDATION.md)。

## 稳态数值方法与完整收敛（2026-10-23 第二轮）

参数区新增“数值求解”：默认使用缩放 Newton 与回溯线搜索，可选择有界信赖域 TRF
作为对照。两种方法使用相同物理方程、变量边界、缩放规则和残差验收标准；TRF 的
优化器停止标志不替代方程残差与完整外环判定。旧方案缺少 `nonlinear_solver` 字段时
按 `newton` 载入；既有计算历史不补造轨迹。重新运行设计点后查看新增证据。

“完整收敛与迭代历程”显示四层判据、内外环残差曲线、循环残差求值次数、雅可比次数、
未接受试探、热启动以及延续接受／拒绝明细。每次内层调用独立绘图，可以展开其固定
缩放与有单位的容许误差。内层曲线仅画实际接受点；热反馈拒绝试探在曲线上断开，在
数值表中保留残差、松弛系数及拒绝状态。Newton 回溯控制残差平方和下降，图示最大分量
范数可以短暂上升，不能据此单独判定算法失效。

完整热启动在同一次温度目标外环内传递流量／压比、Tc、γ、摩尔质量；失败时重试冷启动
延续。独立计算不会继承陈旧缓存，临时输入在正常、失败及取消退出时恢复。延续失败缩步、
成功增步，分别记录成功到达比例和最后尝试比例；热反馈采用受保护的自适应松弛与振荡抑制。
取消仍通过任务控制传播，固定供给边界的非法工质相态仍直接拒绝。

所有真实循环残差评价（含差分、拒绝和异常试探）共享每次内层调用的预算：
`max(1, 2 * (变量数 + 1) * (最大接受步数 + 1))`。默认 50 步时，三变量为 408 次、
两变量为 306 次；耗尽后保存最后接受点并标注 `max_evaluations`。这不是整个嵌套任务的
总预算，也不包括温度反求中单独调用的热化学函数次数。

实算、输入快照、计数及复现脚本在 `diagnostics/numerical_methods_20261023/`：

- `compare.py`：原截图额定点、不同数值初值、低推力设计点的 Newton/TRF 对照。
- `check_warm_start.py`：仅关闭完整热启动，隔离其减少重复计算的效果。
- `check_throttle.py`：同一主喉部／冷却几何下，40% 和 100% 两工况回归；仍显示供给约束失败。
- `run_gg_smoke.py`：甲烷／煤油代理、单轴／双轴、两后端共 8 个 GG 案例。
- `check_jacobian_steps.py`：差分步长减半敏感性检查。
- `convergence_preview.html`：使用生产页面渲染器生成的 Newton/TRF 实算交互预览。

运行上述 Python 脚本使用 `.venv-web/Scripts/python.exe -X utf8`。本轮 175 项 Python
回归和 310 项前端测试通过，桌面入口已作编译检查；当前环境缺少 PySide6，未执行桌面
交互测试。浏览器自动化连接失败，预览已生成并通过静态渲染和前端测试，未宣称完成截图验收。
