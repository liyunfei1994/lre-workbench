# 本机网页版试用

当前交付是运行在一台 Windows 电脑上的浏览器入口。服务固定监听
`127.0.0.1`，默认端口 `8765`。只需服务电脑安装 Python；这版尚不接受其他电脑连接，
也没有修改防火墙、路由器、Ubuntu 服务器或公网部署设置。

## 第一次使用

1. 双击项目根目录的 `start_web_windows.bat`。首次会准备 `.venv-web`；
   如尚无 Python 3.14，请先安装，或通过 `LRE_PYTHON` 指定解释器。
2. 浏览器打开 `http://127.0.0.1:8765`。自行创建管理员：用户名为
   3–32 位字母、数字、下划线或短横线；密码至少 10 位。没有内置默认密码。
3. 点击“新建项目”，选择已有参考工况。表单支持常用参数；
   “完整参数 JSON”保留桌面版全部 109 个输入字段，支持方案导入、导出。
4. 修改后点击“保存新版本”，再点“提交计算”。在“计算记录”查看结果。
   关闭网页后，服务仍会继续计算。
5. 在“成员管理”创建其他账号。可用另一浏览器的独立会话登录，
   验证同一项目和结果共享；这只能验证本机多会话，不能代替两台电脑验收。

参考工况沿用桌面版，包含模型假设和标定参数。计算完成、数值收敛、
工程约束通过分别显示；任何未通过或缺失信息都会保留。完整结果 JSON 包含
原提交参数、求解器有效参数、环境版本、机理文件哈希、状态点和警告。

## 启动、停止与数据

| 入口 | 用途 |
| --- | --- |
| `start_web_windows.bat` | 检查独立环境、启动服务并打开网页；已经运行时打开现有入口 |
| `setup_web_windows.bat` | 仅安装或修复网页运行环境 |
| `stop_web_windows.bat` | 请求停止默认工作区服务，正在计算的任务记为“服务中断” |
| `user_data/web-workbench/workspace.sqlite3` | 本机账号、方案版本、任务和结果 |
| `user_data/web-workbench/job-logs/` | 每个计算任务的日志 |

双击启动时保留命令窗口；关闭窗口也会停止服务。通过后台启动的服务请用停止脚本。
没有安装开机自启或 Windows 系统服务。电脑关闭或休眠时无法提供访问和持续计算。
环境检查不一致时才安装依赖；正常使用不必每次下载软件。
搬动整个文件夹前应先停止服务；代码路径变化后可重建 `.venv-web`，保留 `user_data`。

备份：停止服务并确认启动窗口已退出，然后完整复制 `user_data/web-workbench/`
到自己的备份目录。不要在运行期间只复制 SQLite 主文件，因为 WAL 可能尚未合并。
恢复时停止服务，将完整备份放回相同位置再启动。备份包含账号密码哈希和会话信息，
应和原数据一样保存；`user_data`、`.venv-web` 和测试数据均不进入 Git 或源码包。

首版暂未提供改密、找回密码、删除账号、删除项目或自动备份功能。请保管好管理员凭据。

## 协作规则

- 一个工作区内的所有登录成员都能查看、编辑全部项目和查看计算结果。
  管理员可以创建成员账号、取消任意任务；普通成员只可取消自己的任务。
- 每次保存创建不可变的方案版本。两个会话同时修改时，后保存的旧版本请求会被拒绝，
  网页保留草稿。可先导出草稿，再重新载入最新版本、手动合并后保存。
  本版不是实时多人同屏编辑。
- 提交任务固定使用当时的版本和参数快照，之后修改方案不会改变历史任务。
- 一次执行一个独立计算进程；每人最多 3 个未结束任务，工作区最多 12 个；
  每次计算最长 10 分钟。超时、取消和退出会终止对应进程。
- 正常停止时当前任务中断；重启会将遗留运行任务标为中断，排队任务继续执行。
  中断任务需要用户确认后重新提交。

## 开发与验收

技术组成：FastAPI / Uvicorn + SQLite + 原生 HTML、CSS、JavaScript，
后端复用 `make_cycle_model(...).evaluate()`，保留桌面设计点流程及其后处理。
没有修改物理公式、默认工况、求解器收敛容限。独立进程隔离 Cantera 的可变状态。
科学库与桌面固定版本一致：Cantera 3.2.0、CoolProp 7.2.0、
NumPy 2.3.5、SciPy 1.16.3、scikit-fem 11.0.0；完整依赖在 `requirements-web.txt`。

```powershell
.\setup_web_windows.bat
.\.venv-web\Scripts\python.exe -m unittest discover -s web_tests -v
.\.venv-web\Scripts\python.exe -m webapp.run
```

临时验收数据应使用单独路径和端口：

```powershell
.\.venv-web\Scripts\python.exe -m webapp.run --port 8766 --database .cache/web-qa/workspace.sqlite3
```

程序没有提供 `--host 0.0.0.0` 开关。本阶段仅支持回环地址和同源请求。
局域网版本应在确认网络互通后添加 HTTPS、明确成员访问范围及数据库备份机制，
再进行两台电脑的实际提交与查看验收。GitHub 托管代码；运行服务与项目数据库在本机。
使用者日常在网页操作，开发者继续通过 Git 分支、测试和 Pull Request 更新程序。

第一版只迁移共享方案与设计点计算闭环，桌面版其他交互页面、CFD 适配器执行、
三维交互、批量优化等还没有搬到网页。
