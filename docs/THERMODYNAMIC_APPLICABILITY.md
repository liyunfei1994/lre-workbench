核对日期：2026-10-23。本轮针对系统仿真的热化学数据、模型假设和证据记录；不把软件一致性、数值收敛或能量闭合等同于发动机试验验证。

后续更新：已接入 `gri30_highT.yaml`；新构造 `EngineInputs` 默认采用 `gri30_highT`，旧方案显式保存的 `gri30` 不自动迁移。早期循环复算、CEA 对照与压力网络定义修正见 [甲烷热化学数据与压力网络定义修正](THERMOCHEMICAL_DATA_AND_PRESSURE_NETWORK.md)。本轮进一步修正纯流体理想参考焓，并以同一准一维冷却/热气耦合模型替代系统点与沿程后处理的重复物理求解，见 [统一再生冷却模型、数据契约与验证边界](UNIFIED_REGENERATIVE_COOLING.md)。下文数值表和集中抽热/绝热喷管描述保留为此前历史校核证据，不代表本轮统一模型的最终性能。

## 结论与工具选择

继续使用 Cantera 作为生产计算工具，以真实运行的 CEA 作为独立实现对照。两者不是简单的精度等级关系：结果同时受物种集合、热力学数据、状态方程、入口焓和膨胀假设影响。当前循环计算调用化学平衡，GRI30 的反应速率系数不参与平衡解；换一套更大的动力学机制不自动解决热化学数据温区问题。

本机 GRI30 气相使用 `ideal-gas`。主要 CHO 物种多项式上限为 3500 K，而本轮主室计算超过此值。原 `_check_gas_model_range` 跳过 GRI30 的逻辑已经修复，检查所有实际非零物种的上下温限，保存外推物种及质量分数，不截断求解温度。全机制共同温区与当前存在物种共同温区分别记录；微量物种的外推仍保留，不能把其占比当误差百分比。[Cantera GRI30 文件](https://www.cantera.org/stable/examples/input/gri30.html)、[物种热力学模型](https://www.cantera.org/stable/reference/thermo/species-thermo.html)

Cantera 本身支持多种气相 EOS，但本项目当前使用理想混合物，不是高压真实混合气模型。本轮确认并显示这一事实，尚未量化富氧/富燃预燃室的非理想性误差。独立 CEA 基准同样按理想气体计算，因此不能据两者接近宣告高压 EOS 已通过。[Cantera 相模型](https://www.cantera.org/stable/reference/thermo/phase-thermo.html)

## 焓参考态与燃烧损失

主室温度、γ、摩尔质量初猜仍归入数值初值；真正的纯推进剂化学焓对齐单独显示：

`h(T,p) = h_Cantera,ideal,pure(Tref) + h_HEOS(T,p) − h_HEOS,ideal(Tref)`

其中 `h_HEOS,ideal(Tref) = h_HEOS(Tref,pref) − h_HEOS,residual(Tref,pref)`。甲烷/氧使用 298.15 K、101325 Pa 参考状态，并显式扣除 HEOS 的有限压力残余焓；`src/fluid_properties.py:ideal_reference_enthalpy` 返回该理想参考焓。此前直接减去有限压力 HEOS 总焓的公式已被替换，不能继续当作现行实现。低温纯流体焓来自受范围检查的 HEOS，不为取得液体焓先外推低温气相 NASA 多项式；也不把 CoolProp 的绝对焓零点当化学生成焓。

对照两端采用同组入口焓，能排除输入不一致，却不能独立验证共同入口焓本身。有限压力参考残余焓现已显式处理；数据库生成焓差异和 EOS 误差仍需独立核验，不能被两软件接近掩盖。下文旧数值是在当时模型与焓基准下得到，不能替代本轮重新计算。

新增明确的燃烧损失模型选择：

| 模式 | 实际行为 | 用途 |
| --- | --- | --- |
| 焓平衡，不附加经验燃烧损失 | FFSC 按两路入口焓减去已建模冷却抽热，再求 HP 化学平衡；不折减温升 | 新加载 Raptor 类 FFSC 示例的默认模式 |
| 历史温升折减 | HP 平衡后冻结组成，按旧系数降低温升，将相应焓差记为经验热汇 | 旧方案兼容与差异复核 |

新模式不是“100% 燃料完全燃烧”，平衡组成仍含解离产物。也没有把旧系数重新命名成 c* 效率后继续使用。若要建模有限速率、不完全混合或对外热损失，需要独立的闭合关系和依据；不能仅为贴近目标 Isp 再加入任意系数。

旧方案缺失新字段时继续解释为历史模式，保存值不自动迁移；新加载参考示例才选择焓平衡。GG 兼容路径尚未完整闭合冷却热端，也未输出旧折减的独立损失热汇，报告已与 FFSC 分开说明。

## 两次实际系统计算

同一 Raptor 类工程示例，海平面目标推力 2451.6625 kN、室压 33 MPa、总 O/F 3.6、面积比 34.34。内部参数仍是工程假设。

| 项目 | 焓平衡 | 历史 0.99 温升折减 |
| --- | ---: | ---: |
| 完整数值收敛 | 是 | 是 |
| 主室计算温度 / K | 3773.6046 | 3743.0270 |
| 附加经验燃烧损失 / MW | 0 | 54.2091 |
| 再生冷却集中抽热 / MW | 135.2575 | 134.2415 |
| 全系统能量账残差 / W | −11.01 | −14.30 |
| 独立重算的能量检查 | 23 项通过 | 23 项通过 |
| 热力学适用性 | 待核实，主室外推 | 待核实，主室外推 |

冷却抽热随主室反馈重新计算，因此两次不完全相同。能量检查仍采用已有 `10 W + 1e-5 × 最大能量项` 政策；其通过只证明当前账目闭合。当前再生冷却总热量集中从主室扣除、喷管绝热膨胀的处理仍是系统级近似。

记录：`diagnostics/thermodynamic_applicability_20261023/system_adiabatic.json`、`system_legacy_temperature_rise.json`；复算脚本为同目录 `check_system_thermo.py`。

## 喷管与独立热化学对照

生产主喷管使用从主室组成冻结的等熵膨胀。不是喉部冻结，也不是连续平衡；不能无条件称为“更真实”或“已验证的保守值”。本轮同时保存喉部温压，检查主室、喉部和出口的热力学温区。

独立校核现在可明确选择连续平衡、主室冻结、喉部冻结，以及两端各自完整数据库或共同 CHO16 中性气相物种集合。对照统一入口 J/kg 焓、元素原子量、压力、O/F、面积比，并核验 CEA 原始输入与组成质量和。修正了本机 RocketCEA 1.2.3 公共组分接口漏掉最后一个产物的问题，没有用归一化掩盖遗漏。

已实际完成 54 个配对点：10/33 MPa × O/F 3.2/3.6/4.0 × 三种膨胀假设 × 三种数据/物种策略。共同物种、33 MPa、O/F 3.6、面积比 34.34、主室冻结时：

| 数据 | 主室温度 / K | 真空比冲 / s |
| --- | ---: | ---: |
| Cantera + GRI30 | 3777.926 | 346.63979 |
| Cantera + NASA gas 候选 | 3777.669 | 346.64262 |
| 本机实际 CEA | 3774.301 | 346.49894 |

这是独立理想燃烧室/喷管，不是 FFSC 整机结果。GRI30 此处外推；Cantera 随附 `nasa_gas.yaml` 的所选物种覆盖 200–6000 K。该候选只在校核页启用，尚未替换生产数据：CHO16 尚未证明覆盖极富燃预燃室及所有必要产物。候选与 CEA 数据来源也可能相关，不能把三列当三份独立实验。

本机使用 RocketCEA 1.2.3 包装的经典 CEA，数据库版本和文件哈希已保存；不称为最新版 NASA CEA。详情、可复算脚本及已知限制见 [热化学对照文档](THERMODYNAMIC_VALIDATION.md)。NASA CEA 官方项目提供化学平衡与火箭性能计算，但仍须按具体版本和假设对齐。[NASA CEA](https://www.nasa.gov/glenn/research/chemical-equilibrium-with-applications/)

## CoolProp 与 REFPROP

本机 REFPROP 10.0 已经能通过 CoolProp 的 REFPROP 后端实际调用。无需为了此次对照额外安装 ctREFPROP；NIST 官方 Python wrapper 也是调用已安装动态库，不自带授权数据库。[NIST Python wrapper](https://github.com/usnistgov/REFPROP-wrappers/tree/master/wrappers/python)、[CoolProp REFPROP 接口](https://coolprop.org/coolprop/REFPROP.html)

对上一轮冻结设计点的 13 个纯流体状态完成真实对照。密度、定压比热与共同参考态焓增量高度接近；最大黏度差 4.2329%、导热率差 0.2213%。这些是软件差异，不是实验误差，更不能直接换算为冷却热流或推力误差。

物性校核补充熔化线检查：例如甲烷 100 K、70 MPa 虽落在矩形温压范围内，却低于约 107.588 K 的熔化边界，不能把可返回的亚稳流体值当有效液体状态。EOS 范围、输运模型范围与实验精度分别说明。生产仍使用 HEOS，纯流体后端切换不能解决混合燃气非理想性。逐点证据见 [纯流体物性报告](FLUID_PROPERTY_APPLICABILITY.md)。

## 界面与尚未完成的物理验证

稳态页新增独立“热力学适用性与模型假设”，展示节点温区、外推物种、气体 EOS、喷管冻结位置、焓对齐和损失热量；历史记录缺失证据显示未记录。热力学校核页可选择共同物种与高温候选数据，纯流体详情显示固相边界和数据指纹。

下一项科学工作应是扩展温区合格数据的物种覆盖并验证两类预燃室工况，再研究有参数来源的混合气 EOS；同时补冷却分布与输运关联式敏感性。当前不采用纯 O2/CH4 的压缩因子代替反应混合物，也不因一次对照接近就取消外推警告。
