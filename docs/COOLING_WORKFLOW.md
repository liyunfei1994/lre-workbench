# 再生冷却：常规设计与历史记录

网页常规设计使用统一准一维冷却模型，不再提供“给定吸热量与压降”的日常切换选项。新建与加载常规示例采用目前支持的液氧／甲烷方案；冷却模型摘要为只读信息。

## 日常操作

1. 在“推力室型面与覆盖”“冷却系统几何·通道与壁面”和“壁面材料与热物性”中设置硬件与材料假设。同一参数保持单一编辑位置。
2. 保存方案并运行设计点。在稳态结果的“再生冷却”页查看所选计算记录的几何示意、模型摘要、沿程曲线和校核状态。
3. 同时检查吸热量、压降、出口状态、守恒残差、物性和材料数据适用范围以及壁温约束。数值收敛与守恒闭合不等于换热模型、材料寿命或结构可靠性验证通过。

统一准一维模型沿同一轮廓求解冷却剂压力与焓，吸热量、压降、出口状态和沿程曲线来自同一份求解结果，并反馈主循环。热侧、壁面与冷侧的模型假设应从结果摘要和展开的依据中核对；几何示意用于查看计算范围，不是详细制造图。

结果页读取上方选中的计算记录。修改当前参数或刷新网页不会重新计算旧记录，也不会用新草稿补造旧记录缺少的剖面。要评价修改后的设计，应运行新的设计点并选择其记录。

新增计算记录保存 `profile.model_methods`，说明实际采用的热侧、壁面、冷侧和水力方法，以及换热和摩擦是否启用。旧记录没有这份明细时明确显示“方法明细未随记录保存”；仍可显示原记录已有的几何、尺寸、曲线与诊断。本次仅增加方法描述的保存与展示，没有改动换热和压降方程。

## 旧预算方案

给定 Q／Δp 的模式继续在后台、API 和旧方案中保留。它计算端口焓差与给定压降，不提供准一维沿程解，也不能据此声称完成固定硬件冷却预测。

打开旧预算方案时，界面显示其历史模式，给定吸热量与压降收在展开项中；普通保存和刷新不会将它自动转为准一维。相关完整参数仍保存于方案版本和计算记录，隐藏日常入口不等于删除兼容数据。

液氧／甲烷预算方案可以通过明确的升级操作建立准一维草稿。升级后须检查通道几何、材料与计算范围，保存为新版本，再运行设计点。原方案版本和原预算结果继续保留；旧的 Q／Δp 兼容数值不会作为准一维结果使用。

当前液氧／煤油替代工质模型尚未支持这套准一维冷却关联式。因此，其预算工程示例不列入网页常规设计入口，既有方案与后台兼容能力保留；不能直接把模式改为准一维来取得煤油冷却预测。
